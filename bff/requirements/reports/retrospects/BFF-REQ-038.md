# BFF-REQ-038 — 회고 (2026-09-24)

- 서버 슬라이스 1 이 응답 변환(`riskView.ts`)에서 원 반올림 · 비율 소수를 이미 정해 둬 BFF 는 모양 검사만 했다. 금액을 바꾸는 `if` 0건
- 거래 + 계획 저장을 BFF 가 조립했다. 성능 규칙은 의존 호출을 서버 조합으로 올리라고 하지만, "거래가 저장되면 성공" 이라는 부분 성공 계약이 화면의 것이라 여기 뒀다. 서버에 합친 쓰기가 생기면 지운다
- 처음엔 계획 수량에 거래 수량을 넣었다 — 준수 판정 `size_exceeded` 가 영원히 거짓이 되는 값이라 뺐다. 폼이 받지 않는 값을 BFF 가 채우지 않는다
