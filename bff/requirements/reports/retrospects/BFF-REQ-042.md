# BFF-REQ-042 회고 — 성적 4요소 claim 중계 (2026-10-07)

## 결과가 기대와 달랐나

- 종목 코치 뷰모델이 서버 `trackRecord` 객체를 그대로 넘기고 있어, 타입에 없는 필드가 검사 없이 화면까지 갔다 — claim 을 더하다 발견했다

## 잘한 것

- 7곳을 공용 순수 함수 하나로 처리해 검사 규칙이 한 벌이다
- 목표 비중의 자리 불일치(BFF 가 라이브를 내림)를 claim 에도 반영했다 — 숫자와 기간이 다른 기록을 말하지 않는다

## 아쉬운 것

- "뷰모델 파일은 import 없음" 조건에 예외가 하나 생겼다. 조건의 이유를 주석에 같이 적었다

## Action

- 서버 객체를 통째로 넘기는 뷰모델을 다음에 만지면 필드를 골라 옮기도록 바꾼다
