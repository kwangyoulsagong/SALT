# 데스크톱 화면 규칙 (웹 1024 이상)

근거: 기준 국내 증권 앱 웹 11화면 실측(2026-10-30, 1920 · 1280 폭, 계산 스타일) + 공개 2차 실측 대조. 값 표와 화면 대응은
`FE-REQ-047`(틀) · `FE-REQ-048`(홈) · `FE-REQ-049`(상세). **문서 · 코드 · 커밋에 기준 서비스 이름을 쓰지 않는다.**

> 표에 "실측"은 우리가 직접 잰 값, "2차"는 공개 실측 자료와도 맞은 값이다. 둘 다 아닌 값을 새로 지어내지 않는다 —
> 필요하면 다시 재고 이 표에 행을 더한다.

## 1. 틀 — 모든 데스크톱 화면이 같은 틀이다

```
┌ 전역 헤더 52 (투명, 바탕 위) ──────────────────────────────┐
│ 로고 · 내비(홈 · 투자 · 코치 리포트)        검색 · 프로필 │
├──────────────────────────────────────────┬─────────────────┤
│ 본문 패널 (#FBFCFD · 모서리 12 · 여백 12) │ 오른쪽 사이드 312 │
│  ─ 요약 띠 → 탭 → 목록 + 미리보기          │ (관심 · 안내)     │
└──────────────────────────────────────────┴─────────────────┘
```

| 항목 | 값 | 출처 |
|---|---|---|
| 바탕 | `#F4F5F8` | 실측 |
| 본문 패널 | `#FBFCFD` · 모서리 12 · 안쪽 0.75~1px 선 · 바깥 여백 12 | 실측 · 2차 |
| 상세 패널 | 모서리 16 · 안쪽 1px 선 `rgba(2,32,71,.05)` | 실측 · 2차 |
| 전역 헤더 | 높이 52 · 내비 링크 36 높이 · 14/600 · 패딩 8×12 · 모서리 9 | 실측(링크 36 은 2차도 같음) |
| 폭 | **가득 찬 폭.** 가운데 정렬 최대 폭 컨테이너를 쓰지 않는다 | 실측 |
| 오른쪽 사이드 | 312 + 왼쪽 0.75px 선. 1280 에서도 고정, 줄어드는 것은 본문 | 실측 |

- 화면마다 프로필 · 뒤로 링크를 따로 놓지 않는다 — 헤더 하나(`widgets/app-header`)
- 1024~1279: 사이드 유지, 본문 안 격자가 줄고 표는 덜 중요한 열부터 숨긴다. 768~1023: 사이드를 본문 아래로. 768 미만: 안내(`FE-REQ-043`)

## 2. 글자 위계 — 토큰만 쓴다

| 단 | 크기/굵기/줄 | 쓰는 곳 |
|---|---|---|
| 제목 | 18/700/24 | 화면 제목 · 상세 패널 제목 큰 것 |
| 섹션 | 14/600/20 | 섹션 탭 · 내비 · 종목 이름(상세 머리 14/700) |
| 본문 | 13/600/20 | 표 행 · 목록 행 · 칩 · 값 |
| 라벨 | 12/500/16 | 표 머리 · 통계 이름 · 출처 · 시각 |
| 가격(상세) | 24/700 | 상세 머리 한 곳만 — 기준(18)보다 한 단 크게, 우리 화면의 주인공 |

| 글자색 | 값 | 쓰는 곳 |
|---|---|---|
| 1단 | `rgba(26,31,41,.89)` | 제목 · 값 · 선택된 탭 |
| 2단 | `rgba(22,31,46,.61)` | 보조 설명 · 표 머리 일부 · 호버 |
| 3단 | `rgba(18,31,51,.47)` | 라벨 · 미선택 탭 · 시각 |

- 한 화면에 크기는 위 5단만. 20 · 16 같은 사이값을 새로 쓰지 않는다
- 숫자 열은 오른쪽 정렬 · 고정폭 숫자(`tabular-nums`)
- 문장 · 목록 한 줄은 최대 720px — 넓은 카드에 문장을 끝까지 늘리지 않는다

## 3. 컨트롤

| 컨트롤 | 값 | 출처 |
|---|---|---|
| 섹션 탭 | 글자 진하기로만 구분, 밑줄 없음 | 실측 |
| 알약 탭(상세) | 모서리 999 · 8×12 · 선택 = 옅은 면 | 실측 |
| 세그먼트 | 바깥 `rgba(2,32,71,.05)` 모서리 8 · 안쪽 2, 항목 28 · 모서리 6, 선택 = 흰 면 | 실측 |
| 필터 칩 | 28 · 모서리 7 · 4×8 · 13/600, 켜짐 = 파랑 글자 + 9% 파랑 면 | 실측 · 2차 |
| 버튼(주) | 32 · 모서리 8 · 14/600 | 2차 |
| 정보 상자 | 배경 `rgba(13,25,74,.02)` · 모서리 12 · 그림자 없음 | 실측 |
| 타일(지수 · 요약) | 투명 · 모서리 8 · 8×12, 호버 때만 면 | 실측 |
| 표 행 | 40~44 · 호버 면 모서리 8 | 실측 — **우리 표는 이미 맞다, 바꾸지 않는다** |

- 카드에 그림자를 쓰지 않는다 — 면 색 차이와 안쪽 선으로 가른다(메뉴 · 팝오버만 그림자)
- 파랑 바탕 위 흰 작은 글자는 대비 미달(3.7:1) — 큰 글자 · 굵은 글자에만

## 4. 화면 패턴

| 패턴 | 규칙 |
|---|---|
| 목록 + 미리보기 | 같은 패널 안 왼쪽 표 · 오른쪽 미리보기 칸. 선택은 주소에(`?symbol=` · `?goal=`) |
| 요약 띠 | 위 띠 = 타일 격자 + 오른쪽 정보 상자. 무엇을 보일지는 서버가 정한다 |
| 상세 | 머리 2줄(≤ 88) → 알약 탭 → 패널 격자 + 오른쪽 고정 열 360 |
| 뒤로 | 상세 머리 첫 칸에 뒤로 버튼 + 이동 경로 한 줄. 목록의 탭 · 필터는 주소에 있어 돌아오면 같은 자리 |
| 탭 제목 | 상세는 `{가격} {등락률} \| {이름}` 을 실시간으로(초당 1회까지) — 서버 HTML 제목은 그대로 |
| 빈 상태 | 패널 높이를 지키는 한 줄 안내. 빈 카드를 쌓지 않는다 |

## 5. 하지 않는 것

- 휴대폰 화면을 가로로 늘린 배치(한 줄씩 쌓인 카드 · 화면 폭 균등 분배 통계)
- 화면마다 다른 머리 · 뒤로 링크 · 프로필 위치
- 같은 숫자 두 번(판단 카드 성적 = 해설 칸 성적)
- 그림자 카드 · 큰 보라 버튼을 정보 영역에 — 주 버튼은 화면당 하나
- 기존 결정 뒤집기: 표 선택 보라 금지 · 차트 색 · 등락 색 · 가격 깜빡임 없음 · 종목 아이콘 · 셰브론(`respect` 규칙은 메모리 · REQ)
