# 데스크톱 화면 규칙 (웹 1024 이상)

근거: 기준 국내 증권 앱 웹 11화면 실측(2026-10-30, 1920 · 1280 폭, 계산 스타일) + 공개 2차 실측 대조. 값 표와 화면 대응은
`FE-REQ-047`(틀) · `FE-REQ-048`(홈) · `FE-REQ-049`(상세). **문서 · 코드 · 커밋에 기준 서비스 이름을 쓰지 않는다.**

> 표에 "실측"은 우리가 직접 잰 값, "2차"는 공개 실측 자료와도 맞은 값이다. 둘 다 아닌 값을 새로 지어내지 않는다 —
> 필요하면 다시 재고 이 표에 행을 더한다.

### 1-1. 카드 판 — 휴대폰 같은 느낌(2026-11-20 `FE-REQ-076`, 투자 zone 제외)

사용자 "데스크톱도 이런 느낌으로" · "틀은 두고 부품만". 위 틀(레일 · 머리 · 패널 자리 · 사이드 312 · 표)은 그대로, 본문 안만 휴대폰 부품(`mobile-design.md` §2)의 데스크톱 판.

| 항목 | 값 | 어디 |
|---|---|---|
| 판 | `PageFrame surface="cards"` — 패널 자리를 grey100 `#F2F4F6` 으로 · 사이드 왼쪽 선 없음 | 홈 · 저축 · 가계부 · 알림 · 설정 · 하위 화면(목표 만들기 · 상세 · 가계부 하위 7) · 금융 팁(2026-11-20 2단계) |
| 카드 | 흰 · 모서리 20 · 안쪽 20 × 24 · 선 · 그림자 0 — `@repo/web-shared/ui/surface.css` `card`. 판 위 공용 `panel` 도 저절로 이 모양. 사이드 직계 자식 하나 = 카드 하나(안쪽 16) | 묶음마다 |
| 아이콘 판 | 44 · 모서리 12 · grey100 + 3D 28(`iconTile`) · 사이드 행 36 · 24(`SideRow` 가 붙인다) | 카드 머리 · 목록 행 |
| 금액 카드 | `SummaryBand icon` — 아이콘 판 + 금액 24/700 위 · 이름 아래 · 나머지 타일 오른쪽 | 저축 · 가계부 요약 |
| 회색 알약 | grey100 · 모서리 12 · 32 · 13/600 — 다음 행동 한 단어(`@repo/core/labels` `HOME_CARD_PILL_LABEL`) | 홈 도메인 카드 |
| 목록 행 판 | 40 · 모서리 12(전 32 · 8) | 목표 · 지출 행 |
| 폼 상자 | 기능 폼 · 묻는 카드는 `formBox`(옅은 면 · 선 · 12) · 흰 선 카드는 `lineCard` 를 조합한다 — **판이 자리를 보고** 판 위 = 흰 카드, 카드 · 패널 · 사이드 묶음 안 = 선 없는 정보 상자(`PageFrame.css`). 같은 값을 기능에 복사하지 않는다 | 하위 화면 · 팁 |
| 대기 칸 | 판 위 `Skeleton` = 흰 카드 모양(표지 `data-skeleton` — 판과 같은 grey100 이라 안 보였다) · 카드 안은 회색 | 판 전체 |

- 카드 안에 카드를 두지 않는다 — 카드 안 상자는 정보 상자 면만(선 0)
- 투자 zone 은 판을 쓰지 않는다(사용자 2026-11-20) — 표 · 띠가 주인공인 화면은 `surface="white"` 그대로

## 4. 화면 패턴

| 패턴 | 규칙 |
|---|---|
| 목록 + 미리보기 | 같은 패널 안 왼쪽 표 · 오른쪽 미리보기 칸. 선택은 주소에(`?symbol=` · `?goal=`) |
| 요약 띠 | 위 띠 = 타일 격자 + 오른쪽 정보 상자. 무엇을 보일지는 서버가 정한다 |
| 상세 | 머리 2줄(≤ 88) → 알약 탭 → 패널 격자 + 오른쪽 고정 열 360 — 틀은 `@repo/web-shared/ui` `DetailTabs`(`?view=` · 첫 탭 개요 = 차트 + 한 장 패널 · 고정 열은 1280 미만 탭) · 면 `detailPanel`(2026-11-19 `FE-REQ-049`) |
| 뒤로 | 상세 머리 첫 칸에 뒤로 버튼 + 이동 경로 한 줄. 목록의 탭 · 필터는 주소에 있어 돌아오면 같은 자리 |
| 탭 제목 | 상세는 `{가격} {등락률} \| {이름}` 을 실시간으로(초당 1회까지) — 서버 HTML 제목은 그대로 |
| 빈 상태 | 패널 높이를 지키는 한 줄 안내. 빈 카드를 쌓지 않는다. **그래프 자리는 지우지 않고 회색 "예시"** (사용자 2026-11-26) |
| 대시보드(셸 홈) | 숫자 띠(카드 하나 안 타일) → 격자 세 줄, 줄마다 넓음 2 + 좁음 1 · 열 수는 본문 칸 폭 컨테이너 쿼리 · **같은 줄 카드 아래 끝 = 같음 · 사이드 첫 카드 위 끝 = 본문 첫 카드 위 끝**(재서 0px — 눈으로 판정하지 않는다). 기록 없이도 차는 블록(시장 · 코치 브리핑 · 증시 일정)을 섞는다 · 무엇을 보일지는 BFF(`FE-REQ-048` FR-14~18) |
| 금액 요약 띠(돈 관리) | 타일 가로 · 주인공 하나만 18/700 · 나머지 13/600 — 저축 · 가계부 · 홈(`FE-REQ-060` · `048`) |
| 날짜 묶음 목록 | 묶음 머리 = 날짜 · 그날 합(12/500) · 행 = 왼쪽 아이콘 판 32 · 이름 · 금액 오른쪽(공개 디자인 시스템의 목록 행 세 칸) |
| 모바일 | **이 규칙이 아니다** — 휴대폰 PWA `/m`(`ADR-012`)은 `screen-mobile.md`(한 열 · 하단 고정 CTA · 바텀 시트) |

## 5. 하지 않는 것

- 휴대폰 화면을 가로로 늘린 배치(한 줄씩 쌓인 카드 · 화면 폭 균등 분배 통계)
- 화면마다 다른 머리 · 뒤로 링크 · 프로필 위치
- 같은 숫자 두 번(판단 카드 성적 = 해설 칸 성적)
- 그림자 카드 · 큰 보라 버튼을 정보 영역에 — 주 버튼은 화면당 하나
- 기존 결정 뒤집기: 표 선택 보라 금지 · 차트 색 · 등락 색 · 가격 깜빡임 없음 · 종목 아이콘 · 셰브론(`respect` 규칙은 메모리 · REQ)
