# 휴대폰 마이크로 인터랙션 규칙 (`/m`)

근거: 사용자 2026-11-20 "모바일이니까 마이크로 인터랙션이 더 많아야겠지". 모든 움직임의 공통 원칙(토큰 · transform/opacity 만 · 줄인 모션 ·
수익 축하 금지)은 `motion.md` — 이 문서는 휴대폰에서 **어디에 무엇을 더하는지**만 정한다. 배치 · 부품은 `mobile-design.md`.

## 1. 누름 — 손가락에 바로 답한다

| 무엇 | 반응 | 어디서 정한다 |
|---|---|---|
| 화면 안 누를 수 있는 것 전부(링크 · 버튼 · 접힘 머리 · 세그먼트 칸 · 시트 안 버튼) | 누르는 동안 `scale(0.97)` · 놓으면 복귀 | `MobileShell.css` `:where(…)` 전역(낮은 우선 — 부품 값이 이긴다) |
| 카드 한 장이 통째로 링크(홈 도메인 카드 · 두 칸 타일) | `scale(0.98)` — 큰 면은 덜 줄인다 | 부품 스타일 `...press` · `pressedCard` |
| 목록 행(바로가기) | `scale(0.97)` + 면이 grey50 로 | 부품 스타일 |
| 하단 탭 칸 | `scale(0.94)` | `MobileShell.css` `tab` |

- 길이 `duration.instant`(0.12s) · 곡선 `easing.enter` — 숫자를 컴포넌트에 쓰지 않는다. 묶음은 `layout/mobile/MobilePress.css.ts`(`press` · `pressed` · `pressedCard`)
- `-webkit-tap-highlight-color: transparent` — 브라우저 회색 덮개 대신 위 반응을 쓴다
- 줄인 모션(`prefers-reduced-motion: reduce`)이면 전환을 끈다(누른 상태는 순간 바뀜)

## 2. 자리 바뀜 — 고른 것이 보이게

| 무엇 | 반응 |
|---|---|
| 하단 탭 고른 칸 | 회색 알약 면이 `duration.base` 로 바뀌고 아이콘이 `scale(1.08)` 로 한 번 자리 잡는다 |
| 세그먼트 · 기간 칩 | 디자인 시스템 컴포넌트가 이미 가진 전환 그대로 — 화면에서 다시 만들지 않는다 |
| 바텀 시트 | 아래에서 올라오고(`BottomSheet` 기본) 뒤로 · 바깥 누름 · Esc 로 닫힌다 |

## 3. 등장 — 카드가 차례로

- 탭 화면 카드 · 홈 도메인 카드 · 타일 · 바로가기 카드는 `@repo/ui/enterReveal`(8px 아래에서 떠오름 · 형제 차례 · 8개 넘으면 한꺼번에)
- 등장은 **처음 그릴 때 한 번**. 숫자가 바뀔 때 카드를 다시 띄우지 않는다
- 서버 HTML 에 빈칸을 만들지 않는다 — `enterReveal` 은 CSS 애니메이션이라 JS 없이도 끝 상태에 선다(`motion.md` §6)

## 4. 하지 않는 것

- 레이아웃 속성(높이 · 폭 · 위치) 애니메이션 · 스크롤에 묶인 움직임(`performance.md`)
- 가격 · 손익 숫자 깜빡임 · 축하 효과(`motion.md` §8) — 등락은 색 + 부호로만
- 무한 반복(로딩 표시 제외) · 한 화면에 동시에 도는 장면 둘 이상
- 진동(haptics) API — 웹에서 기기마다 다르고 iOS 사파리가 막는다. 쓰려면 이 표에 행을 먼저 더한다
