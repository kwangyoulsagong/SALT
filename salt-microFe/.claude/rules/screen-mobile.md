# 모바일 화면 규칙 (RN 앱 · 앱 웹뷰)

근거: 기준 금융 앱의 **공개 디자인 시스템 문서**(모바일 파운데이션 · 컴포넌트 · 소비자 UX 가이드 · 라이팅 원칙, 2026-10-30 조사).
값이 공개된 것만 옮겼다. 공개되지 않은 값(내비 바 높이 · 버튼 px · 간격 스케일 · 다크 hex)은 **지어내지 않고** §6 에 남긴다.
문서 · 코드 · 커밋에 기준 서비스 이름을 쓰지 않는다. 웹 768 미만은 안내만 보인다(`FE-REQ-043`) — 이 규칙의 대상은 `apps/mobile` 과 앱 웹뷰다.

## 1. 글자 — 토큰 이름으로, 고정 px 로 쓰지 않는다

| 토큰 | 크기/줄 | 용도 |
|---|---|---|
| `t1` | 30/40 | 매우 큰 제목(금액 한 줄) |
| `t2` | 26/35 | 큰 제목 |
| `t3` | 22/31 | 화면 제목 |
| `t4` | 20/29 | 시트 제목 · 섹션 큰 제목 |
| `t5` | 17/25.5 | 본문 |
| `t6` | 15/22.5 | 작은 본문 · 설명 |
| `t7` | 13/19.5 | 안 읽어도 되는 글(출처 · 시각) |

- 굵기 5단: Light · Regular · Medium · Semibold · Bold
- **기기 글자 크기를 따른다** — 160% · 200% 에서 배치가 깨지지 않게(금액은 잘리지 않고 줄바꿈, 시트 · 목록 머리는 세로로 쌓임). 토큰 값을 컴포넌트에 숫자로 박지 않는다
- 숫자는 고정폭 숫자

## 2. 색

| 이름 | 값 |
|---|---|
| grey50 · 100 · 200 · 300 · 400 | `#F9FAFB` · `#F2F4F6` · `#E5E8EB` · `#D1D6DB` · `#B0B8C1` |
| grey500 · 600 · 700 · 800 · 900 | `#8B95A1` · `#6B7684` · `#4E5968` · `#333D4B` · `#191F28` |
| 바탕 | 화면 `#FFFFFF`, 회색 바탕 = grey100 |
| 위험 | `#F04452` (오류만 — 하락 표시와 섞지 않는다) |

- 우리 브랜드 주색은 `tokens.brand.primary`(`#7949FF`) — 주 버튼 · 선택 표시. 상승 · 하락 색은 기존 토큰 그대로
- 다크 모드는 기기 설정을 따른다. 그래픽은 두 모드에서 다 보이는 중간 명도
- 우리 웹 토큰 `#191F28`(1단) · `#8B95A1`(라벨)은 위 회색 단계와 같다 — 앱은 회색 단계 이름으로 쓴다

## 3. 배치

| 항목 | 규칙 |
|---|---|
| 좌우 여백 | 목록 행 20(좁게) · 24(기본) |
| 목록 행 세로 여백 | 8 · 12(기본) · 16 · 24 — 행 높이는 고정하지 않고 여백과 내용이 정한다 |
| 목록 왼쪽 그림 | 원 40 · 사각 52(종목 아이콘은 원 40) |
| 목록 구분선 | 기본 왼쪽 들여쓴 선, 이어진 묶음은 선 없음 |
| 화면 제목(Top) | `t3` Bold(22) 또는 28 Bold, 부제 `t5`/`t6`/`t7`, 위아래 간격 24 |
| 섹션 머리 | 제목 `t5`(작게 `t7`) grey800, 오른쪽 글 grey700 · 화살표 grey400, 제목 폭 최대 2/3 |
| 아이콘 | 24~40, 한 자리에 하나 |

## 4. 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| 내비 바 | 상단 고정. 왼쪽 뒤로 + 제목, 오른쪽 더보기 또는 닫기 하나(모노톤) |
| 하단 고정 CTA | 화면 맨 아래 고정, 버튼 하나 또는 둘(좌 보조 · 우 주). 긴 스크롤 · 키보드 입력 중에도 닿는다 |
| 버튼 | 크기 4단(small~xlarge, 기본 xlarge) · 채움/옅음 · 주/어둠/위험/밝음 · 인라인/블록/전체 |
| 탭 | 4개까지 고정 폭, 그 이상은 가로 스크롤. 새 소식은 점 하나 |
| 하단 탭바 | 우리는 3탭(홈 · 코치 · 자산) — 늘리지 않는다(`fsd-pages.md`) |
| 바텀 시트 | 제목 `t4` · 설명 `t6` · 본문과 CTA 사이 34. 바깥 누름 · 뒤로로 닫힌다. 키보드가 열리면 시트도 올라간다 |
| 배지 | 크기 xsmall~large · 채움/옅음 — 색만으로 뜻을 전하지 않는다(글자 병기) |
| 다이얼로그 | 왼쪽 버튼은 "닫기"("취소"는 진행 중인 일을 취소하는 것으로 읽힌다) |

## 5. 쓰기 · 움직임

- 모든 문구 해요체 — 오류 문구도
- 능동형("됐어요" → "했어요") · 긍정형 우선, 부정형은 꼭 필요할 때만
- 버튼만 읽어도 누른 뒤 일을 알 수 있게. 화면 설명을 버튼에 되풀이하지 않는다
- 빈자리를 채우려는 문장 · 전문 용어 · 은어 금지. 지금 필요한 한 가지만
- **압박 · 손실 공포로 행동을 이끌지 않는다** — 제품 공통 수용 기준 4(명령형 매매 지시 0)와 같은 선
- 장식 효과(입자 · 과한 그라데이션 · 의미 없는 효과) 금지, 로딩 그림은 실제로 기다릴 때만, 오류가 아닌데 느낌표 아이콘 금지
- 첫 진입에 동의 · 광고 시트를 띄우지 않는다
- 움직임 값은 `motion.md` 토큰

## 6. 공개되지 않아 정하지 않은 것 — 지어내지 않는다

내비 바 높이 · 버튼 · 탭 · 입력칸의 높이 · 모서리 px · 간격 스케일 · 다크 모드 hex · 상승/하락 색 토큰 매핑 · 숫자 · 금액 표기 규칙 ·
모션 길이. 필요해지면 실기기 측정(`performance-rn.md` 기준 기기)으로 정하고 이 절에서 표로 옮긴다.
