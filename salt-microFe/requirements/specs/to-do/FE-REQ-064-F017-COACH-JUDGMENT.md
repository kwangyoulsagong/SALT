## FR

| FR | 내용 | 단계 |
|---|---|---|
| FR-1 | **관망 판단** — 관망도 판단 이름 + "규칙이 신호를 내지 않았어요" + 관측 한 줄(문턱에 가까운 둘 — 서버 `summaryLine`) · 성적 한 줄(지금 그대로) · 관측 표(펼치면 — 항목 · 값 · 문턱 · 거리, 색 + 부호) | 1 |
| FR-2 | **보류 문구 정정** — "근거가 부족해 … 표본 N건 · 정상 동작이에요"를 사유별 사실 문장으로(`entities/coach/model/messages.ts`): 재료 멈춤 "{항목}을 {시각} 뒤로 못 받았어요" · 표본 "채점된 판단 {n}/{min}건" · 열지 않은 모드(지금 문구 유지) | 1 |
| FR-3 | **짧게 먼저 · 해설 늘 열림** — 첫 화면은 판단 + 한 줄 + 성적. [자세히] 펼치면 관측 표 · AI 해설(문장마다 `[n]` 인용 → 누르면 그 관측 · 사실로) · 실패 사례. 해설 생성 중 "정리하는 중" · 실패면 템플릿 문장(AI 표시 없음) | 2 |
| FR-4 | **물어보기** — 상세 판단 카드 아래 한 줄 입력 · 답 스트리밍(SSE) · AI 표시 · 사실표 밖이면 서버 문구. 비로그인 · 비소유자(국내) 자리 0 | 3 |
| FR-5 | 상태 — 로딩 · 실패 줄 · 만료 세션 · 1024~1600 넘침 0 · 390 웹뷰 한 열 · axe 새 요소 0 · 문구 grep(확신 · 명령형 · 인과 단정 0) | 전 단계 |
