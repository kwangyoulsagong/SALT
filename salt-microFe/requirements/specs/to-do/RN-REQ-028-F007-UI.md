## Summary

F007의 UI는 **화면이 아니라 상태**다. 새 탭이 생기지 않는다. 대신 앱 전체에 걸쳐 네 가지 상태가 추가된다: **알림 권한**, **알림 설정**, **버전 차단**, **오프라인**.

## 화면 목록

| 화면 | 위치 | 성격 |
|---|---|---|
| 알림 권한 안내 | 홈 상단 한 줄 | 배너 (닫으면 다시 안 뜸) |
| 알림 설정 | 자산 탭 > 설정 > 알림 | 스택 화면 |
| 업데이트 필요 | 전체 위 모달 | **진행 차단** |
| 오프라인 배너 | 모든 화면 상단 | 전역 |
| 알림 목록 | 홈 > 종 아이콘 | 스택 화면 |

**새 탭이 없다.** IA는 3탭(홈/코치/자산) 그대로다.

## Requirements

### A. 알림 권한

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-1 | 앱 첫 실행에 **바로 권한을 묻지 않는다.** 온보딩 완료 후, 홈에서 맥락과 함께 묻는다 | Must |
| FR-2 | 요청 전 **왜 필요한지** 한 줄로 설명한다 — "세금 마감 알림을 받으려면 알림을 허용하세요" | Must |
| FR-3 | 거부하면 홈에 **한 줄 안내만** 남긴다. **반복해서 묻지 않는다** | Must |
| FR-4 | 안내를 닫으면 다시 뜨지 않는다. 설정 화면에서만 다시 켤 수 있다 | Must |
| FR-5 | 거부 상태에서 설정 화면은 **OS 설정으로 가는 버튼**을 제공한다 | Must |
| FR-6 | 권한 상태를 앱 포그라운드 복귀마다 재확인한다 | Must |

### B. 알림 설정

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-10 | 알림 타입 **2개**(세금 마감 / 지표 갱신)만 보여준다 | Must |
| FR-11 | 세금 마감 토글 아래에 **"끄더라도 마감 하루 전 알림은 보냅니다"** 를 명시한다 | Must |
| FR-12 | 이 문구가 `alwaysOnExceptions` 응답에서 나오게 한다. **하드코딩하지 않는다** | Must |
| FR-13 | 토글 변경은 즉시 저장하고 실패 시 되돌린다 | Must |
| FR-14 | 등록된 기기 목록을 보여준다 (모델·마지막 접속). **토큰은 보여주지 않는다** | Should |
| FR-15 | 기기 등록 해제 버튼을 제공한다 | Should |

### C. 버전 게이트

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-20 | `426`을 받으면 **전체 위 모달**로 업데이트 안내를 띄운다 | Must |
| FR-21 | 모달은 **닫을 수 없다.** 백 버튼·제스처로 빠져나갈 수 없다 | Must |
| FR-22 | 서버가 준 `message`를 그대로 표시한다 | Must |
| FR-23 | TestFlight / Play 내부 테스트로 가는 버튼을 둔다 | Must |
| FR-24 | **로그아웃 버튼을 남긴다.** 계정을 바꿔야 할 수도 있다 | Must |
| FR-25 | OTA로 해결 가능한 경우(런타임 버전만 낮음)는 **"업데이트 확인 중"** 후 자동 재시작한다 | Should |

### D. 오프라인

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-30 | 오프라인이면 **상단에 배너** — "오프라인 · 9월 10일 08:12 기준" | Must |
| FR-31 | 시각은 BFF의 `lastUpdatedAt`을 쓴다 | Must |
| FR-32 | 금액 화면(청구서·세금·포지션)에 배너가 **반드시** 붙는다 | Must |
| FR-33 | 쓰기 액션(적립 완료·평가·CSV 업로드)은 **disabled**다 | Must |
| FR-34 | 코치 탭은 **스트림을 시작하지 않고 입력을 보존**한다 | Must |
| FR-35 | 온라인 복귀 시 배너가 사라지고 자동 갱신된다 | Must |
| FR-36 | **"나중에 자동으로 보냈습니다" 류의 안내가 0건**이다. 큐가 없기 때문 | Must |

| ID | 요구사항 | 우선순위 |
|---|---|---|

| FR-43 | **목록에 금액이 0건**이다 | Must |

### F. 금지

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-50 | **탭이 4개가 되지 않는다** | Must |
| FR-51 | `MovableGrid`를 모바일에 만들지 않는다 | Must |
| FR-52 | **잠금화면 알림에 금액이 노출되지 않는다** (본문은 서버가 만들지만 앱이 로컬 알림을 만들지 않는 것으로 보장) | Must |
| FR-53 | 스크린샷 방지·루팅 탐지를 하지 않는다 | Must |

| FR-55 | 앱이 로컬 알림(local notification)을 스케줄하지 않는다. **발송은 서버만** | Must |

## UX 상태

- **권한 미결정**: 홈에 안내 한 줄
- **권한 거부**: 한 줄 안내(닫으면 사라짐) + 설정에서 OS 설정 링크
- **버전 차단**: 닫히지 않는 모달. 로그아웃만 가능
- **오프라인**: 전역 배너 + 쓰기 disabled
- **알림 없음**: 빈 상태 문구
- **등록 실패**: **사용자에게 알리지 않는다.** 앱은 정상 동작하고 푸시만 안 온다. 설정 화면에서만 "이 기기가 등록되지 않았습니다 · 다시 시도" 노출

## Acceptance Criteria

- [ ] **앱 첫 실행에 권한을 바로 묻지 않는다**
- [ ] 권한 요청 전 이유가 표시된다
- [ ] **거부 후 반복해서 묻지 않는다**
- [ ] 설정 화면에 OS 설정 링크가 있다
- [ ] 권한 상태가 포그라운드 복귀마다 재확인된다
- [ ] **알림 타입이 2개만 보인다**
- [ ] **"끄더라도 D-1은 보냅니다"가 표시되고 서버 응답에서 나온다**
- [ ] 토글 저장 실패가 되돌려진다
- [ ] 기기 목록에 토큰이 표시되지 않는다
- [ ] **`426`에서 닫을 수 없는 모달이 뜬다**
- [ ] 모달에 로그아웃 버튼이 있다
- [ ] 서버 `message`가 그대로 표시된다
- [ ] **오프라인 배너에 `lastUpdatedAt` 기준 시각이 표시된다**
- [ ] 금액 화면에 배너가 반드시 붙는다
- [ ] **오프라인에서 쓰기 액션이 disabled다**
- [ ] 코치가 오프라인에서 입력을 보존한다
- [ ] **"자동으로 보냈습니다" 류 안내가 0건이다**
- [ ] 알림 목록이 종 아이콘으로 진입하고 **탭이 3개 그대로다**
- [ ] **알림 목록에 금액이 0건이다**
- [ ] `MovableGrid`가 모바일에 없다
- [ ] **앱이 로컬 알림을 스케줄하지 않는다**
- [ ] 스크린샷 방지·루팅 탐지가 없다
- [ ] 등록 실패가 사용자를 방해하지 않는다
- [ ] 글꼴 200%에서 배너·모달이 잘리지 않는다
- [ ] iOS·Android 양쪽에서 통과한다

## Open Questions

- 권한을 "온보딩 완료 후 홈에서" 묻는다면, 온보딩을 끝내지 않는 사용자는 영영 못 묻는다. 온보딩 마지막 스텝에 넣는 편이 나은지.
- 업데이트 모달이 닫히지 않으면 서버 게이트 설정 실수 시 전원이 잠긴다. 서버가 fail-open이므로 위험은 낮지만, 앱 쪽 탈출구(디버그 제스처)가 필요한지.
