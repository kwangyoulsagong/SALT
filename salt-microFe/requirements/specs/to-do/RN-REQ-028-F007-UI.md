## Summary

F007의 UI는 **화면이 아니라 상태**다. 새 탭이 생기지 않는다. 대신 앱 전체에 걸쳐 네 가지 상태가 추가된다: **알림 권한**, **알림 설정**, **버전 차단**, **오프라인**.

## 화면 목록

| 화면 | 위치 | 성격 |
|---|---|---|
| 알림 권한 안내 | 홈 상단 한 줄 | 배너 (닫으면 다시 안 뜸) |
| 알림 설정 | **헤더 프로필 → 설정(F006) ④ 알림** — 켜기/끄기 1개 | F006 설정 화면의 한 그룹 (개정 2026-09-21 — D9 · D5) |
| 업데이트 필요 | 전체 위 모달 | **진행 차단** |
| 오프라인 배너 | 모든 화면 상단 | 전역 |
| 알림 목록 | **3탭 공통 헤더 벨**(안 읽은 수 배지) | 스택 화면 — 내용은 F006 (개정 2026-09-21 — FEATURE-006 FR-7 · FR-52) |

**새 탭이 없다.** IA는 3탭(홈/코치/자산) 그대로다.

### 앱 화면 지도 — 2026-09-21 추가 (D6 · D7 · D9)

모바일 화면은 **웹 IA를 그대로** 따른다. 내용의 소유는 각 기능이고, F007은 이 지도가 모바일에서 성립하는지(스택 · 딥링크 · 오프라인)를 책임진다.

| 탭 / 스택 | 화면 | 내용 소유 |
|---|---|---|
| 홈 | **3블록**: ① 총자산 → ② 이번 주 적립 → ③ AI 추천. 그 아래 **기존 목표 카드 · `AnalysisGraph` · `TipsApp`** 그대로 (D6) | F006 FR-10 · F003 · F004 |
| 홈 → push | 적립 상세(`PlanDetailScreen`) · 목표 화면(상단 이번 달 적립 합계) | F003 · F000 |
| 코치 | 대화 + 추천 카드. 코치 리포트는 push (B15) | F004 · F006 |
| 자산 | 세그먼트 **`포지션` / `시장` / `관심 종목`** (D7). 기본 `포지션` | F006 FR-3 |
| 자산 → push | 종목 → **상세 분석 페이지**(F004). 포지션 → 거래 기록 추가 시트 · 거래 목록 | F004 · F006 |
| 헤더 | 프로필 → **설정 한 화면**(적립 기본액 · 밴드 읽기 전용 · 코치 · 알림 · 보유 기록 관리, D9) · 검색 → 상세 분석 · 벨 → 알림 목록 | F006 FR-7 · FR-80 |
| 온보딩 | 초대 코드 → 첫 보유 기록(건너뛰기 가능) → 월 적립액 (B12) | F006 FR-40 · F003 |

|---|---|---|
| FR-80 | **청구서 · 세금 화면, 그 딥링크, 위젯이 앱에 0건**이다. 자산 탭에 `청구서` · `세금` 세그먼트가 없다(ADR-002 · D7) | Must |

## UX 상태

- **권한 미결정**: 홈에 안내 한 줄
- **권한 거부**: 한 줄 안내(닫으면 사라짐) + 설정에서 OS 설정 링크
- **버전 차단**: 닫히지 않는 모달. 로그아웃만 가능
- **오프라인**: 전역 배너 + 쓰기 disabled
- **알림 없음**: 빈 상태 문구
- **등록 실패**: **사용자에게 알리지 않는다.** 앱은 정상 동작하고 푸시만 안 온다. 설정 화면에서만 "이 기기가 등록되지 않았습니다 · 다시 시도" 노출

## Acceptance Criteria

- [ ] **앱 첫 실행에 권한을 바로 묻지 않는다**
- [ ] 권한 요청 전 이유가 표시된다
- [ ] **거부 후 반복해서 묻지 않는다**
- [ ] 설정 화면에 OS 설정 링크가 있다
- [ ] 권한 상태가 포그라운드 복귀마다 재확인된다
- [ ] **알림 설정이 토글 1개이고 F006 경로로 저장된다** (D5 · B21)
- [ ] **"끄더라도 D-1" 문구·세금 알림 배지가 0건이다** (ADR-002)
- [ ] **청구서 · 세금 화면 · 딥링크 · 위젯이 0건이고 자산 탭 세그먼트가 포지션/시장/관심 종목이다** (D7)
- [ ] 홈이 3블록 + 기존 블록이다 (D6)
- [ ] 상세 분석 페이지가 5개 진입점에서 push로 열린다
- [ ] 알림 목록에 읽음 · 모두 읽음이 있고 벨에 안 읽은 수가 있다 (D5)
- [ ] 토글 저장 실패가 되돌려진다
- [ ] 기기 목록에 토큰이 표시되지 않는다
- [ ] **`426`에서 닫을 수 없는 모달이 뜬다**
- [ ] 모달에 로그아웃 버튼이 있다
- [ ] 서버 `message`가 그대로 표시된다
- [ ] **오프라인 배너에 `lastUpdatedAt` 기준 시각이 표시된다**
- [ ] 금액 화면에 배너가 반드시 붙는다
- [ ] **오프라인에서 쓰기 액션이 disabled다**
- [ ] 코치가 오프라인에서 입력을 보존한다
- [ ] **"자동으로 보냈습니다" 류 안내가 0건이다**
- [ ] 알림 목록이 헤더 벨로 진입하고 **탭이 3개 그대로다**
- [ ] **알림 목록에 금액이 0건이다**
- [ ] `MovableGrid`가 모바일에 없다
- [ ] **앱이 로컬 알림을 스케줄하지 않는다**
- [ ] 스크린샷 방지·루팅 탐지가 없다
- [ ] 등록 실패가 사용자를 방해하지 않는다
- [ ] 글꼴 200%에서 배너·모달이 잘리지 않는다
- [ ] iOS·Android 양쪽에서 통과한다

## Open Questions

- 권한을 "온보딩 완료 후 홈에서" 묻는다면, 온보딩을 끝내지 않는 사용자는 영영 못 묻는다. 온보딩 마지막 스텝에 넣는 편이 나은지.
- 업데이트 모달이 닫히지 않으면 서버 게이트 설정 실수 시 전원이 잠긴다. 서버가 fail-open이므로 위험은 낮지만, 앱 쪽 탈출구(디버그 제스처)가 필요한지.
