## Summary

세금 콕핏은 **별도 zone(`apps/web-tax`, 경로 `/tax`)** 이다. 방문 빈도가 낮고 릴리스 이유가 다르고 코드가 무겁다 — zone 3조건을 모두 만족하는 유일한 화면이다(`ADR-001` §3-4).

화면 구성: **D-Day 칩(즉시) → 자산군 카드 3(Suspense) → 손실수확 솔버(버튼) → 증빙 → 면책**.

```
│   "소액주주 양도차익 비과세. 계산 대상 아님."

│   업비트 2020–2026 ✅ / KIS 2022–2026 ✅ / 2026-12-31 시가 스냅샷 ⏳ 2027-01-01 00:10 예약

├─ 계산 전제 (lawConfigShown 전체 표)
└─ 면책 문구 (고정)
```

## Requirements

### A. zone과 진입

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-1 | `apps/web-tax` zone. `assetPrefix: '/tax-static'`, 경로 `/tax/**` | Must |
| FR-2 | 홈의 `세금 D-Day` 블록과 자산 탭의 세금 세그먼트에서 진입한다. 그 링크는 **`<a>`** 다(zone 경계) | Must |
| FR-3 | zone 진입 링크에 **로딩 상태**를 준다. hard navigation이므로 체감 지연이 있다 | Must |
| FR-4 | zone은 `apps/web/src/**`를 import하지 않는다. 공유는 `packages/*`로만 | Must |

### B. D-Day는 즉시 렌더한다

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-10 | D-Day 칩은 **Suspense 밖**이다. `GET /api/app/tax/deadlines`(100ms)로 먼저 받는다 | Must |
| FR-11 | `daysRemaining`을 **클라이언트에서 재계산**한다. 서버 값은 캐시일 수 있어 하루 틀린다 | Must |
| FR-12 | 미국주식 칩에 **마지막 매도일(12/30)과 권고일(12/29)을 둘 다** 표시한다 | Must |
| FR-13 | 국내주식 칩은 `taxable: false`이므로 **"비과세"** 를 표시하고 D-Day를 표시하지 않는다 | Must |
| FR-14 | **D-14 이내면 칩을 강조**한다. **압박 문구 금지** — "서둘러 파세요" ❌ / "연내 결제 기준 마감일: 12/29" ⭕ | Must |
| FR-15 | `aria-label`로 "미국주식 2026년 12월 29일까지 111일 남음" | Must |

## UX 상태

- **Loading**: D-Day 즉시 렌더 + 자산군 카드만 스켈레톤
- **Empty (계좌 미연결)**: "거래내역을 연결하면 세금을 계산할 수 있습니다." → 온보딩. **D-Day는 그래도 보여준다**
- **Empty (보유 0건)**: D-Day + 증빙만
- **Warning (원장 불일치)**: "취득가액이 정확하지 않아 세금 계산도 부정확할 수 있습니다."
- **Warning (환율 결측)**: 종목 행에 `환율 없음` 배지
- **Warning (lot 재계산 중)**: "취득가액을 다시 계산하고 있습니다" + 마지막 값 표시
- **Warning (D-14 이내)**: 칩 강조. 압박 문구 없음
- **Error (스냅샷 실패)**: 적색 배너 + 수동 입력 폼
- **Optimistic update**: **없음.** 금액 화면이다

## Acceptance Criteria

- [ ] `/tax`가 `apps/web-tax` zone에서 서비스되고 정적 자산이 `/tax-static/_next/...`다
- [ ] 홈·자산 탭에서 세금으로 가는 링크가 `<a>`다
- [ ] `apps/web-tax`가 `apps/web/src/**`를 import하지 않는다
- [ ] **D-Day 칩이 자산군 카드보다 먼저 보인다** (네트워크 스로틀 확인)
- [ ] `daysRemaining`이 클라이언트에서 재계산된다
- [ ] 미국주식 칩에 마지막 매도일과 권고일이 둘 다 있다
- [ ] 국내주식 칩이 "비과세"이고 D-Day가 없다
- [ ] D-14 이내에서 칩이 강조되고 **압박 문구가 0건**이다
- [ ] 블록 하나 실패 시 그것만 에러이고 나머지가 정상이다
- [ ] 금액 블록 실패 시 `0`이 0건이다
- [ ] 스켈레톤 높이가 실제 카드와 같다 (CLS 측정)
- [ ] 취득가액 2방식이 나란히 표시되고 권고 표현이 0건이다
- [ ] 3열에 추천 배지·강조가 0건이다
- [ ] 모바일 폭에서 3열이 세로 스택된다
- [ ] 슬라이더가 키보드로 조작되고 숫자 직접 입력이 된다
- [ ] **슬라이더 조작이 60fps이고 서버 요청이 0건이다**
- [ ] 슬라이더를 놓으면 서버 대조가 일어난다
- [ ] 손익분기 연말시가가 표시된다
- [ ] 연말시가 < 취득가액에서 스텝업 절세액이 0원으로 표시된다
- [ ] 솔버가 버튼으로 시작하고 첫 페인트에 포함되지 않는다
- [ ] 후보 3개에 추천 배지가 0건이다
- [ ] 부분 매도 수량이 표시된다
- [ ] `isOptimal: false`에서 근사 표시가 나온다
- [ ] `caveats`에 재매수 취득가액 경고가 있고 **재매수 권유 문구가 0건**이다
- [ ] 매도 유도 CTA가 0건이다
- [ ] **달러 손실 / 원화 이익 종목이 경고로 표시된다**
- [ ] 매도 환율에 가정값 표시가 있다
- [ ] 환율 결측 종목에 배지 + 계산 제외 표시가 있다
- [ ] 법령 상태 4종이 각각 렌더되고 `deferred`에서도 계산기가 동작한다
- [ ] **`lawConfigShown` 전체가 표로 노출된다**
- [ ] 스냅샷 실패 시 적색 배너 + 수동 입력 폼이 나온다
- [ ] ZIP URL 만료 안내가 있다
- [ ] **면책 문구가 하단 고정**이다
- [ ] 375px에서 body 가로 스크롤이 0이다
- [ ] 스크린리더로 D-Day·3열·계산 전제가 낭독된다
