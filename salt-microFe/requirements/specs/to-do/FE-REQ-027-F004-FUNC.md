## Summary

F004의 기능 규칙은 거의 전부 **"하지 않는 것"** 이다. 게이트를 우회하지 않고, 금액·점수를 계산하지 않고, 확신 표현을 쓰지 않고, 주문을 실행하지 않는다.

## 렌더 게이트 — 컴포넌트가 강제한다

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-1 | 게이트 판정은 **서버가 준 `renderable`을 그대로 쓴다.** 프론트가 다시 판정하지 않는다 | Must |
| FR-2 | 다만 **방어적으로 재확인**한다: `renderable === true`인데 `signalTrackRecord`가 null이거나 `failureCases`가 비면 **렌더하지 않고 개발 로그에 남긴다.** 계약 위반이다 | Must |
| FR-3 | 게이트 로직을 `entities/coach/lib/renderGate.ts`에 순수 함수로 둔다 | Must |
| FR-4 | **우회 prop·플래그·환경변수를 만들지 않는다** | Must |
| FR-5 | `blockedReason` 3종을 i18n 키로 매핑한다. 매핑 없으면 일반 문구로 폴백하되 개발 로그에 남긴다 | Must |
| FR-6 | `disclaimer`가 없으면 **화면 전체를 렌더하지 않는다** | Must |
| FR-7 | `scoreNote`가 없으면 **점수를 렌더하지 않는다** | Must |

## 계산하지 않는다

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-10 | **점수를 계산하지 않는다.** 서버 값 표시만 | Must |
| FR-11 | **승률·평균수익·MDD를 계산하지 않는다.** 서버 값 표시만 | Must |
| FR-12 | **`distancePct`를 계산하지 않는다.** 서버가 준다 | Must |
| FR-13 | **preflight 결과를 계산하지 않는다.** 입력을 서버에 보내고 결과를 받는다 | Must |
| FR-14 | 표시 포맷(퍼센트·부호·통화)만 한다 | Must |
| FR-15 | `staleHours`는 **서버 값을 쓴다.** 클라이언트 시계로 재계산하면 시계가 틀린 기기에서 배지가 잘못 뜬다 | Must |

## 문구 검수 — 이 기능의 최대 위험

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-20 | 사용자 문구는 전부 `shared/i18n`에 있다 | Must |
| FR-21 | **금지 표현 검사**: "확실" · "무조건" · "보장" · "100%" · "목표주가" · "예상 수익률" · "당신은" · "패닉셀러" · "실수" · "잘못" · "점수가 높으니" | Must |
| FR-22 | 서버 `factCode`·`conditionCode`·`reasonCode`·`blockedReason`을 i18n 키로 매핑한다 | Must |
| FR-23 | **매핑 없는 코드를 원문으로 노출하지 않는다** | Must |
| FR-24 | 행동 기록 문구를 **사실 서술로만** 만든다. 인격 평가 0건 | Must |
| FR-25 | LLM 해설(`explanation.text`)은 **서버가 후처리한 것**이다. 프론트가 다시 검사하지 않되, **개발 환경에서 금지 표현 스캔 경고**를 낸다 | Should |
| FR-26 | 익절 가격 문구에 "목표주가"·"예상"을 쓰지 않는다. **"내 규칙 기반 가격"** 임을 명시 | Must |

## 주문을 실행하지 않는다

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-30 | **"주문하기"·"매수하기"·"매도하기" 버튼을 만들지 않는다** | Must |
| FR-31 | preflight 결과 끝에 **"업비트/증권사에서 직접 주문하세요"** 를 표시한다 | Must |
| FR-32 | 거래소 딥링크·외부 링크를 **만들지 않는다.** 편의로 보이지만 주문 유도로 읽힐 수 있다 | Must |
| FR-33 | preflight에 **차단·게이트 로직을 넣지 않는다.** 상한 초과여도 결과를 보여준다 | Must |

## 쿨다운

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-40 | 재생성 쿨다운은 **서버가 판정**한다. 프론트가 타이머를 신뢰하지 않는다 | Must |
| FR-41 | `generation-status`의 `retryAfterSeconds`로 버튼 상태와 남은 시간을 표시한다 | Must |
| FR-42 | **로컬 타이머로 카운트다운**하되, 0이 되면 `generation-status`를 재조회해 확인한다 | Must |
| FR-43 | 429를 받으면 `retryAfterSeconds`로 타이머를 갱신한다. 오류 토스트를 띄우지 않는다 | Must |
| FR-44 | 재생성 mutation은 **재시도하지 않는다** | Must |
| FR-45 | `generate`가 202를 주면 **완료를 폴링**한다. `generation-status` 또는 추천 재조회 | Must |
| FR-46 | 폴링에 **중단 조건**: 완료 · 실패 · 언마운트 · 최대 횟수(15회 = 30초) | Must |

| FR-53 | mutation 재시도 0회 | Must |
| FR-54 | 이미 남긴 피드백이 있으면 그 상태를 표시하고 **변경 가능**하게 한다(upsert) | Must |

## 상태 관리

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-60 | 조회는 **서버 컴포넌트**. React Query는 mutation·폴링·preflight에만 | Must |

| FR-62 | 성향 설정 저장 후 **라우트 재검증**(`router.refresh()`). 성향이 점수에 영향한다 | Must |
| FR-63 | 낙관적 갱신은 **피드백만** | Must |
| FR-64 | 선택된 종목·모드를 URL 쿼리로 유지한다 | Should |

## Acceptance Criteria

- [ ] 게이트 판정이 서버 `renderable`을 쓴다
- [ ] **`renderable: true`인데 3종 중 하나가 없으면 렌더하지 않고 개발 로그에 남긴다**
- [ ] 게이트가 순수 함수로 있다
- [ ] **우회 prop·플래그·환경변수가 0건이다**
- [ ] `blockedReason` 3종이 i18n 키로 매핑된다
- [ ] `disclaimer` 없으면 화면이 렌더되지 않는다
- [ ] `scoreNote` 없으면 점수가 렌더되지 않는다
- [ ] **프론트에 점수·승률·MDD·`distancePct`·preflight 계산 코드가 0건이다**
- [ ] `staleHours`가 서버 값이다 (클라이언트 재계산 0건)
- [ ] 사용자 문구가 전부 `shared/i18n`에 있다
- [ ] **금지 표현 검사가 동작한다** (11개 표현)
- [ ] 서버 코드 4종이 i18n 키로 매핑된다
- [ ] 매핑 없는 코드가 원문으로 노출되지 않는다
- [ ] 행동 기록에 인격 평가 문구가 0건이다
- [ ] 개발 환경에서 LLM 해설 금지 표현 스캔 경고가 나온다
- [ ] 익절 문구에 "목표주가"·"예상"이 0건이다
- [ ] **"주문하기"·"매수하기"·"매도하기" 버튼이 0건이다**
- [ ] preflight 끝에 "직접 주문하세요"가 있다
- [ ] **거래소 딥링크·외부 링크가 0건이다**
- [ ] preflight에 차단 로직이 0건이다
- [ ] 쿨다운이 서버 판정이고 로컬 타이머가 0이 되면 재조회한다
- [ ] 429가 오류 토스트가 아니라 타이머 갱신이다
- [ ] 재생성 mutation 재시도가 0건이다
- [ ] `generate` 202 후 폴링이 동작하고 **중단 조건 4개가 있다**
- [ ] `[도움 안 됨]`이 사유 선택을 띄우고 사유 없이 전송되지 않는다
- [ ] 피드백이 낙관적 갱신이고 실패 시 되돌아간다
- [ ] 이미 남긴 피드백을 변경할 수 있다
- [ ] 조회가 서버 컴포넌트에서 일어난다
- [ ] preflight가 디바운스되거나 버튼으로 실행된다
- [ ] 성향 저장 후 라우트가 재검증된다
- [ ] 낙관적 갱신이 피드백만이다
- [ ] `degradedFields` 블록만 에러 상태다
- [ ] 성적표·실패이력 실패가 에러로 표시되지 않는다

## Open Questions

- FR-2(방어적 재확인)가 **서버를 불신하는 코드**다. 계약 테스트가 있으면 불필요할 수 있지만, **게이트 우회가 가장 위험한 실패**이므로 이중 방어가 정당하다고 본다.
- LLM 해설을 프론트에서 다시 검사할지(FR-25). **서버가 후처리하므로 중복**이지만 개발 중 발견 가치가 있다 → 개발 환경 경고만.
- preflight를 디바운스할지 버튼으로 할지. **버튼이 명확하다**(계산 의도를 사용자가 표현한다).
