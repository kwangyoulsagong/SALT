## Summary

모바일에서 이 기능은 **홈 적립 블록 → 숫자 하나 → 체크**의 3동작이다(2026-09-21: 주간 적립 전용 푸시가 없다 — D5 · B21). 웹의 밴드 표를 그대로 옮기지 않고, **바텀시트**로 접는다. 렌더 게이트는 웹과 **동일하게** 집행한다.

### F. 알림 진입

**개정 2026-09-21 — D5 · B21.** 푸시는 **1종(`signal_update` — 지표 · 추천 갱신)** 이다. "주간 적립" 전용 푸시 타입을 두지 않는다. 밴드 변경으로 이번 주 배수가 바뀐 경우가 `signal_update`의 한 갈래다(FEATURE-006 FR-51 "밴드 갱신 → 홈 적립 블록").

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-50 | `signal_update` 중 **밴드 갱신 갈래**를 탭하면 **`PlanDetailScreen`으로 직행**한다. **개정 2026-09-21** — 주간 적립 전용 푸시 삭제(D5 · B21) | Must |

## UX 상태

- **Loading**: 금액 자리 스켈레톤. 카드 높이 고정
- **Empty**: "월 얼마씩 넣을 계획인가요?" 1필드 온보딩 3단계 — 저장 = `PATCH /api/app/plan/settings` (B12)
- **Empty (이번 달 적립 0)**: "이번 달 적립 0원" — 비난 없이 (B20)
- **Blocked**: 회색 박스 + 사유 + "정상 동작입니다" + 기본액
- **Degraded**: 기본액 + "밴드 조정 없음(지표 조회 실패)"
- **ZeroWeek**: "이번 주 신규 적립 지시 없음" + 밴드 설명
- **Offline**: 마지막 화면 상태 유지 + 상단 오프라인 배너. **체크 버튼 disabled**
- **Error**: 재시도 버튼

## Acceptance Criteria

- [ ] 총액이 32sp 이상으로 가장 크게 표시된다
- [ ] 완료 버튼이 하단 고정이고 safe area를 존중한다
- [ ] **`renderable:false`에서 배수 노드가 트리에 없다**
- [ ] 차단 사유에 "정상 동작입니다"가 있다
- [ ] 차단 시에도 기본액이 표시된다
- [ ] 홈 블록에도 게이트가 적용된다
- [ ] **게이트 셀렉터가 `packages/core` 공유고 RN 복제가 0건이다**
- [ ] 우회 prop이 0건이다
- [ ] 밴드 표의 현재 행이 색 + 마커 + "현재" 텍스트로 표시된다
- [ ] **hits와 misses가 같은 비중이고 2025-10 톱 미검출이 있다**
- [ ] 시트가 드래그·백드롭·백 제스처로 닫힌다
- [ ] Android 백 버튼이 시트를 먼저 닫는다
- [ ] 시트 내부 스크롤이 드래그와 충돌하지 않는다
- [ ] 김프 줄에 % + 원화 비용이 있고 지시형이 0건이다
- [ ] `kimchiPremium: null`에서 적립 숫자가 유지된다
- [ ] `staleDays >= 3`에서 배지와 폴백 안내가 나온다
- [ ] 체크에 햅틱이 있고 더블 탭이 1회만 전송된다
- [ ] **자동 매칭 표시가 0건이고** 다른 기기의 수동 체크가 진입 시 반영된다 (ADR-002 · B20)
- [ ] **`signal_update`(밴드 갱신) 푸시 탭이 콜드 스타트에서도 PlanDetailScreen으로 간다**
- [ ] **주간 적립 전용 푸시 타입이 0건이다** (D5 · B21)
- [ ] 월 적립액 필드 1개, 배수·임계값 입력 0개, 밴드 표 읽기 전용 (D9)
- [ ] 온보딩 3단계 저장 후 홈 적립 블록이 채워진다 (B12)
- [ ] 목표 화면 상단 이번 달 합계가 서버 값이고 실패 시 목표 카드가 유지된다 (B20)
- [ ] **푸시 본문에 금액이 없다**
- [ ] **`Z >= 7`에서 매도 문구가 0건이다**
- [ ] 점수·등급·비난 문구가 0건이다
- [ ] 거래소 주문 딥링크가 0건이다
- [ ] `AsyncStorage`에 적립 금액이 없다
- [ ] 글꼴 200%에서 금액이 잘리지 않는다
- [ ] iOS·Android 양쪽에서 위 항목이 모두 통과한다

## Open Questions

- 밴드 표를 바텀시트에 넣으면 "항상 볼 수 있게"라는 웹 FR-22와 강도가 달라진다. 시트를 **기본 50% 노출 상태**로 열어둘지, 탭으로만 열지.
- 주간 적립 전용 푸시가 없어지면서(D5 · B21) **"월요일 아침 알림"** 경로가 사라졌다. 밴드가 안 바뀐 주는 푸시 없이 사용자가 앱을 열어야 한다. 이걸 받아들일지 — 사용자 확인 필요.
- 푸시에 금액을 넣지 않으면 알림만 보고는 행동할 수 없다. 알림 가치와 잠금화면 노출을 어디서 절충할지.
