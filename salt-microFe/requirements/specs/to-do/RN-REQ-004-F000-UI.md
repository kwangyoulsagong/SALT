## Summary

모바일에는 **수리할 기존 화면이 없다** — 앱이 새로 생긴다. 그래서 F000의 모바일 작업은 **웹의 수리 결과를 처음부터 올바르게 구현하는 것**이다. 웹이 고생해서 고친 것(터치 선택·반응형·하드코딩·더미)을 모바일은 처음부터 안 만든다.

가장 큰 설계 결정: **웹의 5컬럼 실시간 테이블을 좁은 화면에 어떻게 넣을지.**

## 실시간 시세 — 5컬럼을 어떻게 넣는가

웹은 5컬럼 표(현재가·변동률·최고가·최저가·거래대금) + 우측 392px 프리뷰다. 모바일 폭에서 그 표는 읽을 수 없다.

| 후보 | 판정 |
|---|---|
| 5컬럼 표를 가로 스크롤 | ✗ 세로 스크롤과 충돌한다. 한 손으로 못 쓴다 |
| 컬럼을 3개로 줄인다 | ✗ 웹과 정보가 달라진다. "같은 정보"라는 IA 원칙에 어긋난다 |
| **행을 2줄 카드로 재구성** | **✓ 채택.** 1줄: 로고·종목명·현재가·변동률 / 2줄: 최고·최저·거래대금(작게) |
| 종목 상세를 push | ✓ 병행. 행 탭 → 상세 화면(차트·게이지·뉴스) |

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-1 | 시세 목록 행을 **2줄 카드**로 구성한다. 1줄에 로고·종목명·현재가·변동률, 2줄에 최고·최저·거래대금 | Must |
| FR-2 | **정보를 줄이지 않는다.** 웹의 5컬럼 값이 전부 보인다 | Must |
| FR-3 | **변동률 blink 2초**를 모바일에서도 구현한다. 웹의 변경 금지 목록과 같은 시각 언어 | Must |
| FR-4 | 색 토큰: 상승 `#FF2E55` / 하락 `#1677EE`. `@repo/tokens`에서 온다 | Must |
| FR-5 | 필터(정렬 5 / 순서 2 / 기간 7)를 **`BottomSheet`** 로 제공한다. 화면 상단에 필터 칩 3개를 늘어놓지 않는다 | Must |
| FR-6 | 행을 탭하면 **종목 상세를 push**한다. 상세에 차트·심리 온도계·스마트 머니 게이지·뉴스 | Must |
| FR-7 | 별 아이콘으로 관심 종목을 추가/제거한다. 터치 타깃 **44×44 이상** | Must |
| FR-8 | 마지막 WS 수신 시각을 헤더에 표시한다. **하드코딩 0건** | Must |
| FR-9 | WS 끊김을 표시한다 | Must |

## UX 상태

- **Loading**: 시세 목록 스켈레톤. 캐시 있으면 먼저
- **Empty (관심 종목 0건)**: "시세 목록에서 별을 눌러 추가하세요"
- **Empty (뉴스 0건)**: "관련 뉴스가 없습니다". 더미 0건
- **Empty (온보딩 미완료)**: 온보딩 카드 1개
- **Offline**: 캐시 + "오프라인 · {시각} 기준"
- **Error (WS 끊김)**: 헤더에 표시 + 재연결 시도
- **Optimistic update**: 별 아이콘만 허용

## Acceptance Criteria

- [ ] 시세 행이 2줄 카드이고 **웹 5컬럼 값이 전부 보인다**
- [ ] **변동률 blink 2초가 동작한다**
- [ ] 색 토큰이 `@repo/tokens`에서 오고 웹과 같다
- [ ] 필터가 `BottomSheet`로 제공되고 정렬 5 / 순서 2 / 기간 7이 전부 있다
- [ ] 행 탭 → 종목 상세가 push된다
- [ ] 별 아이콘 터치 타깃이 44×44 이상이다
- [ ] **WS 마지막 수신 시각이 표시되고 하드코딩이 0건이다**
- [ ] WS 끊김이 표시된다
- [ ] 온보딩 3스텝이 완주되고 `ProgressStepper`가 동작한다
- [ ] 코드 입력 유효성이 표시되고 **상한 초과가 노출되지 않는다**
- [ ] 실패 `reasonCode` 3종이 각각 다른 문구다
- [ ] 코드 필드가 붙여넣기·자동 대문자화·공백 제거를 한다
- [ ] CSV 연결이 OS 파일 선택기를 띄우고 권한 사유가 있다
- [ ] 온보딩 재진입 시 완료 단계를 건너뛴다
- [ ] 온보딩 미완료 시 홈에 카드 1개만 나온다
- [ ] 종목 상세에 차트·게이지 2종·뉴스가 있다
- [ ] 게이지가 웹과 같은 시각 언어다
- [ ] **뉴스가 실데이터이고 더미·플레이스홀더가 0건이다**
- [ ] 스크롤 중 차트가 터치를 가로채지 않는다
- [ ] 홈에 보유 요약 + 알림 2종이 있다
- [ ] 총자산이 3자산군 원화 합산이고 환율 기준 툴팁이 있다
- [ ] **하단 탭이 3개다**
- [ ] 목표 추가가 `POST /api/goals`까지 연결된다
- [ ] 터치 타깃 전부 44×44 이상
- [ ] **폰트 최대 확대에서 시세 행이 깨지지 않는다**
- [ ] 시세 행이 한 번에 낭독된다
- [ ] 가격 셀에 `accessibilityLiveRegion`이 0건이다
- [ ] 기기 감소된 모션에서 blink가 멈추지 않고 느려진다

## Open Questions

- 2줄 카드가 웹의 5컬럼과 **정보 동등성**을 유지하는지 사용성 검증이 필요하다. 거래대금이 작게 들어가면 읽히지 않을 수 있다.
- 시세 목록에 **100행을 다 내려받을지.** 모바일에서 100행 스크롤은 `FlatList`로 가능하지만 데이터 사용량이 늘어난다 → 서버 페이징 검토(`RN-REQ-007` Open Question).
- 목표 저축을 3탭 어디에 둘지(F006에서 확정).
- 차트 라이브러리 선택(`RN-REQ-011` Open Question과 동일).
