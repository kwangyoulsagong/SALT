## Summary

종목 검색을 페이지(`/search`)에서 **모달**로. 참고 국내 증권 앱 웹 실측(리서치 §3 · §4)을 우리 데스크톱 위계로. 결과 · 추적(★) · 소유자 판정은 지금 서버 · BFF 값 그대로 — 화면 틀이 바뀐다.

## FR

| FR | 내용 |
|---|---|
| FR-1 | **여는 법** — 머리 검색칸(200×32) 누름 · `/` 키(입력칸 · 편집 중이 아닐 때) · `/search` 주소(모달 열린 상태로 그린다 — D5). 열면 검색칸에 포커스 |
| FR-2 | **틀** — 640 · max-height 600 · 위 8 · 모서리 16 · 그림자 두 겹(실측) · 검색칸 616×40 모서리 10 · 입력 15/600 · 본문만 스크롤 · 아래 안내 바 52(↵ 이동 · ESC 지우기 · ↑↓ 탐색, 키 칩 28×24). 배경 막은 D2 |
| FR-3 | **첫 화면** — 최근 검색 칩(28 · 모서리 999 · 13/600 · 칩마다 × · 기기 저장 그대로 `FE-REQ-011` FR-83) → **거래대금 상위**(국내 · 코인, 순번 · 로고 28 · 이름 14/600 · 등락률 13/600 · 행 44 · "{시각} 기준" — 라벨은 D3, 원천 = 기존 표 정렬) |
| FR-4 | **입력 중** — 결과 행 54(로고 30 · 일치 부분 하이라이트 · 코드 12/500 · 현재가 14/600 · 등락률 · ★ 추적 카운터는 지금 그대로) · 묶음 "종목"(코인 · 국내 소유자만) · 빈 결과 문구 해요체 |
| FR-5 | **키보드** — 포커스는 검색칸 고정 · ↑↓ 고른 행(`aria-activedescendant` · `role=option` · `aria-selected`) · Enter 상세로 · Esc 두 단계(지우기 → 닫기) · 닫으면 연 자리로 포커스 · 주소 바뀜 0(`/search` 진입 제외) |
| FR-6 | 접근성 — `role=dialog` `aria-modal` · 포커스 가둠 · 결과 수 `aria-live` 한 줄 · 등락은 색 + 부호 글자 |
| FR-7 | 390 웹뷰 — 같은 내용 한 열 시트 |
| FR-8 | (2단계 — D4) 결과 탭 산업 · 뉴스 · 지수 · 오른쪽 곁 칸(고른 종목 시황 제목의 관련 종목) · 뜨는 업종 순위 — **BFF · 서버 짝 REQ 필요**(번호는 착수 때) |

## Acceptance Criteria

- [ ] 투자 zone 모든 화면에서 `/` · 머리 검색칸으로 열린다 · Esc 두 단계 · 닫으면 포커스 복귀
- [ ] 키보드만으로 검색 → 상세 이동(스크린리더가 고른 행을 읽는다)
- [ ] 비소유자에게 국내 결과 · 국내 순위 0(지금 판정 그대로)
- [ ] 1024 · 1280 · 1440 · 1600 넘침 0 · 390 웹뷰 · axe 0
- [ ] 번들 — 투자 zone 증가분 기록(`FE-REQ-029`)

## 계약 영향

- 1단계: 없음(기존 `/api/app/search` · 시장 개요 · 국내 표 정렬). 2단계: BFF · 서버 짝 REQ(업종 순위 · 뉴스 제목 검색 · 곁 칸)
- 머리 검색칸 자리는 `FE-REQ-067` 결정(D1)에 따른다
