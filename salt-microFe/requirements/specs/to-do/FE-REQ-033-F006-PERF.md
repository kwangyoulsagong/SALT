## Summary

F006의 급소 셋: **① 홈 첫 블록 300ms ② 대화 스트리밍 중 리렌더 ③ `MovableGrid` 드래그 60fps**.

## 예산

| 지점 | 예산 | 비고 |
|---|---|---|
| **홈 첫 블록 페인트** | **300ms** | 총자산(가장 빠른 소스) |
| 홈 전체 완료 | **1.5s** | 청구서 스냅샷 미스가 최악 |
| 탭 전환 (같은 zone) | **200ms** | soft navigation |
| 코치 탭 첫 페인트 | 400ms | 과거 대화 + 브리핑 |
| **첫 토큰 도착** | **1s** | SSE |
| 델타 반영 | **60fps** | 프레임 버퍼링 |
| 대화 스크롤 (메시지 200) | **60fps** | |
| 과거 메시지 로드 | 400ms | 커서 |
| **`MovableGrid` 드래그** | **60fps** | 이동·크기 조절 |
| 격자 배치 저장 | 디바운스 1초 | |
| 자산 탭 세그먼트 전환 | 100ms | 이미 받은 데이터 |
| 홈 클라이언트 JS 증가분 | **40KB gzip 이하** | |

## 급소 1 — 홈 첫 블록 300ms

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-1 | 총자산을 **가장 먼저** 흘린다. 소스가 가장 빠르다(캐시 히트) | Must |
| FR-2 | 청구서(가장 느림)를 **마지막 Suspense**에 둔다 | Must |
| FR-3 | 블록 호출을 **병렬**로 띄운다. 서버 워터폴 0건 | Must |
| FR-4 | **스켈레톤 높이 = 실제 블록 높이.** CLS를 만들면 스트리밍 이득이 상쇄된다 | Must |
| FR-5 | Suspense 경계 **5개**(블록 수와 같다). 더 늘리지 않는다 | Must |
| FR-6 | **첫 블록 페인트와 전체 완료 시각을 측정**한다. 이관 전(1콜) 대비 개선을 기록한다 | Must |
| FR-7 | 개선이 없으면 **집계 1콜로 되돌린다**(`FE-REQ-008` FR-31) | Must |

## 급소 2 — 대화 스트리밍 리렌더

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-10 | **델타를 마지막 말풍선에만** 누적한다. 목록 전체가 리렌더되면 메시지 200개에서 죽는다 | Must |
| FR-11 | 토큰을 **프레임 단위로 버퍼링**한다(`requestAnimationFrame`). 토큰마다 setState 0건 | Must |
| FR-12 | 말풍선 컴포넌트를 `memo`로 감싼다. **리스트 항목은 예방적 메모가 정당하다** | Must |
| FR-13 | 메시지 200개를 넘으면 **가상화를 검토**한다. 다만 대화는 가변 높이라 가상화가 어렵다 → **페이지 크기 제한**이 먼저다 | Must |
| FR-14 | 리스트 `key`에 `messageId`를 쓴다. index 0건 | Must |
| FR-15 | 자동 스크롤이 **매 델타마다 일어나지 않게** 한다. 프레임 단위로 | Must |
| FR-16 | 스트리밍 중 다른 블록(추천 카드·성적표)이 리렌더되지 않는다 | Must |
| FR-17 | 대화 스크롤 프레임을 측정한다 | Must |

## 급소 3 — `MovableGrid` 드래그

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-20 | 드래그 중 **`transform`만** 쓴다. 레이아웃 속성을 바꾸지 않는다 | Must |
| FR-21 | 좌표 계산은 **순수 함수**(`layoutTree`)이고 `ResizeObserver`로 컨테이너 크기를 **한 번만** 관측한다 | Must |
| FR-22 | 드래그 중 **패널 내용을 리렌더하지 않는다.** 패널은 껍데기만 움직인다 | Must |
| FR-23 | 구분선 드래그가 **패널 내용 리렌더를 유발하지 않게** 한다. 크기 변경은 CSS로 | Must |
| FR-24 | 배치 저장을 **1초 디바운스**한다. 드래그 중 매 프레임 저장 0건 | Must |
| FR-25 | `MovableGrid`를 **`ssr: false`** 로 마운트한다. 초기 번들에 넣지 않는다 | Must |
| FR-26 | 1280px 미만에서 **마운트하지 않는다.** 모바일 번들에 격자 코드가 들어가지 않게 | Must |
| FR-27 | 드래그 프레임을 측정한다 | Must |

## Acceptance Criteria

- [ ] **홈 첫 블록 페인트 p95 < 300ms** (측정값 기록)
- [ ] 총자산이 청구서보다 먼저 페인트된다 (스로틀 확인)
- [ ] 홈 전체 완료 p95 < 1.5s
- [ ] 블록 호출이 병렬이다 (서버 워터폴 0건)
- [ ] 스켈레톤 높이가 실제와 같다 (CLS 측정값 기록)
- [ ] Suspense 경계가 5개다
- [ ] **첫 블록/전체 완료가 이관 전 대비 기록되어 있다**
- [ ] **델타가 마지막 말풍선에만 반영된다** (Profiler)
- [ ] 토큰이 프레임 단위로 버퍼링된다 (토큰마다 setState 0건)
- [ ] 말풍선이 `memo`로 감싸져 있다
- [ ] 리스트 key가 `messageId`다
- [ ] 자동 스크롤이 프레임 단위다
- [ ] 스트리밍 중 추천 카드·성적표가 리렌더되지 않는다
- [ ] **대화 스크롤이 60fps다** (메시지 200개, 측정값 기록)
- [ ] **`MovableGrid` 드래그가 60fps다** (측정값 기록)
- [ ] 드래그가 `transform`만 쓴다
- [ ] 드래그 중 패널 내용이 리렌더되지 않는다
- [ ] 배치 저장이 1초 디바운스된다
- [ ] `MovableGrid`가 `ssr: false`이고 별도 청크다
- [ ] 1280px 미만에서 격자가 마운트되지 않는다
- [ ] 스트림 중복 구독·유령 연결이 0건이다
- [ ] **첫 토큰 지연이 측정되고 1s 이내다**
- [ ] 델타 반영 지연이 측정된다
- [ ] 홈 클라이언트 JS 증가분 ≤ 40KB gzip
- [ ] `"use client"`가 잎 4개에 한정된다
- [ ] 스트리밍 중 스크린리더가 매 토큰 낭독하지 않는다
- [ ] 관측 항목 8종이 있다
