## Summary

모바일에서 F000의 동작 규칙. 웹과 가장 다른 것은 **① WS를 백그라운드에서 끊는 것 ② 토큰을 secure store에 두는 것 ③ 딥링크** 셋이다.

## WebSocket — 백그라운드 관리

모바일은 앱이 백그라운드로 간다. **WS를 그대로 열어두면 배터리와 데이터를 먹는다.**

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-1 | 앱이 **백그라운드로 가면 WS를 끊는다** | Must |
| FR-2 | 포그라운드 복귀 시 **재연결**하고 시세를 재조회한다 | Must |
| FR-3 | 재연결 중에는 마지막 값 + "연결 중" 표시. 스켈레톤으로 되돌리지 않는다 | Must |
| FR-4 | WS 끊김을 헤더에 표시한다 | Must |
| FR-5 | 메시지 수신을 **프레임 단위로 버퍼링**한다. 초당 수십 회 setState하면 JS 스레드가 막힌다 | Must |
| FR-6 | **화면이 보는 종목만 구독**한다. 시세 목록을 떠나면 구독을 정리한다 | Must |
| FR-7 | 종목 상세로 push하면 그 종목만 구독한다. 목록 구독은 유지하되 갱신 반영을 줄인다 | Should |
| FR-8 | 언마운트 시 구독 해제. **유령 구독 0건** | Must |
| FR-9 | 재연결 백오프를 둔다. 무한 재시도로 배터리를 먹지 않는다 | Must |

## 토큰 보관

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-10 | 토큰을 **iOS Keychain / Android Keystore**(`expo-secure-store`)에 저장한다 | Must |
| FR-11 | **`AsyncStorage`에 토큰을 두지 않는다.** 쿼리 캐시 저장소와 혼동하지 않는다 | Must |
| FR-12 | 앱 시작 시 secure store에서 토큰을 읽는다. 없으면 로그인·온보딩으로 | Must |
| FR-13 | 만료 시 refresh를 시도하고 실패하면 토큰을 지우고 로그인으로 보낸다 | Must |
| FR-14 | 로그아웃 시 토큰과 **쿼리 캐시를 함께 지운다.** 캐시에 금액이 남으면 다음 사용자가 본다 | Must |
| FR-15 | **거래소 API 키를 기기에 저장하지 않는다.** secure store에도 넣지 않는다 — 서버가 갖는다 | Must |

## 딥링크

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-20 | 스킴을 정의한다(`salt://`). 알림·초대 링크가 그 경로로 들어온다 | Must |
| FR-21 | **딥링크 파라미터를 신뢰하지 않는다.** 진입 후 서버로 재검증한다 | Must |
| FR-22 | 미로그인 딥링크는 **로그인 후 그 화면으로 이어진다** | Must |
| FR-23 | 알 수 없는 경로는 홈으로 보낸다. 크래시하지 않는다 | Must |
| FR-24 | 딥링크 진입 시 스택을 올바르게 구성한다. **뒤로가기가 앱을 닫으면 안 된다** | Must |
| FR-25 | 초대 링크(`salt://invite?code=`)로 온보딩 1단계에 코드를 미리 채운다 | Should |

## Acceptance Criteria

- [ ] 앱이 백그라운드로 가면 WS가 끊긴다
- [ ] 포그라운드 복귀 시 재연결되고 시세가 재조회된다
- [ ] 재연결 중 마지막 값 + "연결 중"이 표시된다
- [ ] WS 메시지가 프레임 단위로 버퍼링된다
- [ ] 화면이 보는 종목만 구독된다
- [ ] 언마운트 시 구독이 해제된다 (유령 구독 0건)
- [ ] 재연결에 백오프가 있다
- [ ] **토큰이 secure store에 있고 `AsyncStorage`에 0건이다**
- [ ] 앱 시작 시 토큰을 secure store에서 읽는다
- [ ] 만료 시 refresh → 실패 시 토큰 삭제 + 로그인
- [ ] **로그아웃 시 쿼리 캐시가 함께 지워진다**
- [ ] **거래소 API 키가 기기 저장소에 0건이다**
- [ ] 딥링크 스킴이 정의되고 알림이 그 경로로 들어온다
- [ ] **딥링크 진입 후 서버 재검증이 일어난다**
- [ ] 미로그인 딥링크가 로그인 후 이어진다
- [ ] 알 수 없는 경로가 홈으로 가고 크래시가 0건이다
- [ ] 딥링크 진입 후 뒤로가기가 앱을 닫지 않는다
- [ ] 관심 종목이 단일 소스이고 두 화면이 동기화된다
- [ ] 별 아이콘 낙관적 갱신이 되고 실패 시 되돌아간다
- [ ] 온보딩 단계가 서버 응답으로 결정된다
- [ ] `invite/check`가 디바운스된다
- [ ] `invite/accept`가 재시도되지 않는다
- [ ] 재진입 시 완료 단계를 건너뛴다
- [ ] 오프라인에서 캐시 + 배너가 표시되고 WS를 열지 않는다
- [ ] 오프라인에서 mutation 버튼이 비활성이다
- [ ] **오프라인 큐가 0건이다**
- [ ] i18n 키가 웹과 공유되고 금지 표현 검사가 동작한다
- [ ] 매핑 없는 서버 코드가 렌더되지 않는다
- [ ] 알림 문구가 `messageCode` + `params`다
- [ ] **동면 API 호출이 0건이고 `register` 화면이 0건이다**

## Open Questions

- 백그라운드에서 WS를 끊으면 **복귀 시 시세가 튄다.** 재조회로 메꾸지만 체감이 어떤지 확인 필요.
- 종목 상세와 목록의 구독을 어떻게 나눌지(FR-7). 둘 다 구독하면 낭비, 하나만 하면 돌아왔을 때 값이 오래됐다.
- 로그아웃 시 캐시 삭제 범위. 전부 지우면 다음 로그인이 느리지만 **금액이 남는 것보다 안전하다.**
