## Summary

청구서 모바일 화면. 웹과 다른 것은 **3선 그래프를 좁은 화면에 넣는 것**, **CSV를 OS 파일 선택기로 받는 것**, **오프라인 캐시 표시** 셋이다. 자책 방지 정책(대칭 렌더·인격 평가 금지)은 웹과 동일하다.

## FSD 배치

| 레이어 | 슬라이스 | 컴포넌트 |
|---|---|---|
| `pages` | `assets` | 자산 탭 → 청구서 세그먼트 |
| `widgets` | `asset-workspace` | 세그먼트 3 |
| `features` | `import-ledger` · `register-exchange-key` | 웹과 같은 슬라이스 이름 |
| `entities` | `invoice` · `ledger` | 웹과 **같은 컴포넌트 이름**, RN 구현 |
| `src/native` | `documentPicker` | OS 파일 선택기 |

## 화면 구조

```
자산 탭 → 청구서 세그먼트
┌─ 오프라인/원장 배너 (있으면)
├─ 기간 SegmentedControl: 30 · 90 · 180 · 365 · 전체
├─ 3선 그래프 (전체 폭, 높이 200)
│   실선/점선/파선 + 직접 라벨 (색만으로 구분하지 않는다)
├─ 요약 3카드 (세로 스택)
│   개입 손익 −1,240,000원
│   규율 손익 −430,000원
│   수수료 −86,000원
├─ 가장 비싼 습관 카드   ┐ 같은 크기
├─ 잘한 개입 카드        ┘ 같은 위치 비중
├─ 편향별 목록 (누르면 거래 목록 push)
├─ 계산 기준 (스냅샷 시각 · 현재가 시각)
├─ 잔차 표시
├─ 결측/미지원 안내
└─ AI 코치 해설 3문장 (null 허용)

거래 목록 (push)
  FlatList · 커서 페이징
  행: 날짜 · 수량 · 단가 · 현재가 · 귀속손익
  행 탭 → 전후 90일 차트 (BottomSheet)
```

## Requirements

### A. 3선 그래프 — 좁은 화면

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-1 | 선 스타일로 구분한다: 실선/점선/파선. **색만으로 구분하지 않는다** | Must |
| FR-2 | **직접 라벨**을 붙인다. 좁은 화면에서 범례를 따로 두면 자리를 먹는다 | Must |
| FR-3 | 높이를 200~240으로 고정한다. 세로 화면에서 그래프가 화면을 다 먹으면 안 된다 | Must |
| FR-4 | 점 수는 서버가 다운샘플링한 것을 쓴다. **모바일에서 추가로 줄일지 측정 후 판단** | Must |
| FR-5 | 터치로 특정 시점 값을 볼 수 있게 한다(crosshair). 없으면 그래프가 장식이 된다 | Should |
| FR-6 | 언마운트 시 차트를 정리한다 | Must |
| FR-7 | 그래프 대신 **표 대체 수단**을 제공한다(스크린리더용). 시작·끝·최대 차이 3개 값 | Must |

### B. 대칭 렌더 — 웹과 같은 정책

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-10 | `topGains` 카드를 `topLosses` 카드와 **같은 크기·같은 위치 비중**으로 렌더한다 | Must |
| FR-11 | `hasGains: false`면 기계적 적립 트랙 비교를 나란히 표시한다 | Must |
| FR-12 | **점수·등급·벌점 0건** | Must |
| FR-13 | **2인칭 인격 평가 0건.** 사실 서술만 | Must |
| FR-14 | 기간 내 거래 0건 문구가 중립적이다 | Must |
| FR-15 | 손익 부호를 **색 + `+`/`−` 문자** 동시 표기 | Must |

### C. 잔차와 신뢰도

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-20 | `residual`을 화면에 표시한다. 없으면 **청구서를 렌더하지 않는다** | Must |
| FR-21 | 원장 오차 > 0.5%면 상단 배너 + [원장 점검] | Must |
| FR-22 | `interpolatedDays`·`unsupportedTransactions`를 안내한다 | Must |
| FR-23 | `computedAt`·`priceAdjustedAt`을 표시하고 `priceStale`을 명시한다 | Must |
| FR-24 | **국내·미국 주식은 `priceStale`일 가능성이 높다**(BFF가 업비트 WS만 구독). 그 사실을 종목 단위로 표시한다 | Must |

### D. 거래 목록

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-30 | `FlatList` + 커서 페이징. `ScrollView` 금지 | Must |
| FR-31 | 편향별 항목을 누르면 **필터된 거래 목록을 push**한다. 아코디언으로 인라인 펼치지 않는다(모바일에서 스크롤이 길어진다) | Must |
| FR-32 | 행을 누르면 **전후 90일 차트를 `BottomSheet`** 로 띄운다 | Must |
| FR-33 | 행에 날짜·수량·단가·현재가·귀속손익. 좁은 폭에서 2줄로 배치 | Must |
| FR-34 | 편향 필터·정렬을 헤더에 둔다 | Should |
| FR-35 | 목록에 `accessibilityLabel`로 행 전체를 낭독한다 | Must |

### E. CSV 업로드 — OS 파일 선택기

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-40 | `src/native/documentPicker`로 OS 파일 선택기를 띄운다. CSV MIME 필터 | Must |
| FR-41 | **파일 접근 권한을 요청할 때 사유를 명시**한다 | Must |
| FR-42 | 파일 크기·확장자를 **선택 직후 검사**한다. 20MB 초과면 업로드하지 않는다 | Must |
| FR-43 | **파일 내용을 읽지 않는다.** URI를 그대로 `FormData`에 넣는다 | Must |
| FR-44 | 업로드 중 진행 표시 + **취소 가능** | Must |
| FR-45 | 결과: `inserted`·`duplicated`·`failed`. 실패 행 최대 10건 | Must |
| FR-46 | 실패 행 CSV는 **서버 URL → OS 공유 시트**로 넘긴다 | Must |
| FR-47 | 재업로드 시 `duplicated > 0`이 정상임을 안내한다 | Must |
| FR-48 | 거래 0건이면 온보딩 + **워터마크 `예시` 샘플 청구서** | Must |
| FR-49 | 업로드 중 앱이 백그라운드로 가면 **중단된다.** 그 사실을 알리고 재시도하게 한다 | Must |

### F. 거래소 키

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-50 | 조회 전용 키만 등록 가능함을 명시한다 | Must |
| FR-51 | `403 SCOPE_NOT_ALLOWED`면 안내 + 조회 전용 키 발급 방법 | Must |
| FR-52 | secret 입력 필드는 `secureTextEntry`. **클립보드 붙여넣기는 허용**한다(키가 길다) | Must |
| FR-53 | 등록 후 `accessKeyMasked`·`scopes`만 표시. **secret 재표시 0건** | Must |
| FR-54 | 키 삭제 시 `Dialog.confirm` | Must |
| FR-55 | **거래소 키를 앱에 저장하지 않는다.** 서버가 저장하고 앱은 마스킹 상태만 본다 | Must |

### G. 오프라인

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-60 | 오프라인에서 캐시를 보여주고 **"오프라인 · {시각} 기준" 배너**를 붙인다 | Must |
| FR-61 | 오프라인에서 업로드·키 등록·재계산 버튼을 **비활성**하고 사유를 표시한다 | Must |
| FR-62 | **오프라인 큐 0건** | Must |
| FR-63 | 캐시 24시간 초과 시 "데이터가 오래되었습니다" | Must |

## UX 상태

- **Loading**: 캐시 먼저 → 인라인 스피너. 전체 스켈레톤으로 되돌리지 않는다
- **Empty (거래 0건)**: FR-48
- **Empty (기간 내 0건)**: FR-14
- **Offline**: FR-60~63
- **Degraded (원장 불일치 / 결측 / 잔차 초과)**: 배너
- **Degraded (`narrative` null)**: 그 영역을 렌더하지 않는다. 오류 표시 0건
- **Error (업로드 실패)**: 실패 행 + 재시도
- **Optimistic update**: 없음

## Acceptance Criteria

- [ ] 3선이 선 스타일 + 직접 라벨로 구분된다 (색만 0건)
- [ ] 그래프 높이가 고정이고 화면을 다 먹지 않는다
- [ ] 언마운트 시 차트가 정리된다
- [ ] **그래프의 표 대체 수단이 있고 스크린리더로 낭독된다**
- [ ] `topGains` 카드가 `topLosses`와 같은 크기·위치 비중이다
- [ ] `hasGains: false`에서 기계적 적립 비교가 표시된다
- [ ] 점수·등급·벌점이 0건, 2인칭 인격 평가가 0건이다
- [ ] 거래 0건 문구가 중립적이다
- [ ] `residual`이 표시되고, 없으면 청구서가 렌더되지 않는다
- [ ] 원장 오차 > 0.5%에서 배너 + CTA가 나온다
- [ ] `priceStale`이 종목 단위로 표시된다 (국내·미국 주식)
- [ ] 거래 목록이 `FlatList`이고 커서 페이징이다
- [ ] 편향 항목을 누르면 목록이 push된다 (인라인 아코디언 0건)
- [ ] 행을 누르면 전후 90일 차트가 `BottomSheet`로 뜬다
- [ ] OS 파일 선택기가 CSV MIME으로 필터된다
- [ ] 파일 권한 요청에 사유가 있다
- [ ] 20MB 초과 파일이 선택 직후 걸러진다
- [ ] **파일 내용을 읽지 않는다** (`FileReader`/`readAsStringAsync` 0건)
- [ ] 업로드가 취소 가능하다
- [ ] 실패 행 CSV가 OS 공유 시트로 넘어간다
- [ ] 재업로드 시 `duplicated`가 정상임이 안내된다
- [ ] 거래 0건에서 워터마크 샘플이 나온다
- [ ] 업로드 중 백그라운드 전환 시 중단이 알려진다
- [ ] `403 SCOPE_NOT_ALLOWED`에서 안내가 나온다
- [ ] secret 필드가 `secureTextEntry`이고 붙여넣기가 된다
- [ ] 화면에 secret 재표시가 0건이다
- [ ] **거래소 키가 앱 저장소에 0건이다**
- [ ] 키 삭제 시 confirm이 뜬다
- [ ] 오프라인 배너에 시각이 있고 mutation 버튼이 비활성이다
- [ ] 오프라인 큐가 0건이다
- [ ] 터치 타깃 44×44 이상, 폰트 최대 확대에서 금액이 잘리지 않는다

## Open Questions

- 3선 그래프를 무엇으로 그릴지. `@repo/ui-native`에 차트가 없다 — **`react-native-svg` 기반 자체 구현**이 기본안(다운샘플링된 200~400점이면 충분). `react-native-skia`는 번들이 크다.
- 편향별 목록을 push할지 아코디언으로 펼칠지. **push가 기본안**이지만 왕복이 늘어난다.
- 업로드 중 백그라운드 전환 처리. iOS는 백그라운드 업로드가 가능하지만 복잡도가 크다 → **중단 + 재시도**가 기본안.
