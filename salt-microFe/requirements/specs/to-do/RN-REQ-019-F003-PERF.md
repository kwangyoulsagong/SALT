## Summary

이 화면의 성능은 **푸시 탭 → 숫자 보임**까지의 시간으로 정의된다. 콜드 스타트가 포함되므로 웹보다 예산이 길고, **JS 번들·폰트·초기 파싱**이 지배한다.

## 예산

| 지표 | 조건 | 목표 | 상한 |
|---|---|---|---|
| 콜드 스타트 → 첫 프레임 | 중급 Android | 1.8s | 2.5s |
| 푸시 탭 → 적립 숫자 표시 (콜드) | 중급 Android | 2.5s | 3.5s |
| 푸시 탭 → 적립 숫자 표시 (웜) | 중급 Android | 700ms | 1.2s |
| 홈 → 상세 push 전환 | 전 기기 | 250ms | 400ms |
| 바텀시트 열림 | 전 기기 | 200ms | 300ms |
| 체크 탭 → 시각 반응 | 전 기기 | 100ms | 150ms |
| 프레임 드롭 (시트 드래그) | 전 기기 | 0 | 1% |
| JS 번들 (앱 전체, Hermes) | — | 4MB | 6MB |
| 메모리 (상세 화면) | 중급 Android | 180MB | 250MB |

기준 기기: Android — Galaxy A34급 / iOS — iPhone 12.

## Requirements

### A. 시작과 전환

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-1 | Hermes + 바이트코드 프리컴파일을 켠다 | Must |
| FR-2 | `PlanDetailScreen`을 **네비게이션 lazy**로 등록한다. 콜드 스타트 번들에 넣지 않는다 | Must |
| FR-3 | 푸시 딥링크 경로에서 **스플래시 유지 시간을 데이터 대기에 쓰지 않는다.** 셸을 먼저 그린다 | Must |
| FR-4 | 화면 전환 애니메이션이 데이터 fetch를 기다리지 않는다 | Must |
| FR-5 | 스켈레톤 높이를 실제 레이아웃과 일치시켜 **점프가 0건**이다 | Must |

### B. 렌더

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-10 | 자산 10종 이하면 `map` 렌더. 초과 시에만 `FlashList` | Should |
| FR-11 | 금액 포맷터를 **모듈 레벨에서 1회 생성**한다. 렌더마다 `Intl.NumberFormat` 생성이 0건이다 | Must |
| FR-12 | 바텀시트를 **열기 전까지 마운트하지 않는다**(lazy mount) | Must |
| FR-13 | 시트 드래그는 **Reanimated 워크릿(UI 스레드)** 으로 처리한다. JS 스레드 브릿지 왕복이 0건이다 | Must |
| FR-14 | 게이지·밴드 표는 SVG/View로 그린다. **차트 라이브러리를 넣지 않는다** | Must |
| FR-15 | 리렌더 범위를 항목 단위로 제한한다. 체크 1회에 전체 리스트가 리렌더되지 않는다 | Must |

### C. 네트워크와 캐시

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-20 | 화면 진입 시 요청은 **1회**다. 실패 이력은 시트 열 때만 | Must |
| FR-21 | 포그라운드 복귀 재검증에 **60초 디바운스**를 둔다 | Must |
| FR-22 | `renderable:false`면 실패 이력 요청이 0건이다 | Must |
| FR-23 | 오프라인 캐시 읽기가 **50ms 이내**다 | Should |
| FR-24 | 이미지·아이콘은 벡터. 원격 이미지 로딩이 0건이다 | Should |

## 부하·열화 시나리오

| 시나리오 | 조건 | 기대 |
|---|---|---|
| 김프 upstream 지연 | BFF가 1.5s 후 `null` | 적립 숫자 도착 시간 **불변** |
| 지표 전체 실패 | `indicators: []` | 기본액 표시, 예산 유지 |
| 오프라인 콜드 스타트 | 네트워크 없음 | 캐시 + 배너, 3s 이내 표시 |
| 저사양 기기 | Android Go급 | 상한 예산 내, 크래시 0건 |
| 글꼴 200% | 접근성 최대 | 레이아웃 유지, 프레임 드롭 없음 |
| 장시간 백그라운드 | 12시간 후 복귀 | 재검증 1회, ANR 0건 |

## Acceptance Criteria

- [ ] Hermes가 켜져 있다
- [ ] **`PlanDetailScreen`이 콜드 스타트 번들에 없다**
- [ ] **푸시 탭 → 숫자 표시가 콜드 3.5s / 웜 1.2s 상한 이내다**
- [ ] 스플래시가 데이터를 기다리지 않는다
- [ ] 스켈레톤 높이가 실제와 같고 레이아웃 점프가 0건이다
- [ ] 렌더마다 `Intl.NumberFormat`을 생성하지 않는다
- [ ] **바텀시트가 열기 전 마운트되지 않는다**
- [ ] **시트 드래그가 UI 스레드에서 처리되고 프레임 드롭이 1% 이하다**
- [ ] 적립 화면에 차트 라이브러리가 없다
- [ ] 체크 1회에 전체 리스트가 리렌더되지 않는다
- [ ] 화면 진입 요청이 1회다
- [ ] **포그라운드 복귀 재검증에 60초 디바운스가 있다**
- [ ] `renderable:false`에서 실패 이력 요청이 0건이다
- [ ] **김프 지연이 적립 숫자 도착 시간을 바꾸지 않는다**
- [ ] 오프라인 콜드 스타트가 3s 이내 표시된다
- [ ] `push_tap → number_visible` 트레이스가 콜드/웜 구분으로 수집된다
- [ ] CI 번들 크기 회귀 검사가 동작한다
- [ ] 기준 기기 2종에서 릴리스마다 예산이 검증된다
- [ ] **성능 로그에 적립 금액이 없다**
- [ ] Android Go급에서 크래시가 0건이다
