## Summary

코치 화면 모바일 구현. 웹과 다른 점은 **카드에 3종을 다 넣으면 화면 두 개 길이가 된다**는 것이다. 그래서 **카드 안에 3종 요약을 넣고 상세는 접힘**으로 처리한다 — 단 **3종이 동시에 보인다는 정책은 지킨다**(요약 3개가 한 화면에 있다).

## 화면 구조 — 세로

**개정 2026-09-21 (B15)**: 아래 구조는 코치 탭이 아니라 **코치 리포트(`CoachReportScreen`, push)** 다.

```
코치 리포트 (CoachReportScreen)
┌─ 생성 시각 + staleHours 배지 + [새로 생성]
├─ 추천 카드
│   ┌ renderable: true ────────────────────────┐
│   │ [매수] KRW-BTC        점수 72             │
│   │ 점수는 확률이 아닙니다                     │
│   │ ─────────────────────────────────────────│
│   │ 근거 3개 (요약)               [자세히 ▾]  │
│   │ 성적 42회 · 승률 57%          [자세히 ▾]  │
│   │ 틀렸던 때 1건                 [자세히 ▾]  │
│   │ ─────────────────────────────────────────│
│   │ [도움 됐음] [도움 안 됨]                   │
│   └──────────────────────────────────────────┘
│   ┌ renderable: false ───────────────────────┐
│   │ (회색) 이 신호의 과거 성적 데이터가        │
│   │ 아직 없어 추천을 표시하지 않습니다        │
│   │ (표본 3건) · 이것은 정상 동작입니다        │
│   └──────────────────────────────────────────┘
├─ 리스크 (severity 내림차순, 최대 3 + 더보기)
├─ 후보 (상위 3, 접힘)
├─ 익절 플랜 (보유 종목별, 세로 카드)
├─ [주문 전 계산] → BottomSheet
├─ [신호 성적표] → push (표는 가로 스크롤)
├─ 행동 기록 (사실 서술 — 청구서 링크 없음, ADR-002)
├─ 국내주식 제외 안내
└─ 면책 (하단 고정)
```

### J. 상세 분석 화면 — 우측 패널 내용 포함 (2026-09-21)

근거: `pm/requirements/reports/feature-audits/2026-09-21-storyboard-gap.md` D2 · D3 · D4 · D7 · B1 · B3 · B9 · B10 · B23.
**`FEATURE-000` FR-33 을 이관받음.** 모바일에는 우측 패널이 없다 — 자산 탭 `시장` 세그먼트에서 종목을 누르면

```
AssetDetailScreen (push)
┌─ Hero: ← · 종목 · 현재가 · 변동률 · [♡ 관심 추가] [🛡 주문 전 체크]   (알림 만들기 없음)
├─ 모드 스위치 [단타 | 장기]   (SegmentedControl — 시장 목록과 공유)
├─ 차트 (기간 6탭, 가로 스크롤) + 오버레이 3선 · 범례 "예측 아님"
├─ 내 규칙 가격(보유) / 관찰 구간(미보유) — KeyValueList 3행
├─ 지금의 판단 카드 — 라벨 · 모드 · 유효시간 · 점수/scoreNote · 3종 요약 [자세히 ▾]
│     (renderable: false → BlockedNotice)
├─ 심리 온도계 · 스마트 머니 + 적중률 한 줄
├─ [해설 보기] → 해설 카드 (이유 · 근거 · 주의점 · 뉴스 5줄 · 면책 + 3종)
├─ 수익 플랜 (보유만)
├─ 관련 뉴스
└─ 면책 (하단 고정)
```
