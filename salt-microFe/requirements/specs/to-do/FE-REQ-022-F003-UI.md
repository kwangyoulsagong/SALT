## Summary

**화면에 숫자 하나.** "이번 주 BTC에 375,000원." 그게 끝이다. 나머지는 근거다. 그리고 **실패 이력이 없으면 배수 카드를 렌더하지 않는다.**

```

  이번 주 적립 475,000원
  BTC 375,000 · VOO 100,000            [자세히]

적립 상세 (자산 탭 또는 홈에서 push)
┌─ 이번 주 적립 475,000원  (큰 숫자)

│   BTC — 기본 125,000원 × 3.0배 = 375,000원
│     근거: MVRV Z −0.3 → 극단 저평가 밴드(Z < 0)
│           과거 4개 사이클 바닥이 이 구간에서 나왔습니다
│     [실패 이력 보기 ▾]  ← 없으면 이 카드가 렌더되지 않는다
│   VOO — 기본 200,000원 × 0.5배 = 100,000원

  이번 달 적립 1,900,000원
  계획 2,000,000원 중 95% · 4일 남음
  ▓▓▓▓▓▓▓▓▓░
  (그 아래 기존 목표 카드 그대로)

  월 적립 계획   [ 1,300,000 원 ]
                주간 기본액 300,000원으로 자동 환산됩니다 (서버 값)
  비트코인 주간 기본액        …원   (읽기 전용)
  S&P500 ETF 주간 기본액     …원   (읽기 전용)
  밴드 표 — MVRV Z 0/2/5/7 · CAPE 백분위 20/50/80/95   🔒 읽기 전용
```

## UX 상태

- **Loading**: 금액 자리 스켈레톤. **밴드 표는 정적이므로 즉시 렌더**
- **Empty (설정 없음)**: 온보딩 3단계 — "월 얼마씩 넣을 계획인가요?" (저장 = `PATCH /api/app/plan/settings`, B12)
- **Empty (이번 달 적립 0)**: "이번 달 적립 0원" + 계획 대비 0%. 비난 없이 (B20)
- **Error (월 합계)**: 합계 블록만 오류, 목표 카드는 유지 (B20)
- **Stale (지표 3일+ 결측)**: `지표 N일 지연` 배지 + 중립 폴백 안내
- **Warning (김프 ≥ +3%)**: 게이지 강조 + **사실 서술**
- **Warning (0x)**: "이번 주 신규 적립 지시 없음" + 밴드 설명. **매도 지시 0건**
- **Blocked (실패 이력 없음)**: 회색 박스 + 사유 + "정상 동작입니다"
- **Error (지표 전체 실패)**: 기본액 + "밴드 조정 없음"
- **Optimistic update**: **적립 완료 체크만**

## Acceptance Criteria

- [ ] 홈에 이번 주 총액과 자산별 금액이 **1,000원 단위**로 표시된다
- [ ] 총액이 가장 크게 표시된다
- [ ] **`renderable: false`에서 배수 카드 대신 회색 박스 + 사유가 나온다**
- [ ] 사유에 "정상 동작입니다"가 있다
- [ ] `trackRecordId`가 있으면 실패 이력 링크가 노출된다
- [ ] **우회 prop이 0건이다**
- [ ] 홈 블록에도 게이트가 적용된다
- [ ] 게이트 미충족 시에도 기본액이 표시된다
- [ ] 근거 한 줄이 지표값 + 밴드명 + 과거 맥락이다
- [ ] **밴드 표가 항상 보이고 현재 위치가 강조된다**
- [ ] 밴드 표가 실제 `<table>`이다
- [ ] `BandGauge`가 색 + 텍스트 동시 표기다
- [ ] Puell이 "배수에 반영되지 않음"과 함께 표시된다
- [ ] **`staleDays >= 3`에서 배지 + 폴백 안내가 나온다**
- [ ] 지표 전체 실패 시 기본액이 표시된다
- [ ] **실패 이력에 MVRV Z 바닥 4/4와 2025-10 톱 미검출이 있다**
- [ ] hits와 misses가 같은 시각적 비중이다
- [ ] 김프 게이지에 프리미엄 %와 원화 비용이 있다
- [ ] 김프 문구가 **사실 서술**이고 지시형이 0건이다
- [ ] **김프 차익거래 안내가 0건이다**
- [ ] `kimchiPremium: null`에서 적립 숫자가 유지된다
- [ ] 적립 완료 체크가 동작하고 **자동 매칭 표시가 0건이다** (ADR-002 · B20)
- [ ] 연속 주차·누적액이 표시된다
- [ ] **미실행 표시에 비난 문구가 0건이고 점수·등급이 0건이다**
- [ ] 적립 완료만 낙관적 갱신이다
- [ ] 설정 저장 후 "다음 계획부터 반영" 안내가 나온다
- [ ] **설정에 배수·임계값 입력 칸이 0개이고 밴드 표가 읽기 전용 + 이유 한 줄이다** (D9)
- [ ] 온보딩에서 월 적립액 하나만 묻고 **저장 후 이번 주 적립이 홈에 바로 나온다** (B12)

- 적립 상세를 **자산 탭 안**에 둘지 **홈에서 push**할지. 3탭 IA에서 별도 탭은 없다 → **홈 블록 → push**가 기본안.
- 밴드 표가 "정적이라 즉시 렌더"라면 **밴드 설정을 클라이언트가 알아야** 한다. 서버 `bandConfig`를 받아야 하므로 완전히 정적이지는 않다. (2026-09-21: 밴드가 전역 읽기 전용 프리셋이 되어 사용자별 차이는 없다 — 캐시가 쉬워졌다)
- 온보딩에서 저장 **전에** "주간 N원으로 환산" 미리보기를 보여 줄지. 보여 주려면 서버 미리보기 API가 필요하다(프론트 환산 금지). 기본안: 저장 후 응답 값으로 표시.

- `Z ≥ 7` 0x가 장기간 이어지면 화면이 계속 "적립 없음"이다. 그때 무엇을 보여줄지.
