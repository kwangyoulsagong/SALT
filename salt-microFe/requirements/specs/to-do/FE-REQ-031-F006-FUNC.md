## Summary

대화의 **SSE 구독·재연결·취소**가 이 REQ의 핵심이다. 그리고 홈은 **읽기 전용**이고 격자는 **저장 실패해도 동작**해야 한다.

## Acceptance Criteria

- [ ] SSE 구독이 훅으로 감싸져 있고 컴포넌트가 `EventSource`를 직접 만들지 않는다
- [ ] `POST` → `messageId` → `GET stream` 흐름이 동작한다
- [ ] **델타가 마지막 말풍선에만 누적된다** (Profiler로 목록 전체 리렌더 0건 확인)
- [ ] 토큰이 프레임 단위로 버퍼링된다
- [ ] 카드가 완성 객체로 한 번에 붙는다
- [ ] `done`에서 스트리밍 해제 + 배지 결정
- [ ] `error`에서 `fallbackText`가 렌더되고 빈 화면이 0건이다
- [ ] 언마운트 시 구독이 해제된다 (유령 구독 0건)
- [ ] 취소 버튼이 구독을 끊고 서버로 전파된다
- [ ] **재연결 시 `POST /messages`를 다시 부르지 않는다** (메시지 중복 생성 0건)
- [ ] 중복 델타가 방어적으로 걸러진다
- [ ] 재연결 3회 실패 시 구독을 끊고 재시도 버튼이 나온다
- [ ] 재연결 중 "연결 중"이 표시된다
- [ ] 메시지 목록이 역순 커서 페이징이다
- [ ] 새 메시지 자동 스크롤이 되고, 위를 보고 있으면 "새 메시지" 버튼이 나온다
- [ ] 전송 실패 시 입력이 보존된다
- [ ] 삭제 시 confirm이 뜨고 자동 삭제가 0건이다
- [ ] 추천 질문 Chip이 즉시 전송된다
- [ ] **홈에 mutation 호출이 0건이다**
- [ ] 블록을 누르면 해당 탭으로 이동한다
- [ ] 블록 순서가 코드로 고정된다
- [ ] 금액 `null`이 `0`으로 표시되지 않는다
- [ ] AI 추천 블록에 게이트가 적용된다
- [ ] 온보딩 미완료 시 카드 1개만 나온다
- [ ] 격자 저장 실패 시 기본 배치로 동작한다
- [ ] 격자 저장이 1초 디바운스된다
- [ ] 손상된 배치가 기본으로 폴백되고 개발 로그에 남는다
- [ ] 1280px 미만에서 격자가 마운트되지 않는다
- [ ] 격자 판단이 마운트 후에 일어난다 (하이드레이션 경고 0건)
- [ ] 키보드 대체 수단이 있다
- [ ] 추천 질문 4개가 `shared/i18n`에 있다
- [ ] 금지 표현 검사가 동작한다
- [ ] 매핑 없는 서버 코드가 원문으로 노출되지 않는다
- [ ] 개발 환경에서 LLM 답변 스캔 경고가 나온다
- [ ] 면책이 답변마다 붙는다
- [ ] **"주문하기" 버튼·거래소 링크가 0건이다**
- [ ] 세그먼트 전환이 soft navigation이고 `시장`을 떠나면 WS가 해제된다
- [ ] 벨 배지가 탭 전환 · 알림 화면 이탈 시 갱신되고 폴링이 0건이다
- [ ] 거래 미리보기가 300ms 디바운스 + 이전 요청 취소다
- [ ] 평단 · 총액 계산 코드가 프론트에 0건이다
- [ ] 거래 쓰기 재시도 · 낙관적 갱신이 0건이고 성공 후 관련 쿼리가 무효화된다

- [ ] 수정 시 종목 · 매수/매도가 잠겨 있다
- [ ] 기간 버튼이 성과 경로만 부른다
- [ ] 알림 읽음 · 모두 읽음이 낙관적 + 실패 시 되돌림이다
- [ ] `target` 매핑이 한 곳에 있다
- [ ] 설정이 그룹별 저장이고 밴드 임계값 입력이 0건이다
- [ ] 온보딩 건너뛰기가 서버 성공 후에만 넘어간다
