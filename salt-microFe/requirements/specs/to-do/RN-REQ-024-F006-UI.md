> **2026-09-21 개정.** `ADR-002` · 스토리보드 갭 감사 반영. 홈 **3블록 + 기존 블록**(D6), 자산 탭 = `포지션` / `시장` / `관심 종목`(D7), 세금 상세 스택 삭제, 알림 1종 화면(D5), 설정 한 화면(D9), 포지션 · 거래 기록 바텀시트 · `RadarChart`(B13 · B14), 온보딩 2단계 교체(B12). 근거: 감사 D4~D9 · B12~B14 · B16 · B19.

## Summary

모바일이 **3탭 IA의 기준**이다(PC 격자는 모바일에 없다). 대화 화면이 제품의 중심이고, 홈은 3블록 + 기존 블록 읽기 전용이다(2026-09-21 개정).

## UX 상태

- **Loading**: 캐시 먼저 → 블록별 스켈레톤
- **Empty (온보딩 미완료)**: 카드 1개
- **Empty (대화 없음)**: 브리핑 카드 + Chip 4개
- **Partial**: 블록별 에러 + 재시도
- **Blocked (게이트)**: "표시할 추천이 없습니다" + 사유
- **Degraded (LLM 실패)**: `fallbackText` + 배지
- **Offline**: 캐시 + 배너. 대화 전송 불가 안내
- **Optimistic update**: 없음

## Acceptance Criteria

- [ ] **하단 탭이 정확히 3개다**
- [ ] 자산 탭 세그먼트가 `포지션` / `시장` / `관심 종목`이다
- [ ] 세금 화면 · 세금 칩 · 청구서 문구가 0건이다
- [ ] `MovableGrid`가 모바일에 0건이다
- [ ] **홈 블록 순서가 고정이다**
- [ ] **375×667 스크롤 전에 총자산·적립·추천이 보인다**
- [ ] 블록 하나 실패 시 그것만 에러다
- [ ] 금액 블록 실패 시 `0`이 0건이다
- [ ] 총자산에 환율 기준 안내가 있다
- [ ] **AI 추천 블록에 게이트가 적용된다**
- [ ] **홈에 mutation 호출이 0건이다**
- [ ] 온보딩 미완료 시 카드 1개만 나온다
- [ ] 오프라인 배너가 시각과 함께 표시된다
- [ ] 대화 첫 진입에 브리핑 카드 + Chip 4개가 있다
- [ ] 답변이 토큰 단위로 흐르고 점 세 개가 나온다
- [ ] 메시지 목록이 `FlatList inverted`다
- [ ] 답변 안 카드가 F004 컴포넌트를 재사용한다
- [ ] **카드에 게이트가 적용되고 미충족 시 텍스트만 나온다**
- [ ] LLM 실패 시 `fallbackText` + 배지가 나온다
- [ ] AI 생성물이 `colors.ai.*` + `Badge tone="ai"`로 구분된다
- [ ] **키보드가 입력창을 가리지 않는다** (두 플랫폼)
- [ ] 전송 실패 시 입력이 보존된다
- [ ] 스트리밍 중 취소 버튼이 있다
- [ ] **면책이 답변에 항상 붙는다**
- [ ] 새 메시지 자동 스크롤이 되고 위를 보고 있으면 버튼이 나온다
- [ ] 오프라인에서 스트림이 시작되지 않고 입력이 보존된다
- [ ] `포지션` · `관심 종목` 세그먼트 전환이 캐시로 즉시 된다
- [ ] **변경 금지 목록 항목이 삭제되지 않았다**
- [ ] 터치 타깃 44×44 이상
- [ ] 대화 목록에 `accessibilityRole="log"`가 있고 매 토큰 낭독이 0건이다
- [ ] **폰트 최대 확대에서 홈 블록과 말풍선이 깨지지 않는다**
- [ ] 헤더에 프로필(→ 설정) · 검색 · 벨(안 읽은 수)이 있다
- [ ] `시장`이 표 1열이고 행 탭이 상세로 간다
- [ ] 포지션 Hero · 4기간 + MDD · 보유 · 레이더 4축이 있다
- [ ] 거래 바텀시트 미리보기가 서버 값이고 키보드가 입력을 가리지 않는다 (두 플랫폼)
- [ ] 거래 수정 · 삭제가 동작하고 삭제에 confirm이 뜬다
- [ ] 알림 읽음 · 모두 읽음이 있고 알림 생성 UI가 0건이다
- [ ] 설정 5그룹, 밴드 임계값 읽기 전용, 계좌 · 세금 · 보류 토글 0건
- [ ] 온보딩 2단계가 거래 시트이고 건너뛸 수 있다
- [ ] 폰트 최대 확대에서 Hero 2×3 · 레이더 표가 깨지지 않는다
