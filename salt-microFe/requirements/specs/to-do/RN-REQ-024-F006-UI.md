## Summary

모바일이 **3탭 IA의 기준**이다(PC 격자는 모바일에 없다). 대화 화면이 제품의 중심이고, 홈은 5블록 읽기 전용이다.

## FSD 배치

| 레이어 | 슬라이스 | 컴포넌트 |
|---|---|---|
| `pages` | `home` · `coach` · `assets` | 3탭 |
| `widgets` | `home-briefing` · `coach-console` · `asset-workspace` | 웹과 같은 이름 |
| `features` | `ask-coach` | 메시지 전송 + SSE |
| `entities` | `coach` | `ChatBubble` · `RecommendationCard`(F004 재사용) · `SuggestedQuestionChips` |
| `src/native` | `deepLink` · `keyboard` | 딥링크 · 키보드 회피 |

## 3탭

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-1 | 하단 탭바 **3개**(`홈`/`코치`/`자산`). **4개로 늘리지 않는다** | Must |
| FR-2 | 자산 탭 세그먼트 3개(`포지션`/`청구서`/`세금`) | Must |
| FR-3 | 세금 상세는 **자산 탭 내부 스택** push(웹의 zone과 다르다) | Must |
| FR-4 | 탭바 터치 타깃 44×44 이상. `accessibilityRole="tab"` + 선택 상태 | Must |
| FR-5 | 블록을 누르면 해당 탭으로 이동한다 | Must |
| FR-6 | **`MovableGrid`를 만들지 않는다.** PC 전용 | Must |

## 대화 화면 — 제품의 중심

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-30 | `ChatBubble` + `TextArea autoResize` + `Chip` + `Spinner`(`@repo/ui-native`) | Must |
| FR-31 | **첫 메시지는 오늘의 브리핑 카드**. 빈 화면 0건 | Must |
| FR-32 | **추천 질문 Chip 4개**를 입력창 위에 가로 스크롤로 | Must |
| FR-33 | 답변이 토큰 단위로 흐른다. `streaming`이고 내용이 비면 **점 세 개** | Must |
| FR-34 | 메시지 목록은 **`FlatList inverted`**(역순). 위로 스크롤하면 과거를 불러온다 | Must |
| FR-35 | 답변 안 추천 카드는 F004의 `RecommendationCard`를 **재사용**한다 | Must |
| FR-36 | **카드에 게이트 적용.** 미충족이면 텍스트만 | Must |
| FR-37 | LLM 실패 시 `fallbackText` + `규칙 기반 설명` 배지 | Must |
| FR-38 | AI 생성물을 `colors.ai.*` + `Badge tone="ai"` + 생성 시각으로 | Must |
| FR-39 | **키보드가 입력창을 가리지 않는다.** `KeyboardAvoidingView` + 안전 영역 | Must |
| FR-40 | 전송 실패 시 **입력을 보존**하고 재시도 | Must |
| FR-41 | 스트리밍 중 **취소 버튼** | Must |
| FR-42 | **면책이 답변에 항상 붙는다** | Must |
| FR-43 | 새 메시지가 오면 아래로 스크롤. 사용자가 위를 보고 있으면 "새 메시지" 버튼 | Must |
| FR-44 | 대화 목록 화면(사이드 메뉴 또는 상단)에서 과거 대화를 연다 | Should |
| FR-45 | 오프라인이면 **스트림을 시작하지 않고 입력을 보존**한다 | Must |

## UX 상태

- **Loading**: 캐시 먼저 → 블록별 스켈레톤
- **Empty (온보딩 미완료)**: 카드 1개
- **Empty (대화 없음)**: 브리핑 카드 + Chip 4개
- **Partial**: 블록별 에러 + 재시도
- **Blocked (게이트)**: "표시할 추천이 없습니다" + 사유
- **Degraded (LLM 실패)**: `fallbackText` + 배지
- **Offline**: 캐시 + 배너. 대화 전송 불가 안내
- **Optimistic update**: 없음

## Acceptance Criteria

- [ ] **하단 탭이 정확히 3개다**
- [ ] 자산 탭 세그먼트가 3개다
- [ ] 세금 상세가 자산 탭 내부 스택이다
- [ ] `MovableGrid`가 모바일에 0건이다
- [ ] **홈 블록 순서가 고정이다**
- [ ] **375×667 스크롤 전에 총자산·적립·추천이 보인다**
- [ ] 블록 하나 실패 시 그것만 에러다
- [ ] 금액 블록 실패 시 `0`이 0건이다
- [ ] 총자산에 환율 기준 안내가 있다
- [ ] **AI 추천 블록에 게이트가 적용된다**
- [ ] **홈에 mutation 호출이 0건이다**
- [ ] 온보딩 미완료 시 카드 1개만 나온다
- [ ] 오프라인 배너가 시각과 함께 표시된다
- [ ] 대화 첫 진입에 브리핑 카드 + Chip 4개가 있다
- [ ] 답변이 토큰 단위로 흐르고 점 세 개가 나온다
- [ ] 메시지 목록이 `FlatList inverted`다
- [ ] 답변 안 카드가 F004 컴포넌트를 재사용한다
- [ ] **카드에 게이트가 적용되고 미충족 시 텍스트만 나온다**
- [ ] LLM 실패 시 `fallbackText` + 배지가 나온다
- [ ] AI 생성물이 `colors.ai.*` + `Badge tone="ai"`로 구분된다
- [ ] **키보드가 입력창을 가리지 않는다** (두 플랫폼)
- [ ] 전송 실패 시 입력이 보존된다
- [ ] 스트리밍 중 취소 버튼이 있다
- [ ] **면책이 답변에 항상 붙는다**
- [ ] 새 메시지 자동 스크롤이 되고 위를 보고 있으면 버튼이 나온다
- [ ] 오프라인에서 스트림이 시작되지 않고 입력이 보존된다
- [ ] 세그먼트 전환 시 서버 호출이 0건이다
- [ ] **변경 금지 목록 항목이 삭제되지 않았다**
- [ ] 터치 타깃 44×44 이상
- [ ] 대화 목록에 `accessibilityRole="log"`가 있고 매 토큰 낭독이 0건이다
- [ ] **폰트 최대 확대에서 홈 블록과 말풍선이 깨지지 않는다**
