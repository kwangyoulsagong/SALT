## Summary

`/home` 은 1920 폭에서도 **휴대폰 화면을 가로로 늘린 모양**이다 — 프로필 칩 → 설정 안내 카드 → "0원" 카드(통계 4칸이 화면 폭에
균등 분배, 각 칸 440px 에 숫자 하나) → 빈 목표 카드 → 투자 분석 → 저축 팁이 한 줄씩 쌓인다(2026-10-30 실측).
2026-09-23 결정 "홈 · 온보딩은 모바일 화면, 데스크톱은 따로"의 **데스크톱 쪽이 아직 없다.**

기준 증권 앱 데스크톱 홈(실측)은 **위 요약 띠(타일 격자 + 오른쪽 일정 상자) → 탭이 있는 목록 + 오른쪽 미리보기 → 화면 오른쪽 고정 사이드**다.
우리 홈의 축은 시세가 아니라 **저축 · 목표**(돈 모으기)이므로, 같은 틀에 우리 내용을 넣는다. 투자 기능 진입점은 홈에 달지 않는다.

| 화면 오른쪽 사이드 상단 카드(계좌 개설 안내) | 흰 카드 모서리 12 · 아이콘 + 2줄 + 링크 | **설정 마치기 안내**(온보딩 카드 — 지금 화면 맨 위 큰 카드) |
