## Summary

`FE-REQ-072`(PR #223)은 홈만 기준 화면 모양(금액 행 · 아이콘 판 · 타일)으로 그렸다. 저축 · 가계부 · 투자 탭과 목표 · 종목 상세 · 코치 리포트 안쪽은
데스크톱 조각을 한 열로 쌓은 그대로라 같은 앱으로 보이지 않는다(2026-11-20 390 실측 — 아래 "전"). 같은 부품(`mobile-design.md` §2)으로 맞춘다.
서버 · BFF 변경 0 — 같은 응답 · 같은 칸, 배치와 표면만.

## 전(2026-11-20 390 실측 · 임시 계정)

| 화면 | 보인 것 |
|---|---|
| 저축 탭 | 요약이 이름 · 큰 숫자 · 줄만(아이콘 판 없음) · 목표 행 판이 원 40 · 도달 한 줄이 "2027 / 년 6월"로 글자 중간에서 끊김 |
| 가계부 탭 | 요약 같은 모양 · 지출 행 판이 원 40 |
| 투자 탭 | 코치 리포트 행이 아이콘 없는 글자 카드 · 코인 로고가 없으면 "KR"(심볼 앞 두 글자 `KRW-…`) · 안내 문장 · 링크가 회색 바탕에 맨글자 |
| 종목 상세 | 머리 = 이름 22 · 작은 아이콘 + 가격 30 + 등락이 한 줄 — 기준 화면의 "가격 아래 등락 줄" 아님 |
| 코치 리포트 | 데스크톱 패널(모서리 16 · 안쪽 선 · 18 제목)이 카드처럼 쌓임 · "‹ 투자" 링크와 제목 "코치 리포트"가 머리와 겹쳐 두 번 · 면책 띠가 화면 아래 고정이라 하단 탭과 겹침 |

| FR-1 | **탭 요약 = 금액 카드** — `MobileSummary` 에 `icon`(3D 아이콘 한 벌 `ServiceIconVariant`) · 주인공 금액 22 Bold(`t3`) + 이름 `t6` 아래 · 나머지 칸은 카드 바닥 줄(위 1px grey100). 저축 = `ranking` · 가계부 = `household`. 주인공이 없으면(요약 실패) 전부 줄 — 실패 문장을 큰 숫자로 보이지 않는 `FE-REQ-060` FR-13 그대로 |
| FR-2 | **휴대폰 목록 행 판 = 아이콘 판 44 · 모서리 12**(`mobile-design.md` §2) — 목표 행 · 지출 행. 종목 로고는 원 40 그대로(`screen-mobile.md` §3) |
| FR-3 | **한국어 줄바꿈은 낱말 단위**(`word-break: keep-all`) — 휴대폰 목록 행 보조 줄 · 요약 값. 기기 글자 ×2 에서도 넘침 0(`overflow-wrap: anywhere` 는 남긴다 — 긴 숫자 한 낱말) |

| FR-5 | **종목 로고 대체 글자** — 마켓 접두어를 떼고(코인 `KRW-BTC` → "BT", 전엔 "KR") · 숫자만인 코드는 이름 첫 글자(국내 `005930` + 삼성전자 → "삼", 전엔 "00"). 데스크톱 · 휴대폰 같은 `@repo/ui` `AssetIcon` 한 곳 |

| FR-8 | **코치 리포트 휴대폰 머리 겹침 0** — 위젯 안 "‹ 투자" 링크 · 제목 줄은 `/m` 에서 숨기고(머리가 이미 뒤로 · 제목) 다시 만들기 버튼만 남긴다 · 면책 띠는 고정이 아니라 맨 아래 흐름(하단 탭과 겹침 0) |
