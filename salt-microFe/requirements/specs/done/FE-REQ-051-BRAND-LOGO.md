## Summary

지금 웹에는 로고가 없다(헤더 자리에 프로필 칩 · 파비콘은 기본 `favicon.ico`). 전역 헤더(`FE-REQ-047` FR-1)의 첫 칸이 로고다.
기준 증권 앱 로고에서 가져온 것은 **구성 원칙**뿐이다 — 단색 계열의 둥근 심볼 하나 + 굵은 글자 로고, 헤더에서 높이 약 20px, 심볼만으로도 알아본다.
모양 · 색 · 글자는 우리 것이다.

## 최종 (2026-11-04 — 사용자 선택)

> **정정 2026-11-04** — 아래 2026-10-30 초안(소금 결정 정육면체)은 쓰지 않는다. 사용자가 큐브 · 알갱이 셋 · 평면 7종 · 평면 5종 시안을 거절했고
> ("큐브야 더 이쁜거 없나" · "기준 앱 느낌으로"), 기준 금융 앱 심볼 원본(.ai · PNG — 사용자 제공)과 실제 로고 SVG 19개를 잰 뒤 다섯째 후보 페이지에서 골랐다.

| 항목 | 값 |
|---|---|
| 심볼 | **소금 물방울** — 물방울 + 아래로 퍼지는 물결 세 겹. 접힌 면 하나(결정의 날)가 빛 받는 면 · 그늘 면을 가른다. 뜻: 흘러가는 돈(물)이 남는 돈(소금)으로 맺히고, 작은 한 방울이 넓게 퍼진다 |
| 색 | **은회색**(흰 소금 결정) — `tokens.colors.brand.mark` `hi #F7F9FC` · `light #E6E8ED` · `mid #CBCFD6` · `deep #ABAFB8` · `shadow #969AA3`, 16px 단색 `flat #83868F`(흰 바탕 3.64:1 — `mid` 는 1.56:1 이라 작은 단색 자리에 못 쓴다) |
| 입체 | 원본 실측 규칙 — 어둡게 칠하지 않고 한 계열 안에서 옮긴다(기준 원본: 색상 207°→229° · 채도 .69~.90 · 명도 .90~.97). 회색은 색상이 없어 밝기로, 아주 살짝 푸른 기(hue 220~224). 빛 · 그늘은 블러로 번지게 · 외곽선 없음 |
| 두 벌 | 원본 체계 그대로 — **입체**(기본, 머리 24 부터 앱 아이콘까지) + **단색**(16px · 한 색 자리). 물결은 큰 자리에만 |
| 글자 | **"Salt"** — 기하학 산세리프 Poppins ExtraBold(SIL OFL 1.1, 사용자 "폰트는 기준 앱 느낌으로" · "Salt로") 글자 모양을 경로로 굳힘. 웹 글꼴을 싣지 않는다. 1단 글자색 / 어두운 바탕 흰색 |
| 파일 | 모양 `@repo/tokens` `BRAND_MARK` · 컴포넌트 `@repo/ui/logo` · 정적 파일은 `pnpm brand:icons` 가 토큰에서 생성(`--check` 검사) — zone 5 `app/icon.svg`(입체) · `apple-icon.png`(180, 흰 바탕 · 입체 + 물결 · 여백 20%) · `favicon.ico`(16 단색 + 32 입체), 사람용 사본 `docs/design-system/brand/*.svg` |

기준 원본에서 확인한 것(모양은 가져오지 않았다): 3D 심볼 `.ai` 3개는 벡터가 아니라 1920×1784 이미지 + 투명 마스크다 · 단색 두 벌은 실루엣이 같다(겹침 0.993) · 상자 가로세로 1.08 · 채움 62% · 여백 10~13%.
실제 로고 SVG 19개(금융 · 결제 · 생활 · 커머스 · 교육) 구조 실측: 그라데이션 0/19 · 색 1~2 · 덩어리 하나 · 은행 곡선 30~43% vs 생활 앱 57~100% — 후보 페이지 `https://claude.ai/artifact/KfsoUSLM9t4DmxDgs4fVpf`(비공개).
