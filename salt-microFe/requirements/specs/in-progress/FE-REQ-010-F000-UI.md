## Summary

F000의 UI 작업은 **깨진 것을 고치는 것**이다. 새 화면은 초대 코드·온보딩 둘뿐이고, 나머지는 수리 9건이다. 그리고 **변경 금지 목록을 침범하지 않는 것**이 이 REQ의 가장 중요한 수용 기준이다.

## 변경 금지 목록 — 먼저 못 박는다

이관·수리 과정에서 **파일이 옮겨질 뿐 렌더 결과가 같아야 한다.** 작업 전/후 스크린샷 비교가 수용 기준이다.

## 구현이 REQ와 다른 지점 (2026-09-18)

**FR-63 을 `role="tablist"` 로 하지 않았다.** 이 필터 버튼들은 탭이 아니다 — 대응하는
`tabpanel` 이 없고 화면을 바꾸지 않는다. `tablist` 로 선언하면 스크린리더가 "탭 1/5"이라
읽고 사용자는 패널 전환을 기대한다. `role="group"` + `aria-label` + `aria-pressed` 로
지금 동작을 정확히 말하게 했다. `radiogroup` 이 의미상 더 가깝지만 roving tabindex 와
화살표 이동을 요구하고, 시각 구성이 변경 금지 목록이라 상호작용까지 바꾸는 것은 범위를
넘는다. **REQ 문구를 고칠지 `SegmentedControl` 로 갈지는 열린 판단이다.**
