## Summary

리서치 §9-4 의 [오늘의 판정] 자리(`FE-REQ-040` FR-9)를 **확률 없이** 채운다. 이름은 "이번 주 목표 비중" — 추천이 아니라 비중 안내다
(`FEATURE-010` OQ 3 결정). 보유 + BTC · ETH 를 변동성만으로 나눈 서버 계산을 그대로 보이고, 규칙의 근거 · 과거 성적 · 빗나간 때를 같은
카드에 접지 않고 둔다. 새 화면 0 — `/investments` 머리 아래 첫 카드.

> 번호: `FE-REQ-041` 은 F011(국내 주식)이 예약했다. 첫 커밋 메시지(`26eef7c` · `e1ef668`)에는 041 로 적혀 있고 `11e7a65` 에서 코드 주석을 고쳤다.

## 설계 원칙

1. **명령형 · 확신 · 목표가 0.** 차는 숫자(원 · 수량)와 "부족 · 초과 · 맞음" 글자. "사세요 · 줄이세요"가 없다. 배지는 중립색 — 상승 빨강 · 하락 파랑을 매수 · 매도 신호로 쓰지 않는다
2. **고지를 접지 않는다.** 비중만 보이고 과거 성적이 한 번 눌러야 보이면 고지가 아니다(슬라이스 3 의 소유자 카드 접기와 다른 판단)
3. **"나았다"는 서버가 참이라고 할 때만.** 타이밍 몫이 증명되지 않았으면 "같은 비중을 고정으로 둔 것과 차이를 증명하지 못했어요"를 쓴다
4. **전체 기준을 밝힌다.** 투자금을 안 적었으면 "코인 평가금 합을 전체로 봤어요 — 현금이 있으면 실제 비중은 더 낮아요" + 투자금 적기 링크
5. 금액 · 비중 · 수량 계산 0 — 표시 형식만(비중은 소수 1자리 %: 7.1% · 5.0% 가 정수 % 로 뭉개지지 않게)
