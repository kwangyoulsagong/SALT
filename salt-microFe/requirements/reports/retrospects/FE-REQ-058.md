# FE-REQ-058 — 회고

## 2026-11-05 — 금융 팁 S2a(`MONEY-S2a-tips-content`)

- **판단**: 공개 zone 은 `AppShell` 이 아니라 `PublicShell` — 768 미만 안내는 앱이 있는 사용자용이고, 검색 유입은 휴대폰 폭이 본문이다.
- **판단**: 때맞춘 팁 칸 연결을 `web-shared` 에 — `domain-*` 끼리 import 할 수 없고 셋이 같은 BFF 칸을 쓴다. 도메인 개념(제도 · 글)은 서버에 두고 shared 는 "서버가 고른 카드 한 장" 계약만.
- **실수**: 클라이언트 파일에서 enum 을 내보냈다 — 타입 · 빌드 · 테스트가 다 통과하고 실화면에서만 400. 셀 수 있어 lint 로 막았다.
- **실수**: ISR 글을 글 응답만 보고 그렸다 — 404 재검증은 캐시를 안 덮어 공개를 꺼도 글이 남았다. 항상 200 인 목록으로 가른다.
- **Action**: 공개 · 비공개가 바뀌는 ISR 화면은 "꺼진 뒤 사라지나"를 실화면으로 잰다(켜진 화면만 보면 못 본다).
