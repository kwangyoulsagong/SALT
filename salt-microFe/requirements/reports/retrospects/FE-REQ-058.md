# FE-REQ-058 — 회고

## 2026-11-05 — 금융 팁 S2a(`MONEY-S2a-tips-content`)

- **판단**: 공개 zone 은 `AppShell` 이 아니라 `PublicShell` — 768 미만 안내는 앱이 있는 사용자용이고, 검색 유입은 휴대폰 폭이 본문이다.
- **판단**: 때맞춘 팁 칸 연결을 `web-shared` 에 — `domain-*` 끼리 import 할 수 없고 셋이 같은 BFF 칸을 쓴다. 도메인 개념(제도 · 글)은 서버에 두고 shared 는 "서버가 고른 카드 한 장" 계약만.
- **실수**: 클라이언트 파일에서 enum 을 내보냈다 — 타입 · 빌드 · 테스트가 다 통과하고 실화면에서만 400. 셀 수 있어 lint 로 막았다.
- **실수**: ISR 글을 글 응답만 보고 그렸다 — 404 재검증은 캐시를 안 덮어 공개를 꺼도 글이 남았다. 항상 200 인 목록으로 가른다.
- **Action**: 공개 · 비공개가 바뀌는 ISR 화면은 "꺼진 뒤 사라지나"를 실화면으로 잰다(켜진 화면만 보면 못 본다).

## 2026-11-05 — 금융 팁 S2b(`MONEY-S2b-tips-quiz-diff`)

- **판단**: 시간 제한 · 점수 · 연속 기록을 두지 않았다 — FEATURE-014 "30초"는 문제 길이 목표로 읽었다. 재촉은 이 앱이 하지 않는 일(통제 · 강제 0)이다.
- **판단**: 바뀐 줄에 빨강 · 초록을 쓰지 않았다 — 이 앱에서 두 색은 오름 · 내림 뜻. 앞 글자 · 취소선 · 바탕 + `<del>`/`<ins>`.
- **실수**: 브라우저 요청 훅을 엔티티 배럴에 올려 공개 서버 페이지 `/tips` 가 4 kB 늘었다 — 규칙(`performance-frontend.md` §7)에 이미 있던 함정. main 과 나란히 빌드해서야 봤다(앞 슬라이스 기록값과만 비교하면 원인을 몰랐다).
- **실수**: 시각 문자열 앞 열 글자를 날짜로 — S2a 부터 있던 결함. 서버가 ISO 시각을 주는 자리는 한국 날짜로 바꿔 읽는다.
- **Action**: 공개 서버 페이지 번들은 main 과 나란히 빌드해 경로별 차이를 적는다(앞 기록값 대조로 대신하지 않는다)
