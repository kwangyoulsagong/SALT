# FE-REQ-036 회고 — 관찰 구간 띠 · 버튼 캡슐

## 1. 무엇을 했나

관찰 구간을 두 차트(캔버스 · SVG)에 옅은 띠 + 이름표로 그렸다. 패널 차트에 구간을 처음 연결했고, 패널 차트 y 범위를
캔들만으로 바꿨다. 상세 차트 조작 버튼을 캡슐 하나로 묶었다.

## 2. 잘 된 것

- **"없다"는 보고를 먼저 재현했다.** 사용자 스크린샷엔 선이 없었는데 로그인 상태에선 그려져 있었다 — 원인은 만료된
  세션이었고, 진짜 문제는 "회색 점선이라 구간으로 안 읽힌다"였다. 재현 없이 고쳤으면 없는 버그를 찾았을 것이다
- 참고 화면의 이름표("스마트 바이 존")를 그대로 옮기지 않고 금지 문구 규칙(FR-21)에 맞췄다 — 모양은 가져오고 말은 지켰다
- 패널에 구간을 넣기 전에 `PreviewChart` 의 "선을 범위에 넣는다" 규칙이 장기 구간에서 캔들을 납작하게 만든다는 걸
  먼저 봤다(상세 차트가 같은 문제를 이미 겪었다)

## 3. 틀렸던 것 · 헷갈렸던 것

- 첫 스크린샷 스크립트가 `role=group` 을 잡아 기간 탭을 찍었다 — 차트 그룹은 `aria-label` 로 좁혀야 한다
- 장기 모드 URL 값이 `long_term`(서버 enum)인데 `longTerm`(뷰모델 키)으로 넣었다

## 4. 남은 기술부채

- SVG 이름표 폭을 글자 수로 어림한다(한글 1em · 그 외 0.6em). 글꼴이 바뀌면 칩이 글자보다 짧거나 길 수 있다
- 캔버스 · SVG 두 차트에 같은 띠 규칙(안쪽 · 위 · 아래 배치)이 두 벌 있다. 프리뷰를 캔버스로 옮길 때 합친다
