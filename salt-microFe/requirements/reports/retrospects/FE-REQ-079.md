# FE-REQ-079 회고

- 첫 실화면에서 칩 "그날 +1.13%" 옆 원문이 "오늘 −2.00%"라 둘이 어긋나 보였다 — 원문은 쓴 시각(장중) 값, 칩은 종가. 칩 문구를 "그날 종가"로 바꿔 갈랐다. 지난 날 화면은 "언제 값인가"를 모든 숫자에 붙여야 한다
- `domain-invest` 에 시험 실행기가 없어 첫 순수 함수 시험이 갈 곳이 없었다 — 다른 도메인 패키지와 같은 `vitest run` 을 붙였다
- 기능 슬라이스끼리 못 부르니(스트림 · 지난 날) 위젯이 오늘 해설을 자식으로 끼우는 모양이 됐다 — 지난 날 동안 오늘 스트림이 아예 마운트되지 않는 효과도 같이 얻었다
- FR-6: "애니메이션이 없다"는 사용자 말은 사실 "그릴 때 돌아서 못 봤다"였다 — 화면 아래 칸의 움직임은 처음부터 보일 때 재생으로. 돌아온 뒤 1회차에 문장 셋이 0 으로 남은 것처럼 잰 것은 목록이 30% 미만으로 걸린 순간이었다(다시 재면 1.65초 전부 1) — 측정은 화면 안 비율을 같이 적어야 같은 값으로 읽힌다
