# FE-REQ-078 회고 — 휴대폰 웹 푸시

## 잘 된 것

- 판정(가능 상태 · 누를 때 순서 · 주소 규칙)을 core 순수 함수로 두고, 문자열 서비스 워커는 가짜 `self` 에서 실제로 돌려 같은 표로 대조했다
- 실 FCM 까지 한 번에 — 서버 암호화를 실제 브라우저가 푼 것이 이 브랜치의 가장 강한 증거

## 고친 것

- 첫 실경로가 구독에서 실패 — 원인은 코드가 아니라 Playwright 일회 문맥(푸시 "permission denied"). 영구 프로필로 바꿔 닫았다. 같은 측정을 다시 할 때 기억할 것
- 토글 누름 칸이 32 — 측정에서 잡고 그림은 두고 누르는 자리만 44 로
- 전체 빌드를 상시 운영 zone 위에 돌려 청크 404 가 났다 — `ops/salt.sh web prod` 로 다시 띄워 닫음. 상시 웹이 떠 있을 때 빌드는 그 스크립트로
