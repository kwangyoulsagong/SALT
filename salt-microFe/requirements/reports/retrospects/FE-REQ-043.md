# FE-REQ-043 회고 — 좁은 화면 안내 (2026-09-30)

## 왜 이렇게 됐나

360 폭 필터 줄 넘침을 고치다가 사용자가 "어차피 모바일은 RN 으로 따로"라고 짚었다. 웹 화면을 좁은 폭에 줄마다 맞추는 비용은
끝이 없고 결과는 앱으로 넘어가지 않는다 — 그래서 좁은 폭은 안내 한 장으로 대신했다. 이미 짜 둔 기간 버튼 줄바꿈은 되돌렸다.

## 잘한 것

- CSS 로만 가른 것 — 서버가 폭을 모르는 한 JS 분기는 깜빡임 · 하이드레이션 불일치를 만든다
- 실측이 카드 눌림(부모 flex 높이)과 main 랜드마크 누락을 잡았고, 페이지 전체에 main 이 없던 기존 문제까지 AppShell 하나로 고쳤다

## 아쉬운 것

- Chrome 확장 미연결로 참고 화면의 전환 폭을 재지 못했다 — 768 은 우리가 정했다(태블릿 세로부터 PC 배치)
- 첫 스크린샷이 고정 데이터 빈 화면이라 쓸 수 없었다 — 안내용 스크린샷은 값을 채운 픽스처로 따로 찍었다

## Action

- 사용자가 실제 계정 캡처를 주면 `public/narrow-screen/*.webp` 교체
- RN 앱이 생기면 안내에 앱 링크(지금은 없음)
