# FE-REQ-059 — 회고

- 문구만 바꾸는 REQ 였지만 실스택에서 맥 잠자기로 스트림이 끊기자, 이미 흘린 Claude 문장에 "규칙 기반 설명" 배지가 붙었다 — 화면이 출처를 `done` 에서야 알았기 때문. 서버가 스트림 시작 단계에 `provider` 를 싣게 해 닫았다(SRV-REQ-050 FR-13)
- 모바일 백그라운드 전환 · 네트워크 끊김도 같은 길이다 — 실측에서 잠자기가 그 경우를 대신 재현했다

## Action

- 스트림 상태 정산(`settle`)은 "끝까지 못 받은 경우"의 표시를 같이 정한다 — 출처를 끝 이벤트에만 두지 않는다
