# FE-REQ-041 회고 — 국내 주식 화면 (2026-10-08)

## 잘 된 것

- **자산군을 매개변수로 만들어 화면을 하나로 뒀다.** 국내 주식 행을 코인 행 모양으로 바꾸는 어댑터 하나(`krQuoteToOverviewItem`)로
  표 · 필터 · 미리보기 · 깜빡임 · 별을 그대로 썼다. 다른 것은 데이터 소스 · 구독 · 머리 첫 칸 · 배지뿐이다
- 서버 · BFF 계약 확장(고가/저가 · 필터 · 관심 종목)을 같은 날 병렬로 붙였다 — 화면이 같으려면 데이터가 같아야 했다
- 실측이 기존 버그를 잡았다 — 별 클릭이 행 클릭으로 번져 상세로 넘어갔다(코인에도 있던 것). 따로 커밋해 되돌림 단위를 나눴다

## 아쉬운 것

- **첫 판을 기획서 표 그대로(세 번째 탭 · 다른 열 · 검색 상자) 만들었다가 사용자 지적으로 다시 짰다.** "국내 주식이랑 비트코인 다 같은 기능"(2026-10-07)이
  이미 있었다 — 기획서 화면 표보다 사용자 문장이 우선이다
- 실시간 반영 훅이 첫 렌더의 캐시 키를 잡고 있었다(필터를 바꾸면 옛 캐시를 고칠 뻔) — 리뷰 중 발견해 `ref` 로 고쳤다. 구독 수명과 콜백 수명이 다르면 처음부터 `ref`

- **고정 응답 상태 확인이 라이브 정규장 테스트가 못 본 버그 4건을 찾았다**(첫 열 넓힘 · 밤의 "1분" 배지 · 지연 줄 누락 · 줄 대비). 라이브는 그날 그 시각 상태 하나만 보여 준다 — 상태 분기가 있는 화면은 상태마다 고정 응답으로 본다
- **`object-fit` 을 실제 이미지 없이 고르지 않는다.** 글자 로고가 잘려 `contain` 으로 바꿨더니 FMP 이미지의 자체 배경 사각형이 드러나고 글자가 읽히지 않아 되돌렸다. 화면 품질의 원인은 맞춤 방식이 아니라 소스(정사각 심볼 vs 가로 글자 로고)였다
