# FE-REQ-076 회고 — 데스크톱도 휴대폰 같은 느낌으로(1단계)

- 판(`PageFrame surface="cards"`) 하나에 공용 `panel` · 사이드 자식 카드 규칙을 걸어, 설정 · 알림 · 사이드는 화면 코드를 거의 안 고치고 맞았다 — 휴대폰 `/m` 표지와 같은 "공용 자리에서 한 번" 방식
- 실수: Playwright 전체 페이지 캡처가 등장 애니메이션 중간을 찍어 "미리보기가 비었다"는 결함을 한 번 의심했다 — 계산 스타일로 확인하니 정상. 화면 결함 판정은 스크린샷 하나로 하지 않고 계산 값으로 한 번 더 본다
- 1024 에서 금액 카드 타일이 접히며 왼쪽 선이 남았다 — 접힘은 폭으로 가른다(래핑 상태는 CSS 로 못 본다)
- 할 일: 2단계(하위 화면 · 팁) — 같은 판 · 카드 · 아이콘 판
- 검증 2회차: 1회차가 데이터 있는 계정 · 다섯 화면만 봐서 빈 상태 둘(회색 위 회색 상자 · 카드 안 선)과 대기 칸 높이를 놓쳤다 — 판 · 표면을 바꾸면 빈 상태 · 대기 칸을 같은 회차에 본다
