# FE-REQ-042 회고 — 이번 주 목표 비중 (F010 슬라이스 5, 2026-09-29)

## 잘 된 것

- 고정 데이터를 손으로 만들지 않고 **실데이터 서버 응답 → BFF 뷰모델**로 만들었다. 화면이 받는 모양이 실제 계약과 같다
- "투자금 없음"과 "투자금 있음" 두 벌을 같이 봐서 **모두 초과로 보이는 첫 화면**이 어떻게 읽히는지 먼저 확인했다 — 기준 문장을 줄 목록 위에 둔 이유다
- axe 를 카드 범위로 좁혀 이 카드가 만든 위반만 보았다(첫 판은 문서 전체라 기존 위반에 묻혔다)

## 아쉬운 것

- 폼 새 칸 두 개를 화면에서 눌러 저장해 보지 않았다(토큰 없음)
- 카드가 360 폭에서 길다(고지를 접지 않은 대가). 고지를 한 줄 요약 + 자세히로 줄이는 안은 "고지는 늘 같이" 원칙과 부딪혀 두지 않았다

## Action

- 화면 슬라이스 validate 에 "카드 범위 axe" 스크립트를 쓴다(문서 전체 axe 는 기존 위반을 섞는다)
- 로그인 QA 때 폼 저장 → 목표 비중 무효화 → 카드 갱신을 한 번에 본다

## FR-9~13 (2026-09-29)

- 슬라이스 5 에서 "고지를 접지 않는다"를 지키려고 카드 전체를 투자 화면에 펼쳤고, 876px 카드가 시세 표를 두 화면 반 아래로 밀었다. 사용자가 스크린샷으로 지적했다. 고지를 접지 않는 원칙과 투자 화면의 본업은 **다른 자리에 두면** 둘 다 지켜진다 — 본문은 리포트, 투자 화면엔 고지 한 줄이 붙은 요약
- Action: 새 코치 카드를 투자 화면에 넣기 전에 첫 화면 높이를 잰다(시세 표 시작 위치를 체크리스트에 남긴다)
