## 1. 결론 먼저

- 참고 화면의 검색은 **어느 화면에서나 머리 검색칸 → 모달**(`/` 단축키)이고, 우리는 **페이지 `/search`** 다. 모달로 바꾸면 투자 화면을 떠나지 않고 찾는다.
- 모달 첫 화면은 **최근 검색 칩 → 인기 순위 → 뜨는 산업 순위**, 입력하면 **두 칸**(왼쪽 결과 묶음 · 오른쪽 고른 행의 곁 정보) + **키보드만으로 끝까지**(↑↓ · Enter · Esc 두 단계).
- 글자 · 면 · 모서리 값은 우리 데스크톱 위계(`screen-desktop.md` §2 — 14/600 · 13/600 · 12/500)와 **같은 값**이라 새 토큰이 거의 없다. 다른 것은 모달 면 `#FBFCFD`(지금 토큰 없음 — `FE-REQ-047` FR-14 예정) 하나.
- "투자 탭은 헤더로"는 두 뜻이 가능하다(§6) — **사용자 결정 대기**.

## 4. 실측 — 입력 중("삼성")

| 항목 | 값 |
|---|---|
| 결과 탭 | 전체 · 종목 · 산업 · 뉴스 · 지수(`role=tab` · 선택 표시는 글자 + 밑줄) |
| 배치 | **두 칸** — 왼쪽 결과(약 337 폭) · 오른쪽 "고른 행의 곁 정보"(예: "삼성전자 뉴스에서 언급된 관련주" — 종목 3 · 등락률) |
| 결과 묶음 | "종목" 묶음(14/500 2단 이름) → 5개 + "종목 더 보기 >"(12/600) → "뉴스" 묶음(제목 하이라이트 · `N시간 ・ 출처`) |
| 종목 행 | `role=option` `<a>` 54 높이 · 로고 30 원 · 이름(일치 부분 `<mark>` 파랑 `rgb(49,130,246)` 700) · 코드 12/500 `#6B7684` · 오른쪽 현재가 14/600 · 등락률 · **고른 행 = 면 `rgba(2,32,71,.05)` 모서리 8 + 오른쪽 ↵ 칩** |
| 키보드 | 포커스는 늘 검색칸 · ↑↓ 가 고른 행을 옮긴다(면만 옮김 — `aria-activedescendant` · `aria-selected` 없음) · Enter 이동 · **Esc 두 단계 — 첫 번째 = 글자 지움(모달 유지), 두 번째 = 닫힘** |
| 닫힌 뒤 | 포커스 = 머리 검색 단추로 돌아온다 · 주소 바뀜 0(열고 닫아도 `/`) |
| 빈 결과 | "'{말}' 검색결과가 없어요." + 점 두 줄(철자 확인 · 상장 · 거래 안 되는 종목은 안 나올 수 있음) |

| | 안 A — 투자 zone **하위 내비만** 머리로 | 안 B — **도메인 레일 자체를** 머리로 |
|---|---|---|
| 바뀌는 것 | 머리 52 안에 "투자 분석 · 코치 리포트 · (검색칸)" 링크(14/600 · 36 높이). 지금 투자 화면 머리 줄 링크 둘을 옮긴다. 레일(홈 · 저축 · 가계부 · 투자)은 그대로 | 레일 72 를 없애고 머리에 "홈 · 저축 · 가계부 · 투자" 링크 + 검색칸. 본문 폭 +72 |
| 다른 zone | 저축 · 가계부 · 팁은 무변경(각 zone 이 머리 하위 내비를 원하면 같은 틀) | 다섯 zone 전부 · `AppNavigation` · 하단 탭(768~1023) 관계 · prerender · 문서 간 전환 이름(`view-transition-name`) |

| 비용 | 작다(투자 zone + `AppNavigation` 머리 슬롯 하나) | 크다(공용 크롬 · 다섯 zone 동시 배포) |

## 7. 설계안(결정 뒤 확정)

**검색 모달(`FE-REQ-066`)**
- `features/search-asset` 를 모달로 — `@repo/ui` `Modal` 위에 새 크기 `"search"`(640 · max-height 600 · 위 8 · 모서리 16 · 배경 막 없음) 또는 검색 전용 판. 포커스 가둠 · 스크롤 잠금은 `Modal` 것을 재사용. **배경 막 없음은 우리 결정으로 막을 둔다**(옅게) — 키보드 · 스크린리더 사용자가 모달 밖을 읽지 않게 `aria-modal`(참고 화면은 없음)
- `/` 단축키(입력칸 · 글 편집 중이 아닐 때) · 머리 검색칸 누름 · 기존 `/search` 경로는 모달을 연 상태로 그리는 진입점으로 남긴다(링크 · 새로고침 호환)
- 첫 화면: 최근 검색 칩(× 지우기 · 기기 저장 그대로) → "거래대금 상위"(국내 · 코인 — 탭 또는 두 묶음, 로고 28 · 순번 · 이름 · 등락률) → 뜨는 업종(국내만, 원천 생긴 뒤)
- 입력 중: 탭(전체 · 종목 — 산업 · 뉴스 · 지수는 원천 생긴 뒤) · 결과 행 54(로고 30 · `<mark>` 하이라이트 · 코드 · 현재가 · 등락률 · ★ 추적 — 우리만 있는 칸) · 오른쪽 곁 칸은 2단계(원천 경로 뒤)
- 키보드: 포커스 검색칸 고정 · ↑↓ = `aria-activedescendant` 로 고른 행(참고 화면엔 없는 접근성 — 우리는 단다) · Enter = 상세로 · Esc 두 단계 · 닫으면 연 자리로 포커스
- 아래 안내 바(키 칩 셋) — 문구 해요체
- 빈 결과: "'{말}' 검색 결과가 없어요" + 한 줄(철자 · 추적 가능한 종목만)
- 390 웹뷰: 같은 내용 한 열 시트

**머리 내비(`FE-REQ-067`)** — §6 안이 정해진 뒤. 공통: 링크 14/600 · 36 · 패딩 8×12 · 모서리 9 · 선택은 진하기만(1단 ↔ 2단) · `aria-current="page"`(참고 화면은 없음 — 우리는 단다) · 검색칸 200×32.
