## 1. 결론 먼저

- 참고 증권 웹 둘 모두 **보유(계좌 · 자산)를 시세 · 분석과 떼어 최상위 메뉴 하나**로 둔다. 우리는 보유가 코치 리포트 맨 위 칸이라 관례와 어긋난다 → `/portfolio` 를 뗀다
- 같은 자산 종류 안의 나라(국내 · 해외)는 두 곳 모두 **머리가 아니라 필터**(표 위 세그먼트 · 필터 칩 · 시장별 묶음)다. 거래 체계가 다른 자산 종류(우리: 코인 vs 주식)는 머리 탭으로 가른다(사용자 결정)
- 도메인 이동(홈 · 저축 · 가계부 · 투자)은 왼쪽 레일로 되돌리고, 머리는 그 도메인의 메뉴 자리(투자 zone 만 채운다)

## 2. 실측 — 참고 웹 A(2026-11-10, 1568 폭, 로그아웃)

| 항목 | 값 |
|---|---|
| 전역 머리 | 홈(`/`) · 피드(`/feed/recommended`) · 주식 골라보기(`/screener`) · 내 계좌(`/account` — 로그인으로 돌림) + 검색칸("/ 를 눌러 검색하세요") · 로그인 |
| 홈 본문 탭 | 실시간 차트 · 지금 뜨는 산업 · 외국인·기관 매매 동향 → 그 아래 **전체 · 국내 · 해외 세그먼트** + 정렬 칩(거래대금 · 거래량 · 급상승 …) |
| 골라보기 | 왼쪽 목록(연속 상승세 · 저평가 성장주 …) · 표 위 **필터 칩 "국내 ▾"** · 시가총액 · 산업 칩 |
| 오른쪽 레일(모든 화면) | 아이콘 넷 — **내 투자** · 관심 · 최근 본 · 실시간 · 접기(`»`). 펼친 칸 = 관심 TOP 10 등 |
| 종목 화면 탭 | 차트·호가 · 종목정보 · 뉴스·공시 · 거래현황 · 커뮤니티 · 아래 고정 지수 띠(국내 둘 · 해외 넷 · 변동성) |

공개 자료(로그인 화면): 내 계좌 = 보유 종목 · 계좌 잔고. 주문 내역은 앱 기준 국내 · 해외 · 채권 칩. 2025-10 웹 개편으로 홈이 시장 정보(지표 · 실적 일정 · 지수 · 실시간 차트) 위주. 앱 홈은 "내 주식"(보유 · 관심) · "오늘의 발견" 두 탭(2022 개편).

## 4. 우리에게 옮기면

| 결정 | 근거 |
|---|---|
| 왼쪽 레일 복원 — 도메인 넷(`FE-REQ-054` 판) | 사용자 "헤더바 좌측은 유지". 머리는 도메인 안 메뉴 자리 |
| 투자 zone 머리: **코인 · 주식 · 포트폴리오 · 리포트 · 코치 설정** + 검색칸 | 자산 종류 = 탭(사용자) · 보유 따로(A · B) · 리서치 따로(B) · 코치 설정은 머리 끝(사용자) |
| "주식" — 소유자만 보인다 | 자산 종류 이름. 같은 자산 안 나라 구분은 필터 자리(A 세그먼트 · B 시장 묶음) — 이번 범위 밖 |
| 이름 "포트폴리오"("내 계좌" X) | 우리는 계좌 연동이 없다 — 손 기록(연동 문구 금지 결정) |
| `/portfolio` 새 페이지 = 내 보유 + 매입가 숨김 · 리포트 = 성적 · 추천 · 미러 | A · B 모두 보유를 따로. 같은 페이지 두 링크는 "지금 위치"가 애매 |
| 검색칸은 투자 zone 만 | 사용자 "검색은 투자에서만". 다른 zone 머리 = 로고 · 프로필 |
| 본문 코인/국내 탭 · "내 코치 리포트 ›" 삭제 | 머리로 올라감 — 두 벌 금지 |
| (나중) 오른쪽 레일 "내 투자" 요약 | A 패턴 — 이번 범위 밖, 투자 화면 오른쪽 칸이 이미 코치 패널 |
