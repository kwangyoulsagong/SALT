# 뉴스 목록 · 상세 모달 실측 — 참고 국내 증권 앱 웹(2026-11-09)

사용자 요청(2026-11-09): "뉴스 프리뷰 UI 를 참고 화면처럼 만들려 했는데 프리뷰에 뭔가 안 맞아 — 폰트나 그런 것들. 뉴스 상세도 모달을 띄워 똑같이."

> 측정: 참고 국내 증권 앱 웹의 종목(반도체 대형주) 뉴스 탭, 창 1920 × 854, Chrome `getComputedStyle` · `getBoundingClientRect` 값만 적었다(추정 0).
> 서비스 이름 · 주소는 적지 않는다(`no-reference-brand-in-docs`).

## 4. 우리 데이터 — 참고 화면에 있지만 못 하는 칸

|---|---|---|
| 제목 · 출처 · 시각 | 있음 | 있음 |
| 요약 두 줄 | **없음**(원천에 본문 · 요약 없음) | 있음(`summary`, RSS 요약) |
| 썸네일 | **없음** | 있음(`imageUrl`, 절반쯤 비어 있다 — `FE-REQ-010` FR-41) |
| 본문 | **없음 · 받지 않는다**(`ADR-009` 저작권 선 — 본문 수집 0) | `content` 칸이 있으나 **화면에 싣지 않는다** — 참고 화면은 제공처와 계약한 본문을 보여 준다(끝의 재배포 금지 줄). 우리는 계약이 없다. RSS 가 준 요약까지가 우리 선이고 본문은 원문 링크로(`ADR-009` 와 같은 판단, 사용자 결정 표 D3) |

| 출처 로고 | 없음(이름 글자) | 없음 |

## 6. 구현 설계

**프리뷰 뉴스 행(코인 · 국내 같은 컴포넌트)** — `entities/market/ui/NewsRow`(표시 전용):
- 칸: 제목(14/600, 한 줄) · 요약(13/500, 두 줄 — 있을 때만) · `출처 ・ N분 전`(12/500, 2단) · 썸네일(오른쪽 72 × 60, 있을 때만) · 공시/시황 칩(국내만, 메타 줄 끝)
- 행 전체가 단추(`<button>` — 모달을 연다). 원문 링크는 모달 안에만(행에 링크 둘을 두지 않는다)
- 프리뷰는 한 장(지금 규칙 `PREVIEW_LIMIT=1` · 높이 고정 — 참고 행 높이 100 에 맞춰 자리 높이를 고친다), 상세 "오늘 소식"은 같은 행을 목록으로
- `MarketNewsPreview` · `KrNewsPreview` · `KrStockNews` 가 같은 행을 쓴다(세 벌 → 한 벌). `NewsBadge` 오타는 같이 고친다

**뉴스 상세 모달** — `features/read-news`(새 feature — 모달 열기 · 닫기 · 주소 쿼리는 상호작용):
- `@repo/ui` `Modal` 재사용 — 포커스 가둠 · 스크롤 잠금 · Esc 는 이미 있다(`useFocusTrap` · `useScrollLock`). 더할 것: `size` 변형 `"article"`(680 · 위아래 40 · 모서리 16 · 면 `#FBFCFD`) · 머리 아래 고정 칸(칩 줄) 슬롯 · 본문만 스크롤
- 열면 제목에 포커스(`tabIndex=-1`) · 닫으면 연 행으로 돌린다(참고 화면은 `<body>` 로 — 우리는 돌린다)
- 주소: `?news=<id>` 하나(참고 화면처럼 새로고침 · 뒤로가기로 열고 닫힌다). `router.replace` 로 쿼리만 — 페이지 이동 0. 국내 id = 원천 일련번호, 코인 id = 기사 id
- 국내 갈래: 머리(제목 · 제공처 · 시각 · 공시/시황 칩) → 관련 종목 칩 줄(BFF 가 이름 · 등락률을 붙인 값) → "원문은 제공처에서 볼 수 있어요" → "오늘 소식"(같은 종목 나머지, 누르면 모달 안에서 바뀜)
- 코인 갈래: 머리 → 칩 줄(기사 태그 코인) → 썸네일(있으면, 폭 100% · 모서리 16) → 요약 → **원문 보기**(새 탭 · `noopener noreferrer`) → "주요 뉴스"
- BFF: 국내는 기사 하나 조회 경로가 없다 → `GET /api/app/market/kr/:code/news/:serial`(제목 · 관련 종목 이름 · 등락률 — 서버 market 저장값만). 코인은 `/api/app/news?symbol=` 목록에서 id 로 고르거나 같은 꼴의 하나 경로. 둘 다 `FE-REQ-065` 짝 REQ(BFF · 서버)로
- 390 웹뷰: 같은 내용을 `BottomSheet` 로(`screen-mobile.md` — 바텀 시트)
