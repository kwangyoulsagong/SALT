# SRV-REQ-055 회고 — 검색 모달 2단계 서버 경로

## 2026-11-10

- **원천을 먼저 셌더니 계획이 바뀌었다** — 리서치 §5 는 "시황 제목의 관련 종목"을 원천 있음으로 적었지만 실제 행은 제목 하나에 종목 하나였다(함께 언급 0). 구현 전에 `GROUP BY serial HAVING count > 1` 한 줄로 알았고, 사용자에게 바로 물어 곁 칸 근거를 바꿨다. **리서치의 "있음(원천)"은 칸이 있다는 뜻이지 쓸 만한 값이 있다는 뜻이 아니다** — 분포를 센다
- 지난 날에 멈춘 업종이 오늘 순위에 끼는 것을 실데이터에서 봤다(`0027` 11-06 −7%). 순위를 만드는 규칙은 "가장 늦은 거래일 값만"으로 도메인에 두고 테스트로 걸었다
- `Object.keys` 가 숫자 모양 키(`"1001"`)를 앞으로 보내 지수 순서가 뒤집혔다 — 순서가 뜻인 목록은 배열 상수로
- 실호출 중 제목 제어 문자를 봤고 같은 날 고쳤다(`0df7784e`, 주인 `SRV-REQ-051`)
