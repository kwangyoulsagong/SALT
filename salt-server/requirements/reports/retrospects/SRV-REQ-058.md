# SRV-REQ-058 회고 — AI 가 읽는 기사 본문

## 2026-11-14 — 2a

- **스펙의 90% 는 약관을 읽기 전에 정한 숫자였다.** robots 만 보면 국내 9곳이 남았는데 약관을 읽자 3곳이 됐다. 원천 목표는 원문(robots · 약관)을 먼저 읽고 정한다 — 숫자를 먼저 정하면 그 숫자를 맞추려고 원천을 넓히게 된다
- **같은 이름 ≠ 같은 원천.** KIS 제공처 '인포스탁' 과 인포스탁데일리 RSS 는 다른 상품이었다. 이름표로 묶기 전에 실데이터 제목 몇 개를 나란히 본다
- 판정 결과를 표에 쓰되 **원본은 코드 한 곳**(`Outlets.ts`) — 약관 메모가 PR 리뷰를 지나간다
- 다시 쓰는 upsert 는 처음부터 `WHERE … IS DISTINCT FROM`(`noBlindCandleRewrite` 와 같은 원칙) — 회차마다 245행을 다시 쓰지 않는다

## 2026-11-14 — 2b
