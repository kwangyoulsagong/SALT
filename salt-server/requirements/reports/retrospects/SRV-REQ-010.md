# SRV-REQ-010 retrospects

## 2026-10-29 REQ 전수 조사

- 현재 상태를 말하는 문장이 뒤 슬라이스를 따라가지 못했다. Action: 슬라이스를 닫을 때 그 결과가 바꾸는 다른 REQ 의 본문 · 범위 밖 · 수용 기준을 grep 한다

## 2026-10-30 — F000 레거시 모델 drop · 중복 워커 정정 (루트 `F000-legacy-cleanup`)

- FR-34 "BFF 단일 경로"는 코드에 없던 경로를 수용 기준으로 적은 것이었다. Action: SRV-REQ-007 회고와 같음

## 2026-11-02 — 뉴스 워커 상시화

- 이 REQ 가 "유지"로 판정한 워커를 아무도 띄우지 않았다 — 유지 판정에 "누가 띄우나"가 빠져 있었다. 워커 표를 쓸 때 실행 주체(서버 프로세스 안 · launchd · 수동) 열을 같이 적는다
## 2026-11-02 — 재시작 고아 정리

- 서버에서 드러난 고아 문제를 같은 장치(launchd)로 도는 이 프로세스에도 같은 스크립트로 막았다 — 증상이 안 보였어도 같은 구조면 같이 고친다
