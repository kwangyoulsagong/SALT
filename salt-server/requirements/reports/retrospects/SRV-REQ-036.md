# SRV-REQ-036 — 회고

- 저장 시세에 기준가 컬럼이 없어 등락 금액을 변동률로 되짚었다. 거래소 값과 몇 천 원 어긋날 수 있다(저장 시각 차이) —
  WS 가 거래소 값으로 덮는다. 기준가를 저장할지는 요약이 쓰이는 모습을 본 뒤 정한다
- 번호: 처음 `SRV-REQ-011` 로 적었다가 이미 있는 번호라 바꿨다. **새 REQ 번호는 폴더 전체에서 확인하고 붙인다**

## Action

- 캐시 만료 동시 호출이 거래소 제한에 걸리는지 운영 로그로 확인 — 걸리면 `pacer` 를 태운다
