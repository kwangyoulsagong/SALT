## 2026-11-19 FR 대조 정리 (`WEB-perf-req-close-slice.md`)

- "동기 해소"로 덮어 둔 FR 하나(FR-1 피드백 거르기)가 실제로는 막아야 할 결함을 그대로 품고 있었다 — 원장으로 바뀐 건 성적표뿐이고 최신 추천 조회는 그대로였다. Action: REQ 를 "해소"로 표시할 때 FR 마다 대체한 코드 위치를 적는다. 위치를 못 적는 FR 은 해소가 아니다
- 같은 측정 요구가 DB · SRV 두 REQ 에 두 벌 있었다(종목 판단 패널). Action: 성능 REQ 를 쓸 때 지연 · 쿼리 수 예산은 SRV 한 곳에 두고 DB REQ 는 인덱스 · 계획만 갖는다
