# SRV-REQ-047 — 회고

## 2026-11-05 — 금융 팁 S2a(`MONEY-S2a-tips-content`)

- **판단**: 원문은 레포 파일 — 열린 질문(MDX vs DB)을 1안으로 닫았다. 마크다운 전부가 아니라 제목줄 · 문단 · 목록 셋만 읽어 구조로 내린다(HTML 0 · 링크는 출처 한 칸).
- **판단**: 발행 검사를 빌드와 기동 둘 다에 — 빌드만이면 손으로 고친 jar 가, 기동만이면 PR 리뷰가 늦게 안다.
- **판단**: 공개 플래그가 꺼져도 제도 파라미터 조회는 연다 — 계산이 읽는 숫자이고 글이 아니다.
- **실수**: 회사 이름을 목록으로 늘어놓다 참고 서비스 이름이 코드에 들어갔다(`check-done` 6번) — 업권 꼬리 꼴로 바꿨다. 목록보다 꼴이 넓게 잡는다.
- **실수**: 통합 테스트에 공개 플래그 다른 컨텍스트를 둘 더 띄웠더니 Postgres 연결 상한(53300)으로 저축 테스트가 깨졌다 — 컨텍스트 하나에 켜 두고 꺼짐은 유스케이스 테스트로.
- **Action**: 새 SpringBootTest 설정을 만들기 전에 기존 컨텍스트를 쓸 수 있는지 본다(서비스 풀 5 × 컨텍스트 수).

## 2026-11-05 — 금융 팁 S2b(`MONEY-S2b-tips-quiz-diff`)
