# SRV-REQ-050 — 회고

## 요약

- 요구는 "공급자 라우팅"이었지만 사용자가 실제로 느낀 문제는 **스트리밍이 아니었다는 것**이었다 — 템플릿을 한 틱에 쏟고 끝에 통째로 갈아 끼우니 아무것도 흐르지 않았다. 라우팅이 더 큰 모델을 들여오자 그 모델의 토큰 스트림을 문장 단위 검사와 묶어 진짜 스트림으로 바꿨다. "검사 전 원문 0"(FR-47)은 그대로다
- 실측이 결함 셋을 냈다 — 금액 방향 오탐 · RSI 14자리 · 잠자기로 끊긴 스트림의 잘못된 표시. 단위 테스트로는 하나도 안 보였다
- **평가지 사실 누락이 또 결과를 뒤집었다**(1회차 1:16 → 2회차 16:1). 지난번 회고의 "평가지 입력 사실은 모델이 받은 것과 같아야 한다"를 프롬프트에 새 줄(관찰 기간)을 더하며 다시 어겼다

## Action

- ~~프롬프트에 줄을 더하면 평가지 `facts()` 에도 같은 줄~~ **닫음(같은 날)** — 평가지가 모델 입력 블록(`lineFactsText`)을 그대로 쓴다. 두 곳에 적지 않는다
- 실화면 판정은 측정값으로 — 요소 스크린샷이 애니메이션 도중을 찍어 "흐림"으로 보였다
- 오래 도는 실측은 `caffeinate -i` 아래에서 — 맥 유휴 잠자기(15분)가 스트림을 끊었다
