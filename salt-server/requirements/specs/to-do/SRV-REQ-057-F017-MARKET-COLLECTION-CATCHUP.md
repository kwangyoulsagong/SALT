## 불변식

1. **잠은 결함이 아니다, 깬 뒤 못 메우는 것이 결함이다** — 깬 뒤 30분 안에 코인 · 국내 모두 구멍 0
2. **같은 봉을 두 번 쓰지 않는다** — `price_history` `DO UPDATE` 는 `WHERE` 필수(`noBlindCandleRewrite.test.ts`) · 행 쓰기는 한 문장(`noParallelRowWrites.test.ts`)
3. **거래 없음 ≠ 구멍** — 업비트는 체결이 없으면 봉을 만들지 않는다. 구멍은 "거래소가 봉을 준 구간"에서만 센다
4. **연결 풀 일부만** — 따라잡기는 회차 상한(코인 600호출 ≈ 75초)으로 나눠 장중 API 를 막지 않는다(`workers-external.md`)
