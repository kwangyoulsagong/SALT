## 불변식

1. **잠은 결함이 아니다, 깬 뒤 못 메우는 것이 결함이다** — 깬 뒤 30분 안에 코인 · 국내 모두 구멍 0
2. **같은 봉을 두 번 쓰지 않는다** — `price_history` `DO UPDATE` 는 `WHERE` 필수(`noBlindCandleRewrite.test.ts`) · 행 쓰기는 한 문장(`noParallelRowWrites.test.ts`)
3. **거래 없음 ≠ 구멍** — 업비트는 체결이 없으면 봉을 만들지 않는다. 구멍은 "거래소가 봉을 준 구간"에서만 센다
4. **연결 풀 일부만** — 따라잡기는 회차 상한(코인 600호출 ≈ 75초)으로 나눠 장중 API 를 막지 않는다(`workers-external.md`)

## 구현 결정 (2026-11-11)

1. **위치에서 앞으로** — FR 원문 "to 를 거꾸로" 대신 위치부터 앞으로 200칸씩. 쪽마다 위치가 옮겨져 회차 상한에 잘려도 다음 회차가 잇는다(거꾸로면 잘린 회차의 일이 위치에 안 남아 다음 회차가 같은 쪽을 다시 받는다). 최근 16시간 40분은 정기 수집 몫이라 지표가 먼저 사는 이점은 그대로
2. **정기 수집이 위치를 옮긴다 — 창이 닿을 때만**. 깬 첫 회차가 최신 200개를 받아 `max(timestamp)` 가 지금이 돼도 구멍이 가려지지 않는다
3. **유니버스 합류 = 직전 날 스냅샷과 비교**(FR-7 표). 첫날은 비교할 날이 없어 0
4. **KIS 모의 1건/s · 동시 상한 없음** — 측정 표는 FR-3 줄. 초과 쉬기를 호출 안에서 하던 것이 쉬기 끝에 줄을 한꺼번에 내보내 초과를 되풀이했다(`0c7714f5` — 페이서 `pauseUntil`)
5. **코인 장기 이력 꼬리표는 일봉 수로**(≥ 50) — MA50 이 비었어도 봉이 50 이상이면 지표 갱신 밀림(신선도 꼬리표 몫)이지 이력 탓이 아니다. 문구 · 계약은 국내 `insufficient_history` 그대로
6. 뉴스 워커(별도 프로세스)도 같은 잠 감지 — 1시간 타이머가 자는 동안 멈춰 깬 뒤 최대 1시간 비었다(11-11 04:27 → 08:27 깸 뒤 무수집)
