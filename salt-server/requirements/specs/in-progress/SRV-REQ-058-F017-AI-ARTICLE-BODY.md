## Summary

원인 근거 결과(`SRV-REQ-053` FR-11)와 회사 사정(FR-12)은 기사 · 공시 **본문에서 뽑은 사실**이 있어야 선다. 지금 본문은 포털 뉴스 검색으로 기사를 찾아 받는다(`SRV-REQ-054`) —
그 API 약관이 AI 이용을 막아 사람 화면에만 쓴다. 이 REQ 는 **포털 검색 API 를 한 번도 거치지 않고** 같은 기사의 원문 페이지에 닿는 길을 만든다. 서비스 `market`(S5 전 Express `news` 컨텍스트).

**AI 경로의 원천 순서** — ① 공시 원문(OpenDART `document.xml` — `FC-REQ-026`. 약관 확인 2026-11-13: 저작권 조항 외 가공 · 재배포 제한 없음 · 인증키 본인만 · 하루 허용량) ② 언론사가 직접 내는 RSS 의 원문 링크 ③ 코인 RSS 원천(이미 수집 중 — 중계 주소는 최종 주소로 푼다) ④ 언론사 사이트 기사 목록 페이지(robots.txt 허용 · RSS 가 없는 곳만). 포털 · 검색 API · 비공식 거래소 공지 긁기 0.

**법 · 약관 근거** — 사실은 저작물이 아니고 "사실의 전달에 불과한 시사보도"는 보호받지 못한다(저작권법 제7조 5호). 우리는 사실 단위(누가 · 무엇을 · 얼마나 · 언제)만 저장 · 표시하고 기사 문장은 저장 · 요약 · 표시하지 않는다(`ADR-009` v4). 본인+친구 무상 · 원문 링크와 매체 이름을 늘 붙인다. robots.txt 가 막는 매체 · 약관이 자동 수집이나 AI 이용을 명시적으로 막는 매체는 목록에서 뺀다(매체마다 확인 기록).

## FR

| FR | 내용 | 상태 |
|---|---|---|
| FR-1 | **매체 목록** `news.outlet`(이름 · RSS 주소 들 · robots 확인 시각 · 약관 확인 메모 · 켜짐) — 경제 · 종합 · 코인 매체. 켜기 전 robots.txt 와 이용약관을 읽고 메모를 남긴다(막으면 끔). 하루 한 번 robots.txt 다시 읽음 | to-do |
| FR-2 | **언론사 RSS 수집** — 매체마다 5분 · 조건부 GET(ETag · Last-Modified) · 항목 `{ outlet, title, url, published_at, fetched_at }` · 같은 주소 한 번(`ON CONFLICT DO NOTHING`). 본문은 이 단계에서 받지 않는다 | to-do |
| FR-3 | **같은 기사 잇기** — 국내 KIS 시황 제목 · 코인 RSS 제목 ↔ FR-2 항목. 판정은 `SRV-REQ-054` FR-1 규칙 그대로(Dice ≥ 0.8 · 2일 · 줄인 제목) — 코드 한 곳을 같이 쓴다. 못 이으면 `unmatched`(남의 기사 붙이지 않음) | to-do |
| FR-4 | **원문 받기** — 이은 주소의 페이지만 · `ArticlePageFetcher`(공인 주소만 · 8초 · 3MB · Readability) 재사용 · 매체마다 초당 1건 · 실패 재시도 3회(지수). 본문 문단은 추출이 끝날 때까지만 보관(최대 7일) — 뒤엔 해시 · 길이만 | to-do |
| FR-5 | **AI 경로 표식** — 본문 행에 `via: rss_direct \| dart \| coin_rss \| outlet_list \| portal` 을 단다. `SRV-REQ-053` FR-14 사실 추출은 `portal` 이 아닌 행만 읽는다 — 테스트가 막는다(포털 행을 넣으면 추출 0) | to-do |
| FR-6 | **덮임률** — 종목에 묶인 제목 중 1시간 안에 AI 경로 본문이 생긴 비율을 시장 · 매체별로 매일. 목표 **국내 ≥ 90% · 코인 ≥ 90%**(관련 종목 ≤ 2 제목 기준). 못 미치면 빠진 매체 상위를 리포트 → FR-1 에 더한다. 상태 점검 한 줄(`OPS-004`) | to-do |
| FR-7 | **본문이 끝내 없을 때** — 패널은 "제목만 확인됐어요 · 원문 링크"로 말하고 원인 칸은 그 제목을 사실 근거로 쓰지 않는다(빈 칸이 아니라 단 표시 — `SRV-REQ-053` FR-13 `tier`). 결함으로 센다 | to-do |

## Acceptance Criteria

- [ ] 포털 검색 API 호출 코드가 AI 경로(FR-2~5 · `SRV-REQ-053` FR-14)에서 0 — grep 테스트
- [ ] 매체마다 robots · 약관 확인 메모 · 막힌 매체 0 켜짐
- [ ] 덮임률 실측(장중 하루) 국내 · 코인 ≥ 90% — 못 미치면 매체 추가 뒤 다시
- [ ] 저장소에 기사 문장 0 — 7일 지난 본문 행이 해시 · 길이만 남는지
- [ ] 같은 기사 판정 경계 표 테스트를 `SRV-REQ-054` 와 같은 표로
