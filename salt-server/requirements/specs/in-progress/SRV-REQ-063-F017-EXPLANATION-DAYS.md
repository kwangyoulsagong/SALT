## Summary

사용자가 본 것: 삼성전자는 2026-11-25 −9.87%, 11-26 +2.2%. 11-26 해설은 "업종 9종목 중 8종목이 같이 올라 +2.28%" 만 말해 판정(관망)과 달리
반등 이야기로 읽혔고, 어제 해설은 볼 수도 없었다.

| 원인(실측) | 근거 |
|---|---|
| 해설은 **지문이 바뀔 때만** 만든다 — 지문에 가격이 없다. 판정이 계속 관망 · 관측이 문턱 같은 쪽이면 −9.87% 날에도 지문이 같다 | `explanation_snapshot` 005930: 11-16 · 11-17 · 11-19 · 11-26 뿐(11-25 0행). 같은 날 다른 29종목 82행은 저장됨 — 배치는 돌았다 |
| 지문이 같으면 날짜와 무관하게 `latest` — 어제 화면엔 11-19 해설이 '최신'으로 보였을 것 | `selectExplanationTier` 첫 줄 |
| 해설 재료의 등락은 전일 대비 하나(`change24h`) — 최근 흐름이 없어 문장이 쓸 수 없고 검증기도 그 숫자를 막는다 | `CoachExplanationInput` · `allowedFacts` |
| 보존 5벌(`EXPLANATION_SNAPSHOT_KEEP`) — 날마다 남겨도 5일 뒤 지워진다 | `PrismaExplanationSnapshotStore.prune` |

하나는 숫자로 재현하지 못했다 — 11-25 그날 관측값은 남지 않아 "지문이 같았다"를 다시 계산할 수 없다. 대안(그날 생성 실패 — 로컬 CLI 시간 초과 14건)은
Gemini 대체가 있어 가능성이 낮다. 어느 쪽이든 FR-1 이 같은 결과(날마다 한 벌)를 만든다.

## FR

| FR | 내용 |
|---|---|
| FR-1 | 지문에 **거래일(KST)** — 판정 · 관측이 같아도 날이 바뀌면 그날 해설을 만든다. 어제 해설은 오늘 `previous`(만든 시각과 함께)로만 보인다 — '최신'으로 보이지 않는다 |
| FR-2 | 재료 **최근 흐름** 한 줄(판단 바로 뒤 근거 — 상한에 잘리지 않게): 직전 거래일 · 5거래일 전 종가 대비 · 최근 20거래일 최고 종가 대비(1% 이상 아래일 때만). 닫힌 일봉(`forecast.v_daily_close`) · 오늘 봉 제외 · 7일 넘게 낡으면 없음. 부호를 숫자에 붙여 검증기가 방향까지 대조. 프롬프트는 "오늘 등락을 말할 때 같은 문장에 흐름을 밝히라"(`explain-prompt@5`). 판정 · 점수엔 안 들어간다 |
| FR-3 | 보존 — 최근 5벌 + 최근 30일은 KST 날마다 마지막 한 벌(한 문장 `DELETE`) |
| FR-5 | LLM 하루 시도 상한 360 → **600**(해설 몫 270 → 510) — 날마다 한 벌이면 추적 종목 × 2모드 ≈ 104 + 장중 판단 변화 ≈ 130(11-26 실측 128). 270 이면 재기동 직후 278/270 으로 106 전부 미뤘다(사용자 "삼성전자만 만들면 안 되잖아"). 시도의 94% 가 로컬 Claude(비용 0 · 동시 2 · 회차 12) — 돈이 드는 Gemini(대체 경로)는 토큰 상한 180만이 그대로 지킨다 |
| FR-4 | `GET /api/ai-coach/explanation/history?symbol&mode&days`(기본 7 · 최대 14) — 오늘 이전 날 · 최신 날 먼저 · 날마다 마지막 저장본 **원문 그대로**(다시 만들지 않는다 — 사후 지식). `track` · `miss`(지금 값 문장)는 뺀다. `dayChangeRate`(그날 종가 전 봉 대비) · `changeSinceRate`(그날 종가 → 지금) 서버 계산 · 못 읽으면 null(문장은 그대로). 빗나간 날도 고르지 않고 다 |

## 하지 않는 것

- 지문에 가격 · 등락 넣기 — 매 분 다시 만든다. 날 하나면 하루 한 번(추적 종목 × 2모드 ≈ 104회/일 — 상한은 FR-5)
- 지난 날 해설을 지금 데이터로 다시 쓰기 · 지워진 옛 해설 되살리기(11-20 ~ 11-25 사이는 원래 없다)
- 그날 판정의 적중(hit/miss) 표시 — 판정 기간(장기 30일)이 안 지난 날이 대부분. 등락 숫자만 사실로
