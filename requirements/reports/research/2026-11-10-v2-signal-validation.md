## 0. 요약 (먼저 읽을 10줄)

1. **판정 실력 = "같은 시각 같은 시장의 다른 종목보다 나았나"** 다. 핵심 통계는 하나 — `후보 평균 순수익 − 피함 평균 순수익`(spread)과 그 클러스터 부트스트랩 CI. 적중률은 보조
2. **표본 수는 판정 개수가 아니라 독립 날짜 수**다. 코인 300종목은 같은 날 상관 ~0.5 라 하루 유효 표본 ≈ 2, 국내 57종목(상관 ~0.3)은 ≈ 3. 적중률 +5%p 를 잡으려면 유효 ~620~780건 → **라이브만으로는 코인 ~1년, 국내 ~8개월**. 그래서 백테스트 채점이 필요하고, 라벨로 갈라 둔다
3. 비용은 판정 단위에서 뺀다 — **국내 왕복 ≈ 0.24%**(수수료 0.0186%×2 + 2026 거래세 0.20%) + 호가 반 틱, **업비트 왕복 0.10%** + 스프레드. 1시간 지평 국내는 비용이 일 σ 의 1/10 을 넘는다
4. 다중검정은 **확인용 가설 ≤ 10개 → Holm**, 임계값 격자를 뒤졌으면 **White RC / Hansen SPA**, 전략 Sharpe 는 **DSR** — 시도한 변형 수를 사전등록 표에 같이 센다
5. 조건부 기저율은 **서술(늘 보여 줌)과 주장("평소와 다름" 표지)을 나눈다.** 서술은 n ≥ 100(유효)이면 Wilson 구간과 함께, 주장은 경험적 베이즈 수축 뒤 Holm 통과만
6. 문헌상 단기 효과 중 쓸 만한 것: **코인 — 소형 · 비유동은 하루 되돌림, 대형 · 유동은 하루 모멘텀(B)**, 우리 데이터 change24h 단타 IC −0.038 이 이것과 맞다. **국내 — 큰 하락 뒤 되돌림 · 시가 갭의 장중 되돌림(B~C)**, 상한가 다음 날 · VI 뒤 방향은 국내 직접 연구가 없다(C)
7. RSI > 70 같은 기술적 조건은 데이터 스누핑 보정 뒤 대부분 사라진다(**A**, Sullivan–Timmermann–White 1999). "RSI 과열" 기저율은 보여 줄 수 있어도 효과 주장은 못 한다
8. 단타 방향 확률의 현실적 상한: **일간 정확도 평균 53~54%, 확신 상위 10% 57~60%(코인 100종목, B)**, 15분봉 흐름 모델 AUC 0.52~0.54. 통과 기준을 "정확도 60%"로 잡으면 영원히 못 넘거나 누수다. 기준은 **BSS 하한 > 0 · 보정 기울기 ≈ 1 · 비용 뒤 손익**

## 1. 실력 판정 프로토콜 — 사전등록 순서대로

### 1-1. 단위와 라벨 (먼저 고정)

| 항목 | 정하는 것 | 이유 |
|---|---|---|
| 판정 단위 | (종목, 판정 시각 t, 모드, 지평 h, 행동 ∈ 후보 · 관망 · 피함) | 스냅샷 원장 그대로 |
| 표본 추출 | **종목 × 지평마다 겹치지 않게** — 단타 24h 는 하루 1회(국내 = 장 마감 15:30 이후 첫 스냅샷, 코인 = 09:00 KST 일봉 경계), 장기 30d 는 30일마다 1회. 나머지 스냅샷은 표시용 | 5분마다 찍은 24h 판정은 287/288 이 같은 미래를 공유한다. 겹친 채 세면 n 이 수백 배 부풀려진다 |
| 수익 | 순수익 `r_net = ln(P[t+h]/P[t]) − c`. P 는 **판정 시각 다음 체결 가능 가격**(코인 = 다음 1분봉 시가, 국내 = 다음 분봉 시가 · 장 마감 뒤면 다음 날 시가) | 판정 시각 종가로 사면 이미 지난 가격을 산다(누수) |
| 비용 c | 국내: 0.000186×2 + 매도일 거래세(`KR_STOCK_SELL_TAX` 표, 2026 = 0.20%) + 호가 반 틱×2. 코인: 0.0005×2 + 스프레드 반×2(업비트 호가 스냅샷 중앙값, 없으면 종목 가격대 호가단위) | 서버 `krStockCost.ts` 와 같은 표를 쓴다 — 두 벌 금지 |
| 시장 기준 | 같은 t 의 같은 시장 대상 종목 동일가중 평균 `m_t` (국내 = 유니버스 57종목 또는 `kr-universe@1`, 코인 = 업비트 원화 대상) | 시장 전체가 오른 날 "후보 적중"은 실력이 아니다 |

### 1-2. 행동별 기준선 — 무엇을 이겨야 실력인가

| 행동 | 성공 정의(주) | 기준선 (둘 다 이겨야) | 보조 |
|---|---|---|---|
| **후보** | `r_net > 0` | ① 같은 t 의 무작위 종목 `P(r_net>0)` (시장 기저율) ② "늘 오른다" = 같은 종목을 그냥 산 경우 | 평균 `r_net − m_t` |
| **피함** | `r < 0` (비용 없음 — 안 사는 것은 공짜) | ① 같은 t 시장 하락 비율 ② "늘 내린다"가 아니라 **시장 평균보다 낮았나**: `r − m_t < 0` | 피해서 아낀 평균 `m_t − r` |
| **관망** | 방향 주장 없음 → 적중률을 내지 않는다 | 후보와 피함 사이에 있나(순서), 그리고 `|r|` 이 시장보다 작았나 | "관망 뒤 h 안 ±σ 이탈 비율" |
| **전체(핵심)** | **spread = mean(후보 r_net) − mean(피함 r)** · 순서 `후보 > 관망 > 피함` | 0. 날짜 클러스터 부트스트랩 95% CI 하한 > 0 | 순위 IC(규칙 점수 vs r) — `rule-ic@1` 과 같은 계산 |

- "늘 오른다가 왕복 비용을 이기는 비율"은 **시장 기저율 ①** 로 이미 들어간다. 강세장에서는 후보 적중 60% 도 기저율 62% 면 실력 0 이다
- 적중률 excess 는 **같은 사건 쌍**으로 잰다(같은 t 에서 판정 종목 vs 시장 무작위) — 쌍대 비교라 분산이 준다

### 1-3. 겹침 · 상관 처리

| 문제 | 처리 | 근거 |
|---|---|---|
| 같은 날 여러 종목(코인 BTC 베타 0.7~0.9) | **날짜 클러스터 부트스트랩** — 날짜를 통째로 뽑는다. 유효 n ≈ 날짜 수 × m/(1+(m−1)ρ̄) 를 리포트에 같이 적는다 | 등상관 분산 공식. ρ̄ = 0.5 · m = 300 → 하루 ≈ 2 |
| 지평 > 표본 간격(장기 30d 를 매일 셀 때) | 이동 블록 부트스트랩, 블록 = max(7, 2h) — `rule-ic@1` 과 같게. 또는 겹치지 않게 뽑기 | [Politis–Romano 1994](https://doi.org/10.1080/01621459.1994.10476870) |
| 모델을 학습하는 경우(단타 확률) | **Purge**(테스트 시작 전 h 안에 라벨이 끝나는 학습 행 제거) + **embargo** = max(h, 1일) · 선택은 CPCV, 최종 판정은 **등록 뒤 기간(진짜 표본 밖)** | AFML 7장 · 12장 (09-27 리서치 §6-2) |
| 규칙은 학습 안 했다 | 규칙 판정 채점은 CV 불필요. 단 **규칙이 바뀐 날(커밋) 전 기간은 "설계자가 본 기간"** — 백테스트 라벨에 붙여 둔다 | 손으로 정한 임계 −3/+3 도 차트를 보고 정했다 |

### 1-4. 다중검정 — 무엇을 언제

| 상황 | 방법 | 링크 |
|---|---|---|
| 확인용 가설 몇 개(행동 × 시장 × 지평 ≈ 2×2×2 = 8) | **Holm** (가족 α = 0.05). 사전등록 표에 가족을 적는다 | Holm 1979 |
| 임계값 · 지표 조합 격자 중 최선을 고름(예: RSI 65/70/75 × 변화 3/5/7%) | **White Reality Check** 또는 **Hansen SPA**(약한 대안 영향 적음) — 정상 부트스트랩 | [White 2000](https://doi.org/10.1111/1468-0262.00152) · [Hansen 2005](https://doi.org/10.1198/073500105000000063) · [Romano–Wolf 2005](https://doi.org/10.1111/j.1468-0262.2005.00615.x) |
| 전략 Sharpe 보고 | **DSR** — 시도 수 N 을 `preregistration` 의 trial 카운터에서 읽는다 · 과적합 확률 PBO(CSCV) | [Bailey–López de Prado 2014](https://ssrn.com/abstract=2460551) · [PBO](https://ssrn.com/abstract=2326253) |
| 종목별 "잘 맞음" 표지 | BY-FDR(종목 간 양의 상관) — 09-27 결정 유지 | |
| 새 요인 문턱 | 탐색 단계에서 찾은 것은 t > 3 | [Harvey–Liu–Zhu 2016](https://doi.org/10.1093/rfs/hhv059) |

규칙: **탐색 결과는 화면 문구 근거로 못 쓴다.** 탐색에서 찾은 것은 새 키(`…@2`)로 등록하고 등록 뒤 기간으로 다시 시험한다.

### 1-5. 표본 크기 · 검정력 (수치 근거)

적중률 p0 = 0.50 대비 +5%p(0.55) 검출, 검정력 0.8:

| 유의수준 | 필요 유효 n | 설명 |
|---|---|---|
| 단측 0.05 (단일 가설) | **≈ 620** | n = ((1.645·0.5 + 0.842·√(.55·.45)) / 0.05)² |
| 양측 0.05 | ≈ 780 | |
| Holm 8가설 최악(단측 0.00625) | ≈ 1,110 | z = 2.50 |
| +10%p 검출(단측 0.05) | ≈ 150 | 효과가 두 배면 표본은 1/4 |

- 유효 n 환산: 코인 하루 ≈ 2 → **620 유효 ≈ 310일**, 국내 하루 ≈ 3 → **≈ 210 거래일(≈ 10개월)**. 라이브 스냅샷이 쌓인 지 몇 주인 지금 "라이브 적중률 %"는 노이즈다 → 09-27 결정 "n<30 채점 중" 문턱은 **표시 문턱**이고, **실력 주장 문턱은 유효 n ≥ 620** 으로 별도
- spread 검정은 적중률보다 검정력이 높다(크기 정보를 씀) — 1차 지표로 둔다
- 현실적 효과: 우리 change24h 단타 IC 0.038 → 일 σ 4% 코인에서 후보−피함 spread 대략 0.1~0.2%/일. 왕복 0.10% 를 빼면 남는 게 거의 없다. **"실력 있음"보다 "비용 뒤 0과 구별 안 됨"이 나올 가능성이 높다는 것을 미리 적어 둔다**

### 1-6. 확률 출력의 보정 지표

### 1-7. 승격 · 강등 — 판정은 숨기지 않고 표지만 바꾼다

| 단계 | 조건(전부) | 화면 |
|---|---|---|
| **검증됨** | 등록 뒤 **라이브** 기간에서 spread CI 하한 > 0 (Holm 보정) · 유효 n ≥ 620 · 비용 뒤 · 국면 2개 이상에서 같은 부호 | 판정 + "과거 n번 중 시장보다 나았던 비율 · 범위" |
| **참고** (기본값) | 위 미충족. 또는 백테스트만 통과 | 판정 + 태그 "검증 중 · 유효 표본 n/620" (+ "백테스트 기준" 태그) |
| **주의** | spread CI 상한 < 0 (반대로 맞음) — 라이브 또는 백테스트 | 판정 + 태그 "과거엔 반대 결과가 더 많았어요" + 근거 수치. 규칙은 다음 버전에서 부호 검토(새 키) |
| 확률(단타 FR-1) | §4-3 통과 전 | **확률 숫자 안 냄**(`renderable:false`) — 이것만 숨김. 판정 · 기저율은 그대로 |

## 2. 백테스트 채점 — 코인도 국내처럼 (그리고 라벨)

### 2-1. 함정과 처리

| 함정 | 국내 | 코인 | 처리 |

## 3. 조건부 기저율 — 제품으로 (사기 전 · 팔기 전 점검)

### 3-1. 조건 고르는 법 — 과적합 없이

1. **사전등록 조건 ≤ 8개/시장**, 지평 3개(1h · 4h · 1d — 국내 1h · 4h 는 §5-3 제약). 문헌 근거가 있거나 사용자가 실제로 겪는 장면(추격 매수 · 물타기 · 익절 고민)만
2. 임계는 **종목 자기 변동성 단위**(예: 오늘 수익 > 2σ_20d)와 **사람이 읽는 고정값**(+5%) 중 하나를 등록 때 고른다. 둘 다 시험하면 시도 2배로 센다
3. 문턱: **유효 n ≥ 100**(서로 다른 날짜 ≥ 60) — Wilson 95% 반폭이 n=100·p=.5 에서 ±9.6%p. 그 아래는 행을 내지 않는다(FR-2 그대로). q10 · q90 은 n ≥ 100 일 때만(꼬리 점 10개)
4. **수축(경험적 베이즈, 베타–이항)**: 조건 c 의 상승 비율 p̂_c = (k_c + κ·p₀)/(n_c + κ). p₀ = 같은 종목군 · 같은 지평 무조건 비율, κ 는 조건들 간 분산으로 적률 추정(대개 50~200). n 이 작을수록 평소 값으로 당겨진다 ([Efron–Morris 1975](https://doi.org/10.1080/01621459.1975.10479864)) — A
5. **구간**: 원비율에 Wilson(클러스터 보정 n_eff 로) — Wald 금지 ([Brown–Cai–DasGupta 2001](https://doi.org/10.1214/ss/1009213286)) — A
6. **서술 vs 주장 분리**: "100번 중 61번 올랐어요(범위 51~70)"는 n 문턱만 넘으면 늘 보인다(서술). "평소(54번)보다 많아요" 표지는 수축 뒤 차이의 Holm 보정 p < 0.05 일 때만(주장)
7. **국면 이동 검사**: 등록 기간을 제도 경계(§5-1)와 반으로 나눠 부호 같은지 · 최근 12개월이 전체 구간 Wilson 밖이면 태그 "최근엔 달라요" (숨기지 않음)
8. **같은 날 몰림**: 코인 급등일은 수십 종목이 같은 날 조건을 만족 → n 은 **날짜 수**로도 같이 적고, 문턱은 둘 다

| 투자자 수급(외국인 · 기관 · 프로그램) | — | 당일 장중 추정치만 | C — 표본 밖 붕괴 사례 |

### 4-3. 통과 기준 (사전등록 문안 제안 — 전부 만족해야 `renderable:true`)

1. **기간**: 학습 = 등록일 이전, CPCV(purge h · embargo max(h,1d))로 모델 1개 선택 → 최종 시험 = **등록 뒤 전진 기간**. 코인 1h · 4h ≥ 90일 · 1d ≥ 180일, 국내 1d ≥ 120거래일
2. **표본**: 클러스터 보정 유효 n — 1h · 4h ≥ 1,000, 1d ≥ 500
3. **BSS** vs 기후값 · vs 지속 둘 다 날짜 블록 부트스트랩 95% 하한 > 0 (Holm: 시장 2 × 지평 3 = 6 가족)
4. **보정**: 기울기 CI ⊂ [0.7, 1.3] 이고 1 포함 · 절편 CI 가 0 포함. 화면에 내는 각 10%p 구간 n ≥ 100
5. **해상도**: 예측의 20% 이상이 [0.45, 0.55] 밖 — 아니면 통과해도 "방향이 안 보여요"만 보인다
6. **비용 뒤 의사결정 가치**: p ≥ p\* (= (평균 손실 + c)/(평균 이익 + 평균 손실)) 인 경우만 샀을 때 평균 순수익 > 0, CI 하한 > −c/2 (손해 아님 확인) — 코인 c = 0.10% + 스프레드, 국내 c ≈ 0.24% + 틱
7. **안정성**: 시험 기간을 3등분해 BSS 부호 ≥ 2/3 양수, 제도 경계를 넘는 경우 양쪽 모두 양수
8. **시도 수**: 특징 집합 · 지평 · 보정 방식 변형 전부 trial 로 기록, DSR 은 리포트에 병기(판정 기준은 3~7)
9. **강등**: 매주 13주 이동 BSS CI 상한 < 0 → `renderable:false`. 재승격은 새 데이터로만

국내 1h · 4h 는 1번 기간을 채울 분봉이 없다(KIS 분봉 ~1년, §5-3) — **1d 먼저, 1h · 4h 는 우리 저장 분봉 6개월 이후 시험** 으로 등록한다. 1h 창은 장 마감을 넘지 않게(15:20 이후 판정 없음) 한다.

## 8. 말하면 안 되는 것

1. "이 판정은 n% 맞아요" — 같은 시점 시장 기저율과 나란히가 아니면 금지. 강세장의 높은 적중률은 실력이 아니다
2. 라이브 · 백테스트를 합친 하나의 적중률. 백테스트를 "실적"이라 부르기
3. 유효 n ≥ 620 전에 "검증됨 · 실력 있음 · 신뢰도 높음"
4. 비용 전 수익 · 비용 전 적중률 (국내는 거래세 포함 왕복 ≈ 0.24%)
5. "RSI 70 넘으면 떨어진다" 같은 인과 · 법칙 문장 — 기저율은 "과거 이런 날 뒤에 이랬다"까지만 (기술적 규칙 스누핑 결과 A)
6. "평소보다 높아요/낮아요" — 수축 · Holm 통과 전
7. 상한가 · VI · 공매도 재개 뒤 방향 예측 — 국내 직접 연구 없음(C), 서술만
8. 시험 못 넘은 확률 숫자 · 50% 근처 확률을 "약한 상승" 같은 방향 문장으로 바꾸기
9. 정확도 · AUC 를 "높다"로 — 일간 53~56% 가 문헌의 현실. 60% 넘는 수치가 나오면 먼저 누수를 의심한다고 리포트에 적는다
10. 소형 코인 결과를 대형 코인 · 국내 주식에 일반화 (반전과 모멘텀이 갈린다)
11. 2025-03 이전 국내 시가 갭 기저율을 지금의 갭에 그대로 (대체거래소로 뜻이 바뀜)
12. 투자자 수급(외국인 순매수 등)을 예측 근거로 — 표본 밖 붕괴 이력
13. 확신 표현 · 한 점 목표가 · 명령형 매매 지시(마스터 인덱스 §6) — 기저율도 분위 · 범위로

## 9. 한계 · 확인 못 한 것

- 국내 상한가 다음 날 · VI 뒤 방향 · 대체거래소 이후 갭 — 동료심사 연구를 찾지 못했다 → 우리 데이터 사전등록 연구가 1차 근거

- 거래세 2026 0.20% 는 기사 · 블로그 다수 + 서버 표 일치, 법령 원문은 미확인 ([요약 기사](https://studygov.kr/blog/0337-2026-stock-transaction-tax/))
- 상관 ρ̄(코인 0.5 · 국내 0.3)는 가정 — 첫 리포트에서 실측해 유효 n 공식에 넣는다
