# F004 슬라이스 6 — 상세 분석 페이지 · 해설 (FE) — 회고

- 브랜치: `feat/f004-fe-detail-page`
- 날짜: 2026-09-22
- 체크리스트: `requirements/reports/checklists/F004-fe-detail-page.md`

## 1. 무엇을 했나

패널 ⑦ 이 갈 곳을 만들었다. 새 조회 없이 패널의 뷰모델 하나로 차트 구간 선 · 코치 카드 · 수익 플랜을 그리고,
해설은 누를 때만 부른다. 슬라이스 5 가 만든 `explain` 의 인증 · 429 를 처음 소비했다. 주문 전 체크는 서버
계약을 보고 **이 슬라이스에서 뺐다** — 프론트가 손절 % 를 가격으로 바꾸면 "금액 계산은 서버" 위반이다.

## 2. 잘 유지된 것

- **`market` 은 여전히 `coach` 를 모른다.** 차트는 `priceLines` 를, 프리뷰는 `footerSlot` 을 받기만 한다.
  zone → 선 매핑은 `entities/coach` 순수 함수, 조합은 위젯이다 — 슬라이스 4 의 슬롯 방식 그대로
- **게이트가 상자까지 가져갔다.** 처음엔 위젯이 해설 카드를 상자로 감싸서, 판단이 막히면 빈 상자가 남았다.
  부모가 `renderable` 을 보고 상자를 고르는 대신 카드가 `className` 을 받게 했다 — FR-1 원칙 유지
- **실측이 버그 셋을 찾았다.** 빈 상자 · 같은 프레임 3연타 3건 · CLS 0.097. 셋 다 타입 · lint 는 통과했다
- 빌드를 **worktree 에서** 했다 — 사용자가 켜 둔 dev 서버의 `.next` 를 덮지 않았다

## 3. 남은 기술부채

- **서버 LLM 호출은 화면을 떠나도 끝까지 돈다.** FE · BFF 는 끊지만 서버 `explain` 에 abort 가 없다.
  "BFF 가 끊으면 서버도 끊는다"(슬라이스 5 문서)는 **HTTP 연결까지만** 참이다
- **해설 뉴스 요약 5줄 고정.** 서버 프롬프트가 5줄을 요구해 뉴스 1건에도 5줄이 온다 — 지어낸 요약일 수 있다.
  화면은 5줄로 자르기만 한다
- **캔들이 납작해진다.** 선을 y 범위에 넣어 화면 밖으로 안 나가게 했더니, 먼 선(1년 상단 · 손실 제한)이 있으면
  캔들이 가운데 얇은 띠가 된다. 선을 가장자리 표시로 바꾸는 대안이 있다 — 판단이 열리고 실사용자 화면을 본 뒤에
- **barrel 비용.** 패널 지연 청크가 +5.5 KB — 패널이 안 쓰는 상세 컴포넌트가 `@/entities/coach` ·
  `@/entities/market` barrel 로 딸려 온다. 예산 안이지만 슬라이스가 커질수록 는다
- **`apps/web` 에 테스트 러너가 없다.** `zoneToPriceLines` · `buildExplainRequest` 같은 순수 함수도 실측으로만
  확인했다
- 조회가 클라이언트라 상세 페이지 본문이 `ssr:false` 다 — 쿠키 인증(`FE-REQ-013`) 전까지 스트리밍 SSR 이득이 없다
- 시세 목록 검색으로 종목명 · 거래대금을 찾는다(단건 시세 경로가 없다). 목록에 없는 종목은 해설을 못 부른다

## 4. 다음에 보완할 규칙 · 문서

- **`layer-check` 훅 사후 실행은 `content` 를 실어야 한다.** 처음엔 `file_path` 만 넘겨 import 검사가
  비어 있었는데 "차단 0"으로 보였다. 사후 실행 스니펫을 `fsd` 규칙 문서나 스크립트로 남길 것
- **Playwright 가로채기는 MSW 서비스 워커와 부딪힌다** — `serviceWorkers: "block"` 이 필요하고 그러면 MSW
  기동 실패가 콘솔에 뜬다. `local-fullstack-run` 류 문서에 한 줄
- 연타 가드는 상태가 아니라 ref — `api-convention.md` 의 mutation 절에 한 줄 (LLM · 결제처럼 비싼 호출)

## 5. 추가 검증 제안
