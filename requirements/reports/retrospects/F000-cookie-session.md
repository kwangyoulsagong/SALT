# 회고 — F000 쿠키 세션 2단계

- **잘 된 것**: 1단계가 토큰 읽기 · 쓰기를 한 파일에 모아 둬서 이관이 기계 치환 50곳 + 한 파일 재작성이었다
- **놓칠 뻔한 것**: 갱신 규칙("헤더가 있었나")과 웹소켓(연결 때만 실림)은 저장 방식이 전제에 들어 있었다. Action: 인증 운반을 바꿀 땐 경로별 "언제 실리나" 표를 먼저 쓴다
- **헛통과**: 실화면 첫 판의 웹소켓 검사가 "거부 코드 없음"으로 통과했는데 소켓이 아예 안 열렸다. Action: 부재로 통과하는 검사는 "있어야 할 것이 있었나"를 같이 센다
- **기존 결함**: 머리 계정 메뉴 쌓임 — F2 확인이 "열린다"만 봤다. 이제 테스트가 센다
- **환경**: 3000 은 사용자 회사 작업 포트 — 확인은 다른 포트 + 소켓 허용 origin 임시 추가 후 원복
