# MONEY-S3a — 회고

## 잘된 것

- S3 를 셋으로 자른 것 — 사용자 표 · 토큰을 건드리지 않고 identity 가 태어나, 화면 기능과 로그인 경로 교체가 따로 되돌려진다
- 은퇴 경로 — 소비처를 같은 PR 에서 옮기고 옛 코드 · 그 코드만 쓰던 저축 경로 · 환경 변수까지 한 커밋(revert 지점 하나)

## 아쉬운 것

- 새 설정 패널이 이전 패널의 "저장 중 무시" 가드를 그대로 본떠 같은 결함이 둘이 됐다 — 실화면 연달아 누르기에서야 드러났다
- 첫 확인 스크립트가 도착 직후 스크린샷을 찍어 수화 경고를 만들었다 — 우리 결함인지 가리느라 한 번 더 돌렸다

## Action

- 새 설정 패널(셸 `/settings`)은 `mutationKey` + `scope` + "마지막 저장만 반영" 꼴을 본뜬다(`fsd-features.md` 표 `arrange-home` · `toggle-alerts` 행)
- 실화면 확인에서 zone 이동 직후엔 `networkidle` 뒤 스크린샷 — 수화 중 DOM 을 건드리지 않는다
- 다음 칸 S3b(사용자 · 초대 코드 표 이동 · JWKS 이중 검증 · `UserRegistered`) 또는 S3c(내보내기 · 삭제)
