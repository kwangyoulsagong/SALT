# F006 슬라이스 1 — 투자 화면 시장 요약 띠 — 회고

영역 회고: `salt-server/…/SRV-REQ-036.md` · `bff/…/BFF-REQ-035.md` · `salt-microFe/…/FE-REQ-037.md`

## 요약

- 처음엔 "프론트만으로 되는 것"으로 좁혀 요약 대상 · 임계를 프론트 상수로 박았다. 무엇을 보여 줄지는 서버 판단 — 사용자 지적으로 세 영역을 한 슬라이스로 옮겼고, 등락 금액이 서버 계산으로 범위에 들어왔다
- 참고 화면은 **실제 페이지를 열어 잰 뒤에야** 맞았다(띠 176 · 글자 11~14px). 스크린샷 짐작은 한 번 버려졌다
- 새 REQ 번호 두 개가 이미 있던 번호였다 — 폴더 전체 확인 후 붙인다

## Action

- 참고 화면 작업: 착수 전 실측을 REQ 에 적는다
- 운영에서 스파크라인 캐시 만료 동시 호출이 거래소 제한에 걸리는지 본다
