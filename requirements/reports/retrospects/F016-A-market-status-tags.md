  표본이 됐고, 배포 직후 실서버도 같은 답(09:04~09:34)을 썼다
- 실측 먼저 — KIS 응답 필드(VI 현황 · 현재가 상태 칸)를 모의 키로 직접 받아 보고 이름을 정했다. 리서치의 "VI 하루 30건"은 **최근 30건 한 쪽**이었다(연속 조회 머리 빈 값)

## 아쉬운 것 · 배운 것

- **기존 "마지막 체결" 줄이 시세 받은 시각이었다** — 이름과 값이 달랐고 서킷브레이커 날 그것이 "실시간처럼 보이는" 원인 하나였다. 표시 문구의 값 출처를 같이 본다
- FE 파일에 레포 설정 없이 `prettier --write` 를 돌려(폭 80) 원본 줄까지 바뀌었다 — 원본에서 다시 시작해 편집만 다시 적용했다. **FE 도 파일 단위 포매터 금지**(서버 규칙과 같다)
- 3001 셸 실화면에서 세션이 풀렸다 — BFF 웹소켓 쿠키 허용 출처(`WEB_ORIGINS`)에 3001 이 없으면 401 → 갱신 실패 → 로그인. 메모리에 있던 절차(잠시 넣고 되돌림)를 처음부터 따랐어야 했다
