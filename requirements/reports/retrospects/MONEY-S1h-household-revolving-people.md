# MONEY-S1h 회고 — 리볼빙 · 사람 장부

- **잘한 것**: 리볼빙 계산 전에 규정 · 약관 안내를 먼저 찾아 입력 경계(10~100 · 20%)와 이름("리볼빙(일부결제금액이월약정)")을 그대로 옮겼다. 추정 표를 손으로 다시 계산해 숫자 출처를 닫았다.
- **잘한 것**: 두 갈래를 한 슬라이스로 닫아 "다음 칸" 포인터 정정 연쇄를 끝냈다(가계부 S1 에서 남은 것은 공제 · 영수증).
- **실수**: 화면 이름을 목록 순번으로 지었다 — 같은 대상이 화면마다 다른 이름. 실화면 글자 대조로 찾았다.
- **실수**: 사용자 입력 뒤에 조사를 붙였다("이서연와"). 한국어 문구 규칙에 없던 종류.
- **실수**: 실화면 스크립트에 `networkidle` — dev 서버가 연결을 계속 열어 끝나지 않았다. `load` + 짧은 대기로.
- **Action**: 사용자 입력 값 뒤 조사 금지 — messages 를 쓸 때 `${…}[은는이가을를와과]` grep(`FE-REQ-057` 회고와 같은 줄).
- **Action**: 대상 이름은 그 대상의 값으로 짓는다(목록 순번 금지).
