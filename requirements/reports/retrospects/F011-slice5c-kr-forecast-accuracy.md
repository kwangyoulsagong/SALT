# F011 슬라이스 5c 회고 — P0 · P1 · P2 (2026-10-09 ~ 10-12, 진행 중)

- **좋은 숫자가 두 번 사라졌다.** 위치 0 으로 바꾸자 이득의 대부분(드리프트)이, 유니버스를 넓히자 나머지(생존 표본)가 사라졌다. 둘 다 사전등록 · 플라시보가 없었으면 "개선"으로 보고했을 숫자다 — 순서(검정 정직성 → 유니버스 → 모델)가 맞았다
- **유니버스는 결과 보기 전에 등록했다** — 미통과 뒤 하한을 바꿔 재는 길을 막았다. 다음 P2 도전자도 시도 구성을 먼저 적는다(FR-15)
- **긴 로컬 작업의 실패를 코드에서 먼저 찾았다.** 백필이 0.1건/s 로 떨어진 원인은 맥 잠자기였다. 환경(전원 · `pmset`)을 먼저 본다
- **규모 변화(51 → 973종목)의 비용을 미리 재지 않았다** — 백테스트 49초 → 41분. 다음엔 착수 때 추정
- **P2 에서 처음 실력이 나왔다** — 척도(HAR)만으로 4기간 모두 +1~2%. 리서치가 말한 "한 자릿수 초반 %"와 같은 크기다. 위치 · 표본을 먼저 정직하게 만든 뒤라 이 숫자는 믿을 근거가 있다
- **누적 도전자의 마지막 단계만 판정**하게 등록해서, 더 좋은 중간 단계(범위 HAR)를 올리지 못했다. 규칙은 지켰다 — 다음 등록은 "성분별로 따로 판정 · Holm" 대신 **가장 단순한 구성을 판정 대상으로** 둔다
