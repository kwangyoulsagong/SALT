# F008 슬라이스 — 해설 공급자 라우팅 · 진짜 스트리밍 — 회고

영역 회고: `SRV-REQ-050` · `BFF-REQ-050` · `FE-REQ-059` · 파일만 걸침 각 REQ

## 요약

- 요구는 라우팅이었고 사용자가 느낀 문제는 스트리밍이었다 — 지금 구조(템플릿 한 틱 · 끝에 통째 교체)는 아무것도 흐르지 않았다. 더 큰 모델의 토큰 스트림을 문장 단위 검사와 묶어 "검사 전 원문 0"을 지키며 흐르게 했다
- 실측이 결함 셋(금액 방향 오탐 · RSI 14자리 · 끊긴 스트림 표시)과 운영 함정 둘(launchd PATH · 맥 잠자기)을 냈다
- 평가지 사실 누락이 같은 날 두 번째로 결과를 뒤집었다 — 이제 평가지가 모델 입력 블록을 그대로 쓴다

## Action

- 평가지는 모델이 받은 사실 블록을 그대로 — 따로 적지 않는다(`lineFactsText`)
- 오래 도는 실측은 `caffeinate -i`
- 공급자가 늘면 원장 `provider` 로 버린 문장 수를 비교한다(지금 칸이 있다)
