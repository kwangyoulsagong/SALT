# 돈 관리 앱 F2 — 앱 내비게이션 — 회고

영역 회고: `salt-microFe/requirements/reports/retrospects/FE-REQ-054.md` + 걸린 REQ 23

## 요약

- 구조(탭 한 벌 · 표시 · 판정 · 설정)는 계획대로 갔고, **겉모양은 사용자 지적으로 다시 했다** — 선 아이콘을 넣기 전에 사용자가 만든 아이콘과 기준 화면을 열지 않았다
- 도구 한계(DevTools 가 prerender 를 끔)를 우회하지 않고 사람 확인으로 남겼다. 대신 규칙 · 시도까지는 CDP 로 확인
- 사용자가 다시 보고한 기존 결함(로그인 화면 비침)을 반쪽 세션으로 재현해 원인(로그인 판단 두 곳)을 찾아 고쳤다
- 사고 하나: `git mv` 로 스테이징해 둔 스펙 이동이 첫 코드 커밋에 섞였다 — push 전에 커밋 넷을 풀고 다시 쌓았다. zsh 반복문 변수 `path` 가 PATH 를 덮어 한 번 멈췄다

## Action

- 커밋 전 `git diff --cached --name-only` 로 의도하지 않은 파일(먼저 스테이징한 이동 · 삭제)이 없는지 본다 — `git mv` 는 그 커밋 직전에
- zsh 스크립트에 `path` · `status` 같은 특수 변수 이름을 쓰지 않는다
- 화면 겉모양(아이콘 · 탭)은 기준 화면 실측과 사용자 자산 확인이 구현 앞이다
