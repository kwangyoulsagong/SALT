# F017 v4 순서 2 회고 — 원천

## 2a (2026-11-14)

- 원천 목표(덮임 90%)를 약관을 읽기 전에 정했다. 원천 REQ 는 **원문 확인 → 목표** 순서로 쓴다
- 이름이 같은 매체가 같은 원천이 아니었다(KIS 인포스탁 ≠ 인포스탁데일리 RSS) — 실데이터 제목을 나란히 놓고 확인한 뒤 묶는다
- 국내 원인 근거는 기사보다 공시가 1차라는 것이 수치로 드러났다 → 2b 가 순서 2 의 중심

## 2c (2026-11-14)

- 막힌 칸(2b 키)을 기다리지 않고 순서를 바꿨다 — 2c 는 원천이 하나(기사)여도 같은 표 · 같은 검사로 선다. 공시가 오면 `source_kind` 만 다르다

## 2d (2026-11-14)

- 실데이터 한 종목을 눈으로 대조하는 단계가 규칙 시험이 못 잡은 결함 둘을 잡았다(반복 · '오늘')
