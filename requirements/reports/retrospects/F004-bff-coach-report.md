# F004 슬라이스 14 — BFF 코치 리포트 — 회고

영역 회고: `bff/requirements/reports/retrospects/BFF-REQ-023.md` · `BFF-REQ-025.md`

- 필드를 골라 옮기는 코드는 서버가 필드를 더할 때마다 다시 본다 — 429 본문 필드가 조용히 빠지고 있었다
- 서버 단독 토큰 발급이 막혔을 때 **BFF 경유 실제 로그인**이 더 나은 실측이었다 — 한 번에 세 영역을 지난다
- 4xx 와 5xx 의 실패 격리 규칙이 다르다 — 401 을 삼키면 토큰 갱신이 멈춘다

## Action

- FE 코치 리포트 화면 — 다음 FE 슬라이스
- 테스트 계정에 보유를 기록해 채워진 리포트 실측
