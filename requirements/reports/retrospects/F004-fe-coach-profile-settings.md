# F004 슬라이스 18 — 설정 화면 회고

## 잘 된 것

- 서버 · BFF 가 9월부터 준비돼 있어 화면만 남아 있었다. 프로필 메뉴 "설정" 자리 · 레지스트리 이름(`settings-panel` · `edit-coach-profile`)도 이미 예약돼 있어 새 이름을 짓지 않았다
- 구현 전에 각 설정의 서버 소비처를 grep 했다 — 6항목 중 셋이 저장만 되는 칸이라는 것을 화면을 만들기 전에 알고 사용자에게 물었다

## 실측에서 잡은 것

- **매입가 토글 저장이 캐시를 숨김 한 필드로 덮는 구조**였다. 필드가 하나일 때는 드러나지 않았고, 설정을 늘리면 토글 한 번에 다른 칸이 비었을 것이다 — 매퍼 하나로 막고 실화면에서 토글 뒤 값 유지를 확인
- **390 앱 웹뷰에서 설명 줄이 단어 중간에서 꺾였다**("관/점은" · "코/치") → `keep-all`
- 첫 1280 캡처에서 세그먼트 선택 면이 두 칸 사이에 걸쳐 보였다 — 이동 애니메이션 중간 프레임이었다(1024 재캡처에서 정상). 결함으로 고치기 전에 상태부터 봤다

## 아쉬운 것

- FR-62 · FR-51 의 `router.refresh()` 는 서버 컴포넌트 조회를 전제로 쓴 문장이었는데 화면들은 토큰 때문에 모두 클라이언트 조회다. 스펙과 구조가 어긋난 채 남아 있었다
