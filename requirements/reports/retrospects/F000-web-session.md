# F000 세션 슬라이스 회고 — 로그인 계약 · 토큰 갱신 (2026-09-30 작성, 구현 2026-09-23)

## 무엇이 원인이었나

"코치 프리뷰가 안 뜬다"의 원인은 토큰 갱신 경로 부재(15분 만료) — 그리고 그 앞에 **로그인 자체가 목**(`mock-jwt-token`)이었다.
서버 · BFF 를 먼저 유효 토큰으로 확인해 브라우저 쪽으로 좁힌 순서가 맞았다.

## 잘한 것

- 만료 사슬을 실제 만료 토큰으로 검증(401 → refresh 200 → 재시도 200)
- 목을 지우면서 참조 0 을 확인 — 목이 계약이 되는 사고를 끝냈다(이후 MSW 전체 제거로 이어짐)

## 아쉬운 것

- 브라우저 화면의 갱신 · 리다이렉트는 확장 미연결로 화면에서 보지 못했다(배선은 같은 파일 · 같은 키)
- 참고 화면 치수 비교를 스크린샷 왕복 3회로 대신했다
