# 회고 — 가계부 S1b + F4b

## 잘 된 것
- S1a 가 남긴 약속 둘(착지에서 고정비 빼기 · 월 마감 때 예산 이력)을 새 개념 없이 닫았다 — 엔진 인자 하나 · 마감 행의 예산 사본.
- 경합 셋(확인 · 건너뛰기 · 처음 닫기)을 전부 조건부 한 문장으로 — 오류 코드 분기 0, 테스트로 409 확인.
- 화면이 보여 줄 대상을 정하지 않는다(`stage` · `closable` · 문항 키) — 프론트에 날짜 비교 · 임계 0.
- 같은 칩을 새로 짜지 않고 엔티티로 내렸다(구조 커밋 따로).

## 아쉬운 것
- 손 SQL 의 시각 캐스트 · jsonb 문자열 비교 — 테스트가 잡았지만 첫 실행에 둘 다 틀렸다.
- 실화면 스크립트를 `networkidle` 로 써서 dev 서버에서 30초 멈췄고, 전체 페이지 캡처가 애니메이션을 다시 틀어 패널이 빈 것처럼 보였다 — 코드 결함이 아니었다.
- BFF 전체 테스트의 기존 실패 1건이 남아 있다(main 에도 있음).

## Action
- 손 SQL 에 시각은 `?::timestamptz`, 이벤트 본문 검사는 JSON 으로(`SRV-REQ-046` 회고).
- 실화면 스크립트: `load` + 선택자 · 캡처가 비면 뷰포트 캡처 · 계산 스타일로 먼저 가린다(`FE-REQ-057` 회고).
- `backend-switch` 추적 ID 실패는 `BFF-REQ-045` 다음 작업에서.
