# F004 슬라이스 16 — 주문 전 체크 회고

## 잘 된 것

- 서버가 이미 다 계산해 줘서 FE 는 입력 · 표시만 했다. 손절 칩의 가격 환산까지 서버에 있어 "곱셈 한 번"의 유혹이 없었다
- Hero 를 서버 컴포넌트로 둔 채 해시 링크 하나로 상주 카드 · 바텀시트 두 동작을 냈다 — 머리 JS 0 증가

## 실측에서 잡은 것

- **진입가가 비어 계산이 시작되지 않았다.** 실시간 현재가(WS)만 보고 있었는데 이 환경에서 상세 WS 값이 오지 않았다. 공개 시세를 대체값으로
- **포커스가 body 로 돌아갔다.** 누름 안에서 제목에 포커스를 옮기면 브라우저의 조각 이동이 뒤이어 포커스를 풀었다. 다음 태스크로 미뤄 해결
- **실패 뒤 이전 결과가 남을 뻔했다.** `keepPreviousData` 는 지연엔 맞고 실패엔 틀리다 — 500 이면 결과를 비운다

## 아쉬운 것

- 같은 페이지에 계산 카드가 둘(주문 전 체크 · 거래 기록 사이즈 계산)이 됐다. 사용자 결정으로 따로 두었지만 둘의 "최대 손실"은 분모 · 입력이 달라
  숫자가 다를 수 있다 — 화면 문구가 각자 기준을 밝히는 것으로 버틴다
- FR-154 "목표 도달 시" 금액은 서버 필드가 없어 처음엔 비웠다 — 보고 뒤 사용자 승인으로 같은 날 서버 필드(FR-65)를 더해 닫았다
