# F017 v2 단계 6 측정 태그 — 회고

## 잘 된 것

- **사전을 한 곳에 두고 두 언어가 같은 답을 내게** — 정규식 대신 부분 문자열 · 공용 사례 표 · 서버용 사전 파일이 등록과 같음을 pytest 가 본다. 사전을 바꾸면 테스트 둘이 같이 깨진다
- **평소를 0.5 로 두지 않았다** — 초과 반응 > 0 은 평소 44.7%. 0.5 기준이면 거의 모든 종류가 "보통 내렸던" 이었다
- **실화면이 사전 구멍을 잡았다** — 같은 셀트리온 사건이 "품목허가" 에만 칩. 반응 숫자가 나오기 전이라 새 키(@2)로 고칠 수 있었다

## 아쉬운 것 · 다음

- **`x or 기본값` 이 0 을 버렸다**(Holm 입력 `p or 1.0`) — 테스트가 잡았고 같은 꼴 하나를 더 찾았다(잠복). 숫자 None 검사는 `is not None` — 리뷰 때 grep 할 낱말
- **경로 전환은 옛 경로와 나란히 대조** — 코인 뉴스 upstream 을 바꾸며 동률 순서가 갈리는 것을 찾았다(정렬 키 하나)
- **부하가 큰 맥에서 잰 시간은 버린다** — 처음 잰 3~60초는 다른 프로그램 때문이었다. 다시 잴 땐 부하 평균부터 본다(`sysctl vm.loadavg`)
