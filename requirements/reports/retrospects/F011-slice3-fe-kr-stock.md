- **기획서 화면 표보다 사용자 문장이 먼저다.** 2026-10-07 "국내주식이랑 비트코인 다 같은 기능"이 있었는데 기획서 표(세 번째 탭 · 다른 열 · 검색)대로 첫 판을 만들었다. 사용자가 스크린샷 단계에서 "똑같은 화면이고 데이터만 다른거지"로 고쳤다
- **"같은 화면"은 데이터 계약부터다.** 열 하나(최고가 · 최저가)가 서버에 저장되지 않아 DB 까지 내려갔다. 화면 열 → BFF 필드 → 서버 저장 순으로 거꾸로 세면 첫 판에서 보였다
- 서버 · BFF 확장을 병렬로 맡기고 화면을 매개변수화한 덕에 같은 날 끝났다. 계약 값(필터 문자열)을 먼저 못 박은 것이 병렬을 가능하게 했다
- 실측이 기존 버그(별 클릭 → 상세 이동)를 잡았다 — 실제 클릭 흐름을 스크립트로 도는 것이 단위 테스트보다 넓다
- 확인된 사실: KIS 앱 키는 **모의투자용**("실전투자 도메인은 모의투자 앱키로 호출하실 수 없습니다") — 휴장일 TR 거부 · 처리량 약 2건/s 의 원인
- **후속("베스트 케이스로")**: 고정 응답으로 상태를 돌리자 라이브 정규장 실측이 못 본 버그 4건이 나왔다(첫 열 넓힘 · 밤 "1분" · 지연 줄 · 대비). 로고는 서버가 주소를 정하게 해 키 하나로 소스를 바꿀 수 있게 했다 — `object-fit` 조정은 실제 이미지에서 더 나빠 되돌렸다(원인은 소스)
