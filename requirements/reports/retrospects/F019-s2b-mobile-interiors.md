# F019 순서 2b 회고 — 휴대폰 탭 · 상세 안쪽

영역 회고: `salt-microFe/requirements/reports/retrospects/FE-REQ-074.md`.

- 홈만 새 모양이고 나머지가 옮기기 그대로였던 것은 순서 2 가 "옮기기"와 "디자인"을 한 REQ 에 묶고 디자인을 홈에서 멈췄기 때문 — 다음에 화면 묶음을 옮길 때는 디자인 기준(부품 표)을 먼저 정하고 화면 전부에 같이 건다
- 공용 표면(`surface.css`) 한 곳을 `/m` 값으로 바꿔 상세 화면 셋이 같이 맞았다 — 같은 종류는 공용 자리에서 고친다
- 할 일: 없음
- 검증 2회차: 시험 데이터를 화면이 보내는 모양과 다르게 넣어 없는 결함 셋을 보고했다 — 데이터를 넣기 전에 그 기능의 요청 코드를 읽는다
