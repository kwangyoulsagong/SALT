# F011 슬라이스 5b 회고 (2026-10-09)

- **"돌아간다"와 "맞는다"를 섞었다.** 슬라이스 5 는 누수 · 재현 · 달력을 엄격히 쟀지만 실력은 게이트 숫자를 그대로 믿었다. 사용자가 물어서야 블록 플라시보를 돌렸고, 국내 통과 11개가 우연 기대치(8.7)와 같았다. 다음부터 새 자산군 · 새 게이트는 **플라시보를 먼저** 돌린다(`FC-REQ-020` FR-5 상시화)
- **실데이터가 합성 테스트가 못 잡는 것을 잡았다** — `dailyCloses` 범위 필터가 보정 전 시각으로 걸러 국내 첫날 봉을 빠뜨렸다
- **화면을 이미 만들어 둔 것을 되돌렸다** — 검증 전 카드가 머지로 소유자 화면에 뜨는 것보다 낫다
- **리서치가 질문을 바꿨다**: "더 좋은 모델"이 아니라 "정직하게 잴 수 있는 단위". 순서는 위치 0 → 풀링 게이트 → 유니버스 → 척도 · 형태
- 사고: 서버에 prettier 설정이 없어 기본값(80열)이 파일 전체를 다시 썼다 — 120열 · es5 로 다시 맞추고 남은 노이즈는 손으로 되돌렸다. 서버도 파일 단위 prettier 금지(웹과 같다)
