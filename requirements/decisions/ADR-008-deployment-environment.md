# ADR-008 — 배포 환경: 같은 컨테이너 이미지 · 관리형 실행 환경 · 한 origin 경로 라우팅

- 상태: **채택 (사용자 결정 — "베스트케이스")**
- 날짜: 2026-10-30
- 대체: 맥 한 대 launchd 상시 실행(`com.salt.server`) — 서버 S7 에서 내린다
- 관련: `ADR-001`(자체 호스팅 — Vercel 네트워크 기능에 묶지 않는다) · `ADR-005` · `ADR-006` · 실행 계획 `requirements/specs/to-do/OPS-001-deploy-environment.md`

> 사용자 결정(2026-10-30): 배포 환경 질문에 *"베스트케이스"*

## 1. 결정

| 층 | 선택 | 왜 |
|---|---|---|
| 산출물 | **모든 실행 단위를 OCI 이미지 하나로** — zone 5 · BFF · platform(서비스 모듈) · `market-ingest` · forecast 잡 | 로컬 Compose · 스테이징 · 운영이 같은 이미지. "내 맥에선 됐다"가 사라진다 |
| 실행 | **관리형 컨테이너 실행 환경**(서울 리전) — 서비스별 자동 재시작 · 헬스 체크 · 무중단 롤링 · 이전 리비전 즉시 되돌리기 | 1인 운영에서 서버 관리(OS 패치 · 디스크)를 없앤다 |
| 진입 | **CDN + L7 로드밸런서 한 origin** — 경로 prefix 로 zone · BFF 에 직접 라우팅(규칙은 zone 레지스트리에서 생성). `/{zone}-static` 은 CDN 장기 캐시 | 같은 origin 이 prerender · 문서 간 전환(ADR-005 §3)의 조건. 셸 rewrites 한 홉을 없앤다(셸 rewrites 는 로컬 · 폴백) |
| DB | **관리형 PostgreSQL** — 시점 복구(PITR) · 자동 백업 · 스토리지 암호화. 스키마별 계정(`DB-REQ-036`) | 판정 원장 · 금액 원장은 잃으면 복구 불가 |
| 브로커 | **관리형 RabbitMQ** | 운영 부담 0, Kafka 전환 조건은 `SRV-REQ-044` FR-9 |
| 배치 | forecast · 반복 템플릿 · 유효기한 점검 = **예약 컨테이너 작업** | 상시 프로세스 0(ADR-004 그대로) |
| 비밀 | 관리형 비밀 저장소 — KIS · DART · LLM 키 · JWKS 개인키. 이미지 · 저장소에 비밀 0 | — |
| 환경 | `local`(Compose) · `staging`(같은 이미지 · 가짜 데이터) · `prod`. 운영 데이터는 스테이징으로 복사하지 않는다 | — |
| 배포 | CI → 이미지 레지스트리 → staging 자동 → **prod 수동 승인**. turbo 영향 그래프로 바뀐 zone · 서비스만. 공용 패키지 변경은 영향 zone 동시 배포(ADR-005 §2-6) | — |
| 관측 | OpenTelemetry 수집기 → 관리형 로그 · 지표 · 추적 + 경보(5xx · 수집 멈춤 · 데드레터 · 백업 실패) | 2026-10-09 · 10-20 국내 일봉 멈춤처럼 조용히 끊기는 사고를 잡는다 |

## 2. 선택하지 않은 것

| 안 | 왜 아닌가 |
|---|---|
| 맥 한 대 + launchd 유지 | zone 5 + 서비스 여러 개 + 브로커를 한 대에서. 장애 = 전체 중단, 백업 수동 |
| VM 한 대 + Compose | 싸지만 OS · 디스크 · 무중단 배포를 직접. "베스트케이스"가 아니다 — 비용이 문제가 되면 내려갈 1순위 대안 |
| 프론트 전용 호스팅 플랫폼의 MFE 기능 | ADR-001 — 라우팅 · prefetch 가 그 네트워크에 묶인다 |
| 쿠버네티스 직접 운영 | 서비스 수 대비 운영 비용이 크다. 관리형 컨테이너 환경으로 같은 이득 |

## 3. 결과와 위험

- **비용** — 초대제 ≤10명 대비 과하다. 최소 사양 · 스테이징 야간 정지로 줄이고, 월 비용을 OPS-001 에 기록한다.
- 리전은 서울 — 국외 이전 고지 없이 개인정보 처리(가계부 · 결제 문자 파싱 결과). 리전을 바꾸면 개인정보 처리방침 갱신이 먼저.
- KIS 모의 키 · 초당 약 2건 제한은 그대로 — `market-ingest` 는 인스턴스 1개 고정(ShedLock 이 중복 실행도 막는다).
- 클라우드 공급자 선택은 OPS-001 착수 때 — 위 표의 관리형 구성요소를 서울 리전에서 모두 주는 곳.

## 4. 되돌리기

이미지가 같으므로 VM + Compose 로 내려가는 데 코드 변경 0 — 진입 라우팅만 셸 rewrites 로 되돌린다.
