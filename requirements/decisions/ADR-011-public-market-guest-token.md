# ADR-011 — 시장 데이터는 로그인 없이 연다: 게스트 토큰 · 사람에 묶인 것과 AI 는 로그인

- 상태: **채택 (사용자 결정 2026-11-10)** — *"주식 보는 건 실시간 기능들은 로그인 안 해도 보게 해야"* · *"임시 토큰 주면 되지 · 로그인이 필요한 기능들은 다 빼면"* ·
  *"어차피 판매 목적이 아니잖아 나랑 친구들만 쓸 거니까 · KIS 토큰은 내 걸 쓰고 사용자에겐 (임시 토큰)"* · *"다 보여줘도 되잖아"* ·
  *"ai 기능들은 왠만하면 다"(로그인만)* · *"코치 판단 전망 카드도 다 로그인 이용자만"*
- 날짜: 2026-11-10
- 근거 기능: `FEATURE-018`
- 뒤집는 것: `FEATURE-011` §정책 "시세 재배포 — 공개 SEO 페이지 · 비회원 응답에 국내주식 시세를 넣지 않는다 · 소유자 전용으로 시작"(2026-09-27)
- 그대로 두는 것: `ADR-003` 전망 = 확률 · 구간 · **소유자 전용** · 마스터 인덱스 §6 공통 수용 기준 · `ADR-009` 기사 본문 AI 입력 0

## 1. 맥락

- 국내 시세는 한 번도 비소유자에게 나간 적이 없다 — 판정이 `isKrStockViewer`(이메일이 `FORECAST_OWNER_EMAILS` 안) 하나다. 초대받은 친구도 국내 탭을 못 본다
- 비로그인은 코인 일부(개요 · 요약 · 차트 · 기사 목록)만 본다. 국내 · 검색 · 왜 움직였나 · 기사 본문은 401 → 로그인 화면
- 게이트가 층마다 어긋난다(조사 2026-11-10): 코인 시세는 서버 공개인데 BFF 통과 경로가 로그인 · 국내 일정은 로그인만(소유자 판정 없음) · 왜 움직였나는 LLM 0 인 사실 묶음인데 로그인
- KRX 제3자 제공 약관과 부딪힌다는 점을 사용자에게 알렸다(2026-11-10). 사용자 결정: 비상업 · 본인 KIS 키 · 친구 사용 — 진행

## 2. 결정

**사람에 묶이지 않은 시장 데이터는 누구에게나 같다 → 로그인 없이 연다. 사람에 묶인 것과 AI 는 로그인 뒤.**

| 연다(게스트 포함) | 로그인 뒤 | 소유자만(그대로) |
|---|---|---|
| 시세 · 실시간 · 차트 · 호가 · 투자자 · 장중 수급 · 업종 · 지수 · 장 상태 · 일정 | ★ 관심 · 포트폴리오 · 매입가 · 거래 기록 · 알림 | 전망 카드 · 주요 사건 · 포지셔닝(`ADR-003`) |
| 기사 목록 · 본문(사람이 읽는 화면 — `ADR-009` 개정) · 왜 움직였나 ①② | 코치 판단 · 성적표 · 해설 · 요약 · 대화 · 사이즈 · 계획 · 미러 · 복기 | |
| 검색(종목 · 업종 · 지수 · 뉴스 · 곁 칸) | 왜 움직였나 ③ 한 줄(LLM — 단계 D) | |

- **국내 = 코인.** 자산군으로 가르지 않는다. 국내 판단도 코인처럼 로그인 전체(지금 소유자) — 소유자 판정은 **전망만** 남는다
- **게스트 토큰** — 서버가 발급하는 짧은 토큰(30분 · 사람 정보 0). 브라우저는 httpOnly 쿠키로만 든다. KIS 키 · 접근 토큰은 서버 밖으로 나가지 않는다(지금과 같다)
- **게스트 토큰은 로그인 경로를 절대 통과하지 못한다** — 서명 비밀이 다르다. 사람 토큰 검사(`authMiddleware`)가 게스트 토큰을 서명 불일치로 거절한다(코드가 아니라 비밀로 막는다)
- 화면: 로그인 칸은 **흐린 유리막 + 로그인 단추**로 덮는다(빈칸 · 숨김 아님 — 무엇이 있는지는 보인다)

## 3. 왜 토큰인가 — "토큰 없이 공개"를 버린 이유

| 안 | 버린 이유 |
|---|---|
| 공개 경로는 토큰 검사 없이 | 시장 경로마다 "로그인이면 ★ · 아니면 없음"을 섞는 선택적 인증이 필요해 `req.user!` 를 읽는 자리마다 갈린다. 남용을 셀 단위가 IP 뿐 |
| **게스트 토큰(채택)** | 시장 경로는 "읽는 사람"(사람 또는 게스트) 하나로 받는다 — 검사가 한 곳 · 발급에 IP 상한 · 실시간 중계 상한을 게스트 몫으로 따로 셀 수 있다. 사용자가 제안한 모양 |

## 4. 결과

- `FEATURE-011` §정책 · Unauthorized 줄 · 수용 기준 "비회원 국내 0건"은 정정(줄 긋고 이 ADR)
- 체크리스트의 "비로그인 401"(`BFF-REQ-040` · `043` · `044` · `053` · `FE-REQ-041` · `068` · `SRV-REQ-055` 등)은 그때 맞았던 기록 — 고치지 않는다. 새 동작은 `SRV-REQ-056` · `BFF-REQ-055` · `FE-REQ-070` 체크리스트가 잰다
- 출시(상업 · 공개)로 바뀌면 이 ADR 의 "국내 연다"를 먼저 되돌린다 — 한 곳(서버 읽는 사람 판정의 자산군 분기)에서 끈다

## 5. 되돌리는 법

서버 설정 `PUBLIC_MARKET_GUEST=false` → 게스트 토큰 발급 403 · 시장 경로는 사람 토큰만. 국내를 다시 소유자로 좁히는 건 `isKrStockViewer` 판정을 시장 읽기에 되붙이는 코드 변경(이 슬라이스 커밋 하나 revert)
