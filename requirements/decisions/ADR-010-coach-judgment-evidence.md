# ADR-010 — 코치 판단의 "근거"는 엔진이 본 사실이다: 관망도 판단이고, 보류는 이유를 말한다

- 상태: **제안 (2026-11-09)** — 사용자 결정 대기(`FEATURE-017` 사용자 결정 표 D1)
- 날짜: 2026-11-09
- 근거 기능: `FEATURE-017`(AI 코치 베스트 케이스) · 리서치 `requirements/reports/research/2026-11-09-ai-coach-best-case.md`
- 관련: 마스터 인덱스 §6 공통 수용 기준 1(근거 · 과거 적중률 · 실패사례 3종) · `ADR-003`(전망 3종 — 이 ADR 은 전망을 건드리지 않는다) ·
  `ADR-009`(오늘 왜 움직였나 — 같은 검증기 · 같은 인용 규칙) · `FEATURE-004` · `FEATURE-010`(판단 엔진 v2 · 원장)

## 1. 결정

**공통 수용 기준 1의 "근거"를 "엔진이 이 판단에 실제로 쓴 사실"로 정의한다. 문턱을 넘은 문장만이 아니다.**

| 칸 | 지금 | 바꾼 뒤 |
|---|---|---|
| 근거 | 문턱을 넘은 항목의 문장(`reasons` · 피하기면 `risks`) — 관망이면 0개 | **항목별 관측(값 · 문턱 · 문턱까지 거리 · 기여 점수)** + 넘은 항목의 문장. 관측이 하나라도 있으면 근거가 있다 |
| 과거 적중률 | 같은 모드 · 같은 행동의 채점 성적 | 그대로 — 관망도 행동이라 이미 채점된다(성적 76건 실측). 관망의 채점 기준 문장을 화면에 같이(무엇을 맞힌 것인가) |
| 실패사례 | 같은 행동이 빗나간 사례 | 그대로 |

**판단과 보류를 가른다.**

| 상태 | 뜻 | 화면 |
|---|---|---|
| 판단(후보 · 관망 · 피하기) | 엔진이 재료를 다 봤다 | 3종이 다 있으면 렌더. 관망은 "규칙이 신호를 내지 않았어요" + 본 값 |
| 보류 | 엔진이 볼 수 없었다 — 재료 멈춤 · 이력 부족 · 표본 < 20 · 투자유의 · 열지 않은 모드 · 실패사례 0 | 이유를 사실로("RSI 를 사흘째 못 받았어요") — "근거가 부족해"라고 뭉뚱그리지 않는다 |

`reasons_missing` 사유는 없어진다 — 관측이 0개인 경우(재료 전부 결측)는 이미 `stale_inputs`/결측 항목이 먼저 막는다.

## 2. 왜

- 신호 없는 날이 대부분이다. 근거를 "넘은 문턱의 문장"으로만 두면 표본이 쌓여도 판단이 영영 안 열린다(2026-11-09 BFF 실측: BTC 두 모드 · 국내 대형주 장기 전부 `reasons_missing`, 표본 76~365)
- 관망은 엔진이 값을 보고 문턱 밖이라 판정한 **결과**다. 그 값은 원장(`judgment_ledger` 항목 기여)에 이미 남는 사실이다 — 지어낸 근거가 아니다
- 선택적 예측 연구: 보류를 드러내는 의사결정 지원이 사용자가 느끼는 품질을 떨어뜨리지 않았다. 대신 보류의 **이유**가 보여야 한다(리서치 §3)

## 3. 지키는 선 — 바뀌지 않는다

- 3종이 다 있어야 렌더한다(기준 1 그대로). 표본 < 20 · 실패사례 0 이면 막는다
- 관측 값은 서버가 낸 숫자 그대로(반올림은 응답 직전 1회). LLM 이 관측을 만들거나 고치지 않는다
- 관측을 "이유"로 꾸미지 않는다 — "RSI 48(과열 70 · 침체 35 사이)"는 사실, "그래서 안전합니다"는 금지(확신 표현 · 인과 단정 0)
- 사람마다 같은 판단(보유 · 평단 0)

## 4. 영향

- 서버 `coach`: `judgmentEvidence` · `judgmentGate` · 응답에 관측 칸(`SRV-REQ-053` FR-1 · 2)
- BFF: 판단 뷰모델에 관측 · 보류 사유(`BFF-REQ-052` FR-1)
- FE: 판단 블록 · 보류 문구(`FE-REQ-064` FR-1 · 2)
- 원장 · 채점: 변경 없음(관망은 이미 채점) — 관망 채점 기준 문장만 화면에(`FC-REQ-028` FR-1 이 기준 확인)
- `FEATURE-004` FR(근거 정의) · `FEATURE-010` 게이트 문장 · 마스터 인덱스 §6 기준 1 문장에 "근거 = 엔진이 본 사실(`ADR-010`)" 한 줄(채택 때)

## 5. 되돌리기

게이트 함수의 근거 판정 한 줄(`관측 ≥ 1` → `문장 ≥ 1`)과 응답 칸. 원장 · 채점 무변경이라 데이터 이동 0.
