- 상태: **채택 (사용자 결정)**

- 관련: `ADR-003`(전망을 연다) · 리서치 `requirements/reports/research/2026-09-23-ai-forecast.md` · `FEATURE-008`

> *"데이터 파이프라인 - 온톨로지 - 에이전트"*

## 1. 결정

**다섯 번째 영역 `salt-forecast/`(Python 배치 워커)를 둔다.** 상시 HTTP 서버가 아니다 — 예측이 하루 1회라
온라인 추론이 필요 없고, **DB 스키마 하나가 계약**이 된다.

| 층 | 어디 | 무엇 (전부 무료 · CPU) |
|---|---|---|
| 수집 | `salt-forecast` | 업비트(시세) · 바이낸스 선물 공개(펀딩비 · 미결제약정) · DefiLlama · 영문 뉴스 무료 API. 주식(DART · SEC)은 **TBA**(2026-09-23 범위 축소) |
| 온톨로지 | `forecast` 스키마 | Postgres 엔티티 · 관계 · 사실 테이블(시점 고정 · 출처). 그래프 DB 없음 |
| 숫자 | `salt-forecast` | 기준 모델(무작위 보행 · 경험 분위수) → LightGBM 분위수(종목 풀링) → (선택) Chronos-Bolt 제로샷 → 정규화 CQR 보정(종목 풀링, 슬라이스 16 자체 구현) |
| 텍스트 신호 | `salt-forecast` | FinBERT(영문 감성, CPU) |
| 채점 | `salt-forecast` | 워크포워드(엠바고) · pinball · 커버리지 · 방향 적중 · 기준 대비 · 자동 소등 |
| 해설 | `salt-server` `coach` | **템플릿 기본**(사실 선택 규칙 + 결정적 템플릿). 로컬 소형 모델 · 무료 LLM 은 선택 다듬기, 같은 검증기(숫자 대조 · 금지어 · 명령형 · 인용) 통과 시만 |

## 2. 왜

- **LLM 은 가격을 예측하지 못한다.** LLM 백테스트는 학습 데이터 기억으로 부풀려지고(리서치 §1.2), LLM 에이전트는
  단순 보유에 대체로 못 미쳤다(§1.3). 숫자는 채점 가능한 통계 모델이 내야 한다.
- **파운데이션 시계열 모델도 방향은 거의 동전이다**(일간 약 50~51%, §2.2). 그래서 주력은 우리 피처를 먹는
  LightGBM 분위수이고, 파운데이션 모델은 구간 폭 보조로만 — **기준 대비 채점이 양수일 때만** 앙상블에 들어간다.
- **현실적인 목표는 주간 방향 52~55% + 90% 구간 커버리지 90% 근처**(§0). 이보다 높으면 먼저 누수를 의심한다.
  우리가 약속하는 것은 "잘 맞는다"가 아니라 **"90% 구간이 실제로 90% 맞고, 폭이 기준보다 좁고, 그 성적을 숨기지 않는다"** 다(FR-10).
- 요청 경로 밖(배치)이라 Python 장애가 화면을 막지 않는다. 서버는 DDD 경계 그대로 읽기만 한다.

## 3. 선택하지 않은 것

| 안 | 왜 아닌가 |
|---|---|
| 우리 LLM 학습 · 파인튜닝 | 비용 대비 예측 정확도에 기여 근거 없음. 금융 사전학습은 수십억 건 규모 |
| LLM 에이전트가 숫자 예측 | 채점 불가 · 기억 누수 |
| FastAPI 상시 서버 | 일 1회 예측. 테이블이 계약이면 충분 |
| Neo4j(GPL) · Memgraph(BSL) | 2~3 홉 질의는 Postgres 재귀 CTE 로 충분. 도입은 측정된 지연이 근거일 때 |
| Moirai 2.0 | 가중치 CC-BY-NC |
| Airflow | 1인 규모에 과함. cron → 필요 시 Prefect |
| 투자자별 수급(KRX) | 공식 API 미제공 · 증권사 API 는 계좌가 필요 — 글로벌 플랜 §1-2(계좌 연동 없음)와 충돌. 열린 질문 |

## 4. LLM (문장만) — **2026-09-23 개정: 템플릿이 기본, LLM 은 선택 다듬기**(`FEATURE-008` FR-45)

- 무료 Gemini 는 **입력 · 출력이 학습 · 사람 검토에 쓰일 수 있다**(약관, 리서치 §5). 그래서
  **프롬프트에 보유 수량 · 평단 · 원화 손익을 넣지 않는다.** 금액은 서버 값을 화면이 직접 그린다. 문장은 공개 정보 · 비율 · 구간만 다룬다.
- 모델은 무료 후보(Gemini 2.5 Pro · Gemini Flash 계열 · Groq gpt-oss-120b)를 **같은 입력 블라인드 A/B 20건**으로 고른다.
  공급자 교체가 쉽도록 `CoachExplainer` 포트 뒤에 둔다.

## 6. 단계 (리서치 §9)

1. 원천 테이블(시점 고정) + 기준 모델 + conformal + 채점 → **이것만으로 "구간 + 적중률" 화면이 가능**
2. LightGBM 분위수 + 공시 · 내부자 피처 → 기준 대비 양수일 때만 교체
3. 뉴스 감성 · 온체인 · Chronos 앙상블 — 추가마다 채점으로 채택
4. **라이브 기록 52주 전까지는 백테스트 적중률을 "백테스트"로 표시**한다(라이브와 섞지 않는다)
