# ADR-009 — 오늘의 등락을 설명할 때의 선: 숫자로 나누고, 근거로만 말하고, 원인을 단정하지 않는다

- 상태: **채택 (사용자 결정 2026-11-06)** — 사용자 결정(2026-11-06): *"우린 어차피 출시가 아니자나 해도대 나랑 친구들 쓰기 위해서"*. 비상업 · 초대제(본인 + 친구) · 무료 전제. 출시(상업 · 공개)로 바뀌면 §2 법의 선을 법무 확인과 함께 다시 연다
- 날짜: 2026-11-06
- **개정 2026-11-09 — 기사 본문을 화면에 보인다**(사용자 결정 2026-11-09: *"저작권 이게 의미가 없는게 어차피 우리 판매 안하잖아"* · *"국내도 똑같에"*).
  비상업 · 초대제 전제는 그대로. 단 **본문은 사람이 읽는 화면에만** — ③ 한 줄 요약(LLM) · 코치 프롬프트 입력에 넣지 않는다(포털 검색 API 약관이 AI 답변
  생성 이용을 금지 — 아래 §2 마지막 줄은 그대로 유효). 구현 `SRV-REQ-054` · `BFF-REQ-053` · `FE-REQ-068` · `DB-REQ-042`. 출시(상업 · 공개)로 바뀌면 이 개정을 먼저 되돌린다
- **개정 2026-11-10 — 소식 태그는 측정값으로 붙인다**(사용자 선택 "측정 문구" · `FEATURE-017` FR-5). 소식 행에 사건 종류(실적 · 수주 · 유상증자 …) +
  같은 종류의 과거 반응(1일 · 5일 · 표본 · 오른 비율 — 시장 몫을 뺀 초과 반응) + 선반영(발표 전 5일)을 붙이고, 문구는 "보통 올랐던 소식 · 보통 내렸던 소식 · 반응 엇갈림"뿐.
  **호재 · 악재 단어 0** — 의견이 아니라 채점되는 숫자다(LLM 이 주가 영향을 고르면 전문가와 52% 일치 — 리서치 `2026-11-10-ai-coach-scenario.md` §3). 분류는 규칙 사전(LLM 0)
- 근거 기능: `FEATURE-016`(오늘 왜 움직였나 — 등락 이유 · 시장 상태 태그 · 국내 짝 맞춤)
- 관련: 마스터 인덱스 §6 공통 수용 기준(확신 표현 0 · LLM 은 문장만) · `ADR-003`(전망은 확률 · 구간 · 소유자 전용) ·
  `FEATURE-008` 해설(출처 인용 · `SRV-REQ-050` LLM 라우팅) · MONEY 글로벌 플랜(투자 동결)

## 1. 결정

**"왜 올랐을까 · 왜 떨어졌을까"를 연다. 단 설명은 세 층이고, 위 층일수록 엄격하다.**

| 층 | 무엇 | 누가 만든다 | 규칙 |
|---|---|---|---|
| ① 숫자 분해 | 오늘 등락 = 시장 몫 + 업종 몫 + 종목 고유 몫 | 서버 계산(LLM 0) | 늘 먼저 보인다. 근거가 없어도 이것만으로 말이 된다("오늘 코스피 -8.6% — 이 종목 하락의 대부분이 시장 전체 움직임") |
| ② 같은 날 사실 | 공시 · 기사 제목 · 수급(외국인 · 기관 · 프로그램) · 시장 조치(서킷브레이커 · 사이드카 · VI · 거래정지 · 시장경보) · 코인 거래소 유의 · 주의 플래그(공식 마켓 상세 — 비공식 공지는 안 씀, 2026-11-06 사용자 결정) | 원천 그대로(제목 · 출처 · 시각 · 링크) | 사실만 나열 — 순서는 시각 |
| ③ 한 줄 요약 | ①과 ②를 한 문장으로 | LLM | **②에 있는 항목만 인용**(인용 없는 주장은 버림) · 숫자는 ①에서 주입(LLM 이 쓴 숫자 버림) · 인과 단정 금지 · AI 생성 표시 |

**연다 / 계속 막는다**

| 연다 | 막는다 |
|---|---|
| 상승 · 하락 대칭 — 같은 조건에서 같은 모양 | "~때문에 올랐다" 단정 · "더 오를 것" 같은 앞날 문장 |
| 시장 · 업종 몫이 크면 "종목 고유 소식이 뚜렷하지 않음"이라고 말하기 | 근거 없을 때 그럴듯한 이야기 만들기 |
| 기사 **제목 · 출처 · 시각 · 원문 링크** · **본문 읽기(사람만 — 2026-11-09 개정, 모달에서 출처 · 원문 단추와 함께)** | 기사 본문 ~~저장~~ · **LLM 요약 · 코치 입력**(저작권 — 국내 소송 진행 · EU 법무관 의견 2026-11 · 포털 API 약관) — 본문 캐시는 화면 다시 열기용(`news_article_body`) |
| 서킷브레이커 · VI · 거래정지 표시와 "마지막 체결 시각" | 정지 중 값을 실시간처럼 보이기 |
| 사람마다 같은 설명(보유 여부와 무관) | 개인 맞춤 매매 조언 · "지금 사세요/파세요" |

## 2. 왜

- **원인 귀속은 검증이 가장 어려운 일이다.** 금융 해설 연구는 LLM 이 그럴듯한 인과를 지어내는 것을 핵심 문제로 꼽고, 평가도
  "사실 일치 · 인과 일치"를 따로 본다. 그래서 인과를 말하는 층(③)을 가장 좁게 둔다 — 근거 목록 안에서만, 단정 없이
- **숫자 분해는 거짓말을 할 수 없다.** 2026-11-06 코스피 서킷브레이커 날, 삼성전자 -9.98% 의 대부분은 시장 몫이었다.
  이것을 먼저 보이면 "왜"의 절반이 숫자로 끝나고, 기사 제목을 엮은 이야기가 그 날을 개별 악재처럼 보이게 하는 일을 막는다
- **법의 선**(2차 자료 조사 — 법무 확인 전): 유사투자자문의 규제 대상은 대가를 받는 투자판단 조언 · 1:1 개별 조언 · 자동 종목 선택 ·
  수익 보장 광고다. 지난 사실을 같은 모양으로 설명하는 것은 조언이 아니게 설계한다(앞날 문장 0 · 매매 지시 0 · 사람마다 같음).
  AI 기본법(2026-01-22 시행) 제31조 — 생성형 AI 결과물 표시 의무 → ③에 표시
- ~~**기사 본문을 쓰지 않는다**~~ **정정 2026-11-09: 본문은 사람이 읽는 화면에만 쓴다 · AI 입력에는 쓰지 않는다**(머리 개정) — 국내 언론사 · 포털 AI 소송과 EU 판단이 진행 중이다. 제목 · 출처 · 링크는 포털 검색 결과 수준이다.
  포털 검색 API 는 2026-09 약관 개정으로 AI 답변 생성 이용을 금지했다 → 원천에서 뺀다

## 3. 새 게이트 — 설명 3종

③(한 줄 요약)은 아래 셋이 다 있어야 렌더한다. 하나라도 없으면 ①②만 보인다.

| 필수 | 내용 |
|---|---|
| 숫자 분해 | 시장 · 업종 · 고유 몫(같은 응답) |
| 인용 1개 이상 | ②의 항목 id — 서버가 원천 목록과 대조 |
| 생성 표시 | "AI 가 같은 날 소식으로 정리했어요 — 원인을 단정하지 않아요" |

> **켜는 시점(2026-11-06 결정)** — ③은 평가 문턱을 기다리지 않고 켠다. 위 3종 게이트 · 인과 단정어 가드 · AI 표시는 그대로 두고, 품질(인용 충실도 · 소식 없음 정직률)은 쓰면서 잰다(`FC-REQ-027`). 나빠지면 §4 끄기 하나

## 4. 되돌리기

③만 끄는 서버 설정 하나(①②는 남는다). 끄면 화면은 숫자 분해 + 사실 목록이다.
