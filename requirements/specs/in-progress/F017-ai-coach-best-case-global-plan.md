## 판단 — 리뷰가 볼 곳

1. **근거 = 엔진이 본 사실**(`ADR-010`) — 관망도 판단, 보류는 이유를 말한다
2. **판정 권한은 채점된 규칙 · 모델에만** — LLM 은 문장. 단타 확률도 시험을 통과한 모델만
3. **명령 대신 점검** — "사세요 · 파세요" 0, 조건 + 과거 결과 + 채점
4. **시장 층 · 내 층** — 확률 · 기저율 · 태그 · 해설은 종목마다 한 번(사람마다 같음), 내 층은 서버 계산만 · LLM 입력 0
5. **요청 경로는 저장값만** — 외부 호출 · LLM 0, 늦으면 받아 둔 값 + 시각(단계 0 의 불변식을 새 칸에도)
