## 판단 — 리뷰가 볼 곳

1. **@1 무효 — 기준이 둔하고 셔플이 샜다.** 365일 기후값 기준은 모델의 최근 60일 Beta 보정보다 둔해 피처 없이도 이긴다(+0.0022). 날짜 안 셔플은 1시간 격자에서 앞 시간 라벨이 뒤 행 피처 창과 겹쳐 샌다(+0.0012). 라벨을 8~30일 미루면 피처 몫이 사라진다 — **피처 누수는 없다**. 첫 가설(셔플만 샘)은 틀렸고, 등록 전에 확인해서 잡았다
2. **@2 = 같은 기간을 봤다 → 통과해도 화면은 라이브 증명 뒤.** 기준(피처 없는 같은 보정 모델) · 플라시보(8~30일 미룸)만 바꿨다. 통과는 원장 발행 허가뿐, 화면 확률은 등록 뒤 라이브 확신 300 · 늘 오른다보다 나음 하한 > 0(`live_ready`, 예측이 정하고 서버는 읽기만)
3. **@2 의 기준 (4)도 결함 — 화면 문장까지 고쳤다.** 오른 비율이 43% 라 '확신'의 99% 가 '안 오름' 쪽이고 그대로(11.5%)도 맞힘이다. "59% vs 늘 오른다 41%"는 늘 안 오른다(59%)와 같은 성적이다. 막힌 카드에도 나가는 줄이라 늘 안 오른다를 같이 싣고 '내렸어요' → '안 올랐어요(내렸거나 그대로)'
4. **변동 범위 카드는 지웠다** — 막힌 지평을 대칭 범위로 채우지 않는다(사용자 *"상하 표준 범위면 고양이도 다 저렇게 생각하지"*). 서버 · BFF 의 `/coach/forecast` 경로는 화면 소비처 0 — 코치 도구 쪽 확인 뒤 정리
5. **라이브 표본은 키로 센다** — 커밋 해시가 든 모델 버전으로 세면 배포마다 0 으로 돌아간다

6. **@3 = 전진 시험** — 같은 기간을 세 번 봐 과거로는 더 판정하지 않는다. 예측은 결과를 알기 전에만 기록한다(코인 봉 마감 15분 · 국내 다음 장 시작 전, 경계 표 테스트). 첫 라이브 회차에서 국내 예측이 만기 뒤 기록된 것을 잡아 지웠다 — 이 규칙이 없으면 전진 시험이 답을 보고 쓴 시험이 된다
7. **σ 를 등록대로** — 구현이 등록보다 엄해(창에 구멍 하나면 없음) 업비트 정기 점검 뒤 일주일 코인 예측이 0 이었다. @1 · @2 리포트에 정정을 적었다(판정 그대로)
