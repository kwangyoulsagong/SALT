## 판단 — 리뷰가 볼 곳

1. **판정 기준을 엄격하게** — 후보 2개 Bonferroni(98.75%) CI 하한 > 0 **그리고** 5개 목표 전부 점추정 > 0. 생존 편향이 알트에 유리해서다. 결과는 느슨한 기준으로도 탈락이었다
2. **목표 0 을 "초과"로 두지 않았다** — 알트를 규칙 대상에 남기고 비중 0 을 주면 화면이 "초과 −1,090,000원"이 된다. 매도 지시와 같아서 `no_record` 로 빼고 금액을 만들지 않는다
3. **부족분을 쓸 수 있는 돈 안으로만** — 알트를 빼면 core 목표 + 알트 평가금 > 전체가 된다. 줄이지 않으면 "알트를 팔아 core 를 사라"는 계산이 나온다. 비중은 그대로, 원 · 수량만 비례로 줄이고 표시
4. **라이브 원장은 봉이 있는 월요일만** — 수집 전에 돌면 비중 0 행이 불변 표에 박힌다(테스트로 잡음). 다시 계산한 값이 저장값과 다르면 멈춘다
5. **투자 화면에는 요약만, 그래도 고지는 붙인다** — 목표 비중 칸에 3종 고지 한 줄(근거 · 과거 연수익 · 낙폭 · 가장 크게 잃은 달). 성적표 칸은 건수만(적중률 단독 금지)
6. 위험 카드는 리포트 리스크 예산 패널과 같은 내용이라 **지웠다** — 두 벌이던 것
