## 판단 — 리뷰가 볼 곳

1. **채택 기준을 AUC 가 아니라 BSS 하한에 걸었다.** AUC 0.65 는 순위를 맞힌다는 뜻이지 "18%" 라는 숫자가 18% 로 일어난다는 뜻이 아니다.
   화면에 나갈 것은 숫자라서 기저율 대비 Brier 개선이 기준이다. 결과가 기준 경계(CI 0 포함)라 문턱을 만지고 싶어지는 자리다 — 안 만졌다
2. **셔플 점검 실패를 누수가 아니라고 판단한 근거** — 종목 간 AUC 0.491 · 전체 셔플 0.495 [0.488, 0.503] · 시점 몫 상한 0.859.
   사전등록 문구대로 판정은 "무효 · 채택 안 함"이고 문구는 고치지 않았다. 진단은 작업 코드에 넣어 재현된다
3. **라벨을 화면 익절 계획에 묶었다**(장벽 재설정 안 함, 양성 12%). 확률이 화면 가격선에 대한 말이 되게 하려는 것 — 리서치 20~60% 게이트와 다르다. `meta-model@2` 에서 다시 본다
4. **층 독립** — `scoring.meta_model` 은 `Learner` Protocol 만 알고 `models` 를 import 하지 않는다. 작업이 이어 준다(import-linter 계약 그대로)
5. **LightGBM 을 고르지 않았다** — 로그손실 차 CI 가 0 을 품어 단순한 쪽(리서치 §6-2)
