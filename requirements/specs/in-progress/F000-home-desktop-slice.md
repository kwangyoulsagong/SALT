## 판단 — 리뷰가 볼 곳

1. **아이콘 파일 다시 만들기** — `analysis.svg` 8.2MB · `mission.svg` 490KB 는 원본 이미지를 품고 있었다. 브라우저로 3배(105px) 그린 PNG 를 담은 SVG(10 · 9KB)로 — 이름 · 크기 그대로라 소비처 0 변경. 105px 넘게 키우면 원본보다 흐리다(지금 쓰는 크기 35 · 레티나 70 은 같다)
2. **빈 카드는 크게 쓰지 않는다** — `state: empty` 의 "아직 없어요"를 주인공 18/700 자리에 두면 숫자처럼 보였다. 13/600 2단으로
3. **사이드가 비면 칸째 접는다** — `:has(> aside:empty)`. 시작하기를 끝냈고 숨긴 도메인 때문에 바로 적기도 없으면 312 칸 · 선이 남지 않는다
4. **앱 웹뷰는 시작하기를 본문 카드로** — 사이드가 없어서. 데스크톱 · 태블릿 웹은 행. 같은 쿼리라 요청 하나
5. **100칸 점 파랑은 쓰지 않는다** — 응답은 오른 수(`dots`)만 준다. 내림 · 그대로를 가르려면 서버 계약이 필요하다 — 시안도 빨강 · 회색이었다
6. **날짜 줄은 넣지 않았다** — 리서치 제안이었지만 렌더 중 지금 시각은 수화를 가른다. 서버가 기준 날짜를 줄 때
