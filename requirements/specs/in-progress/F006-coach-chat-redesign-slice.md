## 판단 — 리뷰가 볼 곳

1. **코치가 `plan` 을 import 하지 않는다** — 코치(coach 서비스 S6)와 적립(portfolio 서비스 S4)은 갈라질 서비스다. 코치 응용층에 좁힌 모양의 소스(`weeklyPlan`)만 두고 조립(`composition.ts`)이 `plan` 유스케이스를 끼운다 — 다른 재료와 같은 꼴. 갈라지면 이 자리만 원격 호출로
2. **금액은 옮기기만** — 주간 계획의 원 정수를 문장에 넣는다(계산 0 · 지시형 0 — "계획이 이 금액"). 못 읽으면 그 문장만 "불러올 수 없어요" + `gaps: weekly_plan`
3. **답은 말풍선 없는 본문** — 회색 답 말풍선 + 진한 보라 질문이 섞여 어색했다(리서치 A). 브리핑은 카드
4. **이어 묻기는 지금 칩 넷에서 방금 물은 것을 뺀 셋** — 서버가 정하는 이어 묻기는 LLM 이 붙을 때. 칩 문장은 서버 `COACH_CHIP_QUESTION` 과 같은 고정 문장이라 프론트가 새로 정한 것이 아니다
5. **격자를 안 쓰게 됐는데 지우지 않았다** — 오늘 아침 만든 배치 저장(표 · 경로)까지 지우면 되돌리기가 크다. 다른 화면이 쓸지 지울지 정할 때(체크리스트 미검증 표)
