## 결정

1. **상한 값 — 질문 100개 · 90일**(이 작업에서 정함, 서버 상수 두 개). 근거: 생성 기록 90일 보존 선례 · 100개 = 화면 약 7쪽(30개씩)이라 위로 끝까지 5초
2. **정리는 질문 저장 직후**(cron 0) — 대화는 질문할 때만 늘어난다. 맥이 꺼진 동안 놓치는 회차가 없다
3. **경계 = 남길 질문의 시각** — 메시지 수로 자르면 답이 홀로 남는다
4. `FE-REQ-031` FR-25 "자동 삭제 0건"을 사용자 말로 정정 — 자동 삭제는 보관 한도 하나

## 판단 — 리뷰가 볼 곳

1. `coachHistoryCutoff`(domain policy) — 경계 표 시험 8. 저장소는 "최근 질문 시각"과 "경계 앞 지우기"만
2. 지우기 세 문장(메시지 → 빈 대화 → 수 재계산)을 트랜잭션으로 묶지 않음 — 멱등이라 다음 질문이 마저 한다(인프라는 트랜잭션을 열지 않는다)
3. BFF 틀린 커서 400 — 계약 변경(전엔 조용히 첫 쪽). 프론트는 맞는 커서만 보내므로 화면 영향 0, 그래도 화면에 되풀이 멈춤 · 겹침 거르기를 둠(이중 안전)
4. 쪽 이어붙이기 규칙을 `@repo/core/coach` 로 — 앱(RN)도 같은 함수
