## 판단 — 리뷰가 볼 곳

1. **서킷브레이커는 지수 분 기록으로 추정한다** — 장운영정보 실시간 필드는 발동일에만 실측할 수 있다. 1분 넘게 지수가 소수 넷째 자리까지
   그대로 + 전일 대비 단계 문턱 이하 = 매매 정지. **같은 기록이면 같은 답**이라 매분 다시 돌려도 행이 늘지 않고, 지난 날로 재생 검증한다
   (2026-11-06 실제 기록 → 09:04 시작 · 09:34 끝 · 재개 예정 09:24). 14:50 뒤 1 · 2단계 0 — 종가 단일가 10분 멈춤을 읽지 않게. 사이드카는 추정 0
2. **마지막 체결은 값이 멈춘 이유가 있을 때만 응답에** — 평소 매 행에 시각을 붙이면 "멈춘 값" 신호가 묻힌다. 폴링 종목은 누적 거래량이
   는 회차 시각(오차 1분 안), 실시간 종목은 체결 시각. 상세의 옛 "거래정지 · 마지막 체결"은 **시세 받은 시각**을 쓰고 있었다 — 그날 매분 바뀌어 멈춘 값을 실시간처럼 읽게 한 자리다
3. **거래정지(58)와 임시정지(플래그)를 가른다** — 기존 테스트 기대값 하나를 바꿨다(`halted` → `paused`, 같은 테스트에 정정 주석)
4. **BFF `/status` 경로를 따로 만들지 않았다** — 띠가 있는 두 화면(요약 · 상세)의 기존 응답에 실었다. 요청 하나가 줄고, 쓰지 않는 경로를 두지 않는다(`BFF-REQ-051` FR-2 정정)
5. **VI 현황은 최근 30건 한 쪽뿐**(실측 — 연속 조회 머리가 비어 온다). 1분에 30건 넘게 발동하면 그 앞쪽 종류 · 시각을 놓친다 — 칩 자체는 현재가 상태 칸 `vi_cls_code` 로 선다
