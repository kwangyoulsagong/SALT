## 판단 — 리뷰가 볼 곳

1. **국면 칸은 참고 라벨이다** — "판정 · 비중에 쓰지 않아요"를 늘 붙였다. 검증이 게이트를 채택하지 않았는데 화면이 "지금 사지 마세요"로 읽히면 결과와 반대를 말한다. 국면 모델 고변동 확률은 그리지 않았다(숫자는 판정 확률로 읽히고, 라벨 경계는 서버 임계)
2. **성적표는 표본 부족이면 숫자 대신 감춘 이유** — 문턱 숫자는 서버 판정만 따른다. 빗나간 판정은 최근 순(선별 없음)
3. **소유자 카드 3장을 접었다** — F008 의 핵심 카드가 한 번 눌러야 보인다. 리서치 §9-4 순서를 따랐고, 되돌리려면 `ee8778c` 하나
4. 위험 카드는 리포트 게이지와 **같은 응답 · 같은 컴포넌트**(요청 증가 0). 설정 폼 · 시나리오는 리포트에만
5. 200일선이 없을 때 서버 `trendOpen: true`(게이트 없음)를 BFF 에서 `null` 로 — 판정 기본값이 화면 사실이 되지 않게
