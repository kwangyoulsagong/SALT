## Summary

슬라이스 6 의 상세 분석 페이지 차트를 투자 화면 프리뷰(SVG `PreviewChart`)에서 떼어 **자체 구현 캔버스 차트**
(`@repo/ui/tradingChart`)로 바꾼다. 패널은 프리뷰 그대로다. 영역 하나(프론트)라 본문은 영역 REQ 에 있다 —
이 문서는 전 영역 지도에서 찾을 수 있게 남기는 색인이다.

## 판단 — 리뷰가 볼 곳

1. **캔버스 두 장 + React 는 그리지 않는다** — `canvas.md` 도입 보고는 `salt-microFe/requirements/reports/checklists/FE-REQ-034.md` §3
2. **이동평균은 프론트 계산** — 공통 수용 기준 3 을 사용자 돈에 대한 규칙으로 읽었다. PM 확인 대기
3. **`next/dynamic` 을 쓰지 않고 청크를 직접 불러 상태로 든다** — Suspense 가 그리기를 최대 300ms 늦췄다(실측)
4. **기존 버그 둘을 같은 브랜치에서 고쳤다**(별도 커밋) — 프리뷰 실시간 봉이 틱마다 붙던 것, 서버 일봉 `date` 키
