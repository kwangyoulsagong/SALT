## 판단 — 리뷰가 볼 곳

1. **S2b 를 둘로 좁혔다** — 내 숫자로(FR-6)는 저축 · 가계부 값을 읽어 서비스를 넘고(`msa-services.md` §5 — 프로젝션이냐 BFF 순서냐를 정해야 한다), 나머지 트리거는 붙일 공적 제도 글이 먼저다, 홈 카드는 S3 홈 카드 묶음 몫. 셋을 **S2d** 로(S2c 는 notification)
2. **정답은 서버만 안다** — 공개 글 응답엔 질문 · 보기만. 로그인 없는 채점 경로(`/tips/{slug}/quiz`, 기록 0)를 하나 더 열었다 — 정답 판정이 화면 · BFF 로 갈라지지 않게. 세션이 있는데 401 이면 BFF 가 익명으로 바꾸지 않는다(카드를 조용히 잃는다)
3. **재촉 0** — FEATURE-014 "30초 먼저 맞혀 보기"를 문제 길이 목표로 읽었다. 시간 제한 · 점수 · 연속 기록 없음, 카드는 한 번 생기면 다시 틀려도 남는다
4. **"모른다"와 "안 바뀜"을 가른다** — 줄을 모르는 판(S2a 이력 · 첫 판)은 `changes: null`, 상태만 바뀐 판은 `[]`. 줄은 사람이 읽는 문장만(검수일 · 퀴즈만 바뀐 판이 줄을 내지 않는다)
5. **브라우저 요청은 엔티티 배럴 밖** — 공개 서버 페이지 `/tips` 가 배럴을 값으로 읽어 143 → 147 kB 가 됐다. feature · page `api/` 로 옮겨 144(main 과 나란히 빌드)
