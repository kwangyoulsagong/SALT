## 판단 — 리뷰가 볼 곳

1. **채택 게이트 없이 화면에 낸다**(사용자 결정). 대신 "화면이 쓸 수 있는 문장"을 결과 전에 등록했다 — 결과가 나빠도(타이밍 ✗) 그 문장을 그대로 쓴다
2. **σ 원천을 `annualized` 가 아니라 `ewma` 로** — 같은 뷰의 두 σ 중 사이즈 계산은 채점 게이트를 지난 값, 이 규칙은 등록 정의(게이트 없음). 실데이터에서 ETH 가 빠지는 것을 보고 고쳤다
3. **투자금이 없으면 코인 평가금 합을 전체로** — 그러면 모든 종목이 "초과"다. 계산은 맞지만 "다 팔라"로 읽히지 않게 화면이 기준과 입력 경로를 줄 목록 위에 둔다
4. **보유 알트에도 비중을 준다**(사용자 결정) — 그런데 알트 섞인 기록은 나빴고 등록대로 화면에 쓰지 않는다. 사용자가 알트를 들고 있으면 고지(BTC · ETH 기록)와 실제 안내 묶음이 다르다. 다음 등록에서 결론을 낸다
5. **고지를 접지 않았다** — 카드가 길어졌다(360 폭). 슬라이스 3 의 "소유자 카드 접기"와 반대 판단: 저쪽은 참고 카드, 이쪽은 비중 옆 고지
6. 규칙 식이 Python · 서버 두 곳 — 같은 고정 벡터 테스트 + 서버 상수 ↔ 리포트 대조 테스트로 묶었다
