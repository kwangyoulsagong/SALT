## Summary

화면 없음. 사용자가 적은 거래(수동 입력)와 계획으로 서버가 **계획을 지켰는지 · 청산마다 얼마를 벌고 잃었는지 · 어떤 실수에 얼마를 썼는지**를
쌓는다. 6시간마다 멱등 배치가 결과를 다시 만들고, `GET /api/coach/mirror` 가 준수율 · 처분효과 · 보유 대비 · 회전율 · 태그 비용을 준다.
슬라이스 5(코치 리포트 "내 거래 미러")가 이 숫자를 보인다.

## 판단 — 리뷰가 볼 곳

1. **원가 = FIFO + 매수 수수료** — `portfolio.realizedProfit` 과 매수 수수료만큼 다르다. 매수 기록 없는 매도는 결과를 만들지 않는다(원가 0 이익 방지)
2. **판정 기준 = 업비트 일봉 종가 + 24시간 유예**, 라벨 하나 · 우선순위 고정. 사용자 결정 "KST 09:00"(= UTC 00:00, 같은 경계)
3. **자동 태그는 조각 수량 과반** · 추격은 5분봉(30일)이 없으면 직전 판정을 잇는다
4. **미러는 요청 시 계산**(기획서 "배치 → 읽기 뷰"에서 변경) — 새 표 · 마이그레이션 없이 14ms
5. **보유 대비 = TWR** · 순입금은 같은 날 같은 비중 매수(사용자 결정) · 결과 단위는 청산 30일 뒤 종가
6. **`market` 공개 API 에 `highestCloseBetween` 추가** — 컨텍스트 경계를 넘는 새 계약 하나
