## 판단 — 리뷰가 볼 곳

1. **패널은 화면마다가 아니라 공용 내비 본문 한 곳** — `AppNavigation` 의 본문 칸이 면 · 모서리 · 선 · 여백을 갖는다. 27경로가 한 번에 같은 틀이 되고 화면은
   바탕을 칠하지 않는다. `overflow` 를 걸지 않았다(걸면 표 머리 · 미리보기의 `sticky` 가 갇힌다). 앱 웹뷰는 이 면을 걷는다(모바일은 이 틀이 아니다 — FR-17)
2. **화면 틀 `PageFrame`(`@repo/web-shared/ui`)** — 제목(18/700 h1) · 오른쪽 칸 · 사이드 자리(312, 768~1023 아래, 앱 웹뷰 없음)를 한 컴포넌트로. 투자 9화면 · 셸 설정 · 홈이
   `Root → Section → Container 2xl → Padding` 네 겹 대신 이것 하나. 사이드 **내용**은 도메인이 채운다(투자 `InvestSide`)
3. **변경 금지 목록과 부딪친 둘** — 투자 표 세그먼트(전체 · 거래대금 …)는 글로벌 플랜 §6 "변경 금지"라 FR-4 의 28 · 모서리 6 을 적용하지 않았다(실측 27 · 8 은 "비슷").
   배경 `#F2F4F6` 은 같은 목록에 있지만 FR-14 가 사용자와 개정(11-04)한 값이라 바꾸고 §6 에 표기했다
4. **"새 숫자 금지"는 래칫 시험으로** — 지금 단 밖 크기가 영역마다 있다(투자 63 등). 한 번에 지우면 화면 재설계 REQ 를 미리 하는 셈이라, 늘면 실패 · 줄면 기준을 낮추는
   시험(`@repo/ui` `fontSizeBudget.test.ts`)을 두고 줄이는 일은 `FE-REQ-048` · `049` · `060` 에 남겼다
5. **필터 칩 켜짐 파랑을 진하게** — 실측 `#2272EB` 는 자기 9% 파랑 면 위 3.70~4.01:1(13px AA 미달). 같은 계열 `#1B5FC7`(4.93~5.34)
6. **섹션 탭은 밑줄 · 미끄러지는 표시를 지웠다** — 18px 제목 글자 + 3px 검은 밑줄(FE-REQ-044 P-31)이었다. 진하기로만(1단 ↔ 2단). 쓰는 곳은 시세 화면 표 탭 · 검색 모달 둘
7. **뒤로 판정은 기록 API** — referrer 는 같은 zone 안 이동에 안 바뀌어 늘 "밖에서 옴"으로 읽혔다(실측 결함). 앞 기록이 같은 origin 이면 브라우저 뒤로, 아니면 자산군을 든 목록 주소
8. **스크롤 복원은 "떠날 때 적고 높이가 자라면 옮김"** — 표가 브라우저에서 늦게 차 Next 기본 복원이 0 으로 잘렸다. 스크롤 이벤트로 적으면 전환 중 중간 값이 덮어(실측 250)
   떠나는 누름 캡처 · pagehide 에 적는다. 방금 popstate 로 온 경우만 옮기고, 사람이 스크롤하면 그만둔다
9. **사이드 라벨을 `"use client"` 파일 밖에** — 서버 페이지가 클라이언트 모듈의 값을 읽으면 문자열 대신 참조가 온다(11-05 때맞춘 팁 400 과 같은 원인). 모델 파일로
