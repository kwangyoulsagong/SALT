## Summary

`FE-REQ-074`. 순서 2(`FE-REQ-072`)는 홈만 기준 화면 모양으로 그렸고 저축 · 가계부 · 투자 탭과 목표 · 종목 상세 · 코치 리포트 안쪽은 데스크톱 조각을 한 열로 쌓은 그대로였다.
같은 부품(`mobile-design.md` §2)으로 맞췄다. 서버 · BFF 변경 0 — 같은 응답 · 같은 칸, 배치와 표면만. 순서 3(`FE-REQ-073`) 앞에 끼웠다(사용자 "휴대폰 끝난 뒤" 데스크톱 개편).

| 산출물 | 위치 |
|---|---|
| 금액 카드 | `@repo/web-shared/layout/mobile` `MobileSummary icon` — 저축 · 가계부 탭 요약 |
| 부품 꺼냄 | `MobileShortcuts`(홈 → 홈 · 투자 탭) · `DesktopViewFoot` · `MobileFoot.css`(홈 설정 알약과 한 부품) |
| 상세 흰 섹션 | `@repo/web-shared/ui/surface.css` `MOBILE_ROOT` 패널 값 · 코치 리포트 머리 겹침 0 · 종목 상세 머리(이름 → 가격 → 등락 줄) |
| 같이 고침 | `@repo/ui` `AssetIcon` 대체 글자(`KRW-BTC` "KR" → "BT" · 국내 "00" → 이름 첫 글자, 데스크톱도) · 글자 래칫이 `MOBILE_ROOT` 를 휴대폰 표지로 셈 |

## 판단

1. **상세 패널은 공용 표면 한 곳에서** — 리포트 위젯 · 패널 다섯을 하나씩 덮지 않고 `surface.css` 에 `/m` 값 세 줄. 같은 패널이 휴대폰에 더 와도 그대로 흰 섹션
2. **탭 요약에 알약을 두지 않는다** — 홈 카드 알약은 카드 전체가 링크라 모양만이다. 탭 요약은 링크가 아니고 기록 버튼은 하단 고정에 이미 있다 — 같은 행동 두 자리를 만들지 않는다
3. **한 장 패널 안 칸은 그대로** — 데스크톱과 같은 위젯 · 투자 동결(`ADR-005` §5). 겉 패널만
