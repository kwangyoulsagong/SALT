## 판단 — 리뷰가 볼 곳

1. **Prisma `multiSchema` 대신 SQL 전용 마이그레이션** — 기존 모델 40여 개에 `@@schema` 를 달지 않으려고. 이력은 한 벌 그대로
2. **보정 풀을 종목 전체로 묶었다(정규화 CQR)** — 종목 하나의 52주로는 90% 구간을 보정할 표본이 모자란다. 대가: 종목별 특성은 스케일(변동성)로만 반영된다
3. **기준(비교 대상)도 같은 방법으로 보정한다** — 그래야 "같은 커버리지에서 폭이 더 좁은가"가 공정하다(FR-10)
4. **라이브 52주 전까지 게이트는 백테스트 점수로 판정하고 `score_kind=backtest` 로 표시** — 섞지 않는다
