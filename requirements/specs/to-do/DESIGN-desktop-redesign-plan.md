## Summary

사용자 지적(2026-10-30): 헤더가 허전하고 뒤로 가기가 없다 · 국내 탭이 코인 탭보다 빈약하다 · 국내 상세가 깨지고 코인 · 국내 상세 모두
보기 힘들다 · 데스크톱 홈이 휴대폰 화면이다 · 탭 제목에 실시간 가격이 없다 · 로고가 없다. 기준 증권 앱 웹 11화면 실측과 공개 디자인
시스템 조사로 규칙(`salt-microFe/.claude/rules/screen-desktop.md` · `screen-mobile.md`)을 먼저 세우고, 화면별 REQ 로 나눴다.

| 순서 | REQ | 영역 | 내용 |
|---|---|---|---|
| 1 | `FE-REQ-051` | FE | 로고 SVG · `Logo` 컴포넌트 · 파비콘 (헤더 첫 칸이라 먼저) |
| 2 | `FE-REQ-047` | FE | 틀 — 전역 헤더 · 바탕 · 패널 · 사이드 · 위계 토큰 · 뒤로 · 탭 주소 보존 |
| 3 | `FE-REQ-049` | FE | 종목 상세 재설계(코인 · 국내 한 틀) · 국내 깨짐 B1~B8 · 탭 제목 실시간 가격 |
| 4 | `DB-REQ-035` → `SRV-REQ-042` → `BFF-REQ-044` → `FE-REQ-050` | 전 영역 | 국내 탭 요약 띠를 코인과 같은 모양으로(계약 변경 — 한 PR 정당) |
| 5 | `FE-REQ-048` | FE | 홈 데스크톱(요약 띠 · 목표 목록 + 미리보기 · 사이드) |
| 함께 | `FE-REQ-046`(F008 슬라이스 24) | FE | 국내 상세 "주요 사건" — 3번의 "자세히" 탭 자리 |

> **순서 개정 2026-10-30** — 마스터 인덱스 §4-1: 디자인은 기능(남은 것 · 추가된 것) **뒤**다. 국내 탭 요약 4종(`DB-REQ-035` · `SRV-REQ-042` · `BFF-REQ-044` · `FE-REQ-050`)은 새 서버 계약이라 기능 묶음(순위 3)으로 옮겼고, 헤더 검색 상자는 F000 FR-40 종목 검색(순위 2)이 먼저 있어야 한다. 이 문서의 디자인 순서는 051 → 047 → 049 → 048.

## 판단

1. **표는 그대로** — 사용자가 좋다고 한 유일한 부분이고, 실측 값도 이미 같다
2. **같은 컴포넌트, 다른 데이터** — 국내 요약 · 국내 상세가 코인과 다른 화면처럼 보이는 것이 핵심 문제였다. 국내 전용 상자(`KrIndexSummary`)를 지운다
3. **규칙이 먼저** — 화면마다 다시 재지 않게 실측 값을 규칙 파일 한 곳에. 공개되지 않은 값(모바일 내비 높이 등)은 지어내지 않고 남겼다
4. 기준 서비스 이름은 문서 · 코드 · 커밋에 0건
