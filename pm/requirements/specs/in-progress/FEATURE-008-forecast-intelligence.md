# FEATURE-008: AI 전망 · 인텔리전스 (데이터 파이프라인 → 온톨로지 → 에이전트)

## TL;DR

- 상세 분석 페이지 **[해설 보기]** 를 확장한다. 지금은 "왜 이 판단인가"만 말한다. 앞으로는 **앞으로 어떻게 될 수 있는가**
  (기간별 가격 구간 · 상승 확률 · 주간 "이 주에 판다면" 시나리오 · 내 규칙 가격 도달 확률)와 **누가 움직이는가**
  (외신 · 고래 · 자사주 · 내부자 거래)를 말한다.
- 전망은 **확률 · 구간만**, **소유자 전용**, **전망 3종 세트(채점 이력 · 기준 모델 대비 · 빗나간 사례)가 없으면 렌더하지 않는다** — `ADR-003`.
- 숫자는 새 **Python 예측 서비스**(`salt-forecast/`)가 낸다. LLM 은 숫자를 만들지 않는다 — **에이전트가 온톨로지 · 전망을 도구로 조회해 문장만 쓴다** — `ADR-004`.
- 해설은 **단계가 차례로 흘러나오는** 스트리밍 경험으로 보여 준다.
- 목표는 "적중률이 높다"를 약속하는 게 아니라 **적중률을 매주 채점하고, 기준 모델을 못 이기면 스스로 꺼지는 전망**이다.

## 배경과 문제

- 사용자 요구(2026-09-23): *"미래에는 이 정도 차트가 올라요 또는 내려요 · 얼만큼 벌어요 · 이때 팔아야 돼요 … 주간별로
  이날에 팔면 이 정도 이득 이 정도 손실 예측 … 분석을 외신 · 고래 · 자사주 파는 거 등 더 자세한 정보로"*,
  *"적중률이 진짜 높고 신뢰도가 좋아야"*, *"데이터 파이프라인 - 온톨로지 - 에이전트"*.
- 현재 해설(`ExplainCoachDecision` → `GeminiCoachExplainer`, `gemini-2.5-flash-lite`)은
  - 프롬프트의 숫자 · 뉴스를 **프론트가 보낸 요청 본문**에서 받는다(서버가 사실을 모으지 않는다)
  - 데이터가 업비트 시세 · 대량 체결(≥ 5천만 원) · 공포탐욕 · 뉴스 RSS 뿐이다. **DART · SEC · 온체인 · 주식 시세 없음**
  - LLM 출력에 **확신 표현 필터가 없다**(프롬프트 규칙뿐)
  - 2026-09-18 LLM 이 만든 `expectedReturn` 을 지웠다 — 채점되지 않는 숫자였다

## 목표

1. 전망을 **채점 가능한 형태**(분위수 · 확률)로 내고, 채점 결과를 전망 옆에 붙인다.
2. 분석 재료를 **서버가 모은 사실**로 바꾼다 — 외신 · 고래 · 자사주 · 내부자.
3. LLM 을 **에이전트**로: 사실 · 전망을 도구로 조회하고, 인용한 사실에 출처를 단다.
4. 해설이 기다림 없이 **단계별로 흘러나오게** 한다.

## 사용자 시나리오

1. `/investments/KRW-BTC` → [해설 보기].
2. 즉시 단계 표시가 흐른다: `시세 확인 ✓ → 고래 흐름 확인 ✓ → 공시 · 내부자 확인 ✓ → 외신 확인 ✓ → 전망 계산 …`
3. **전망 카드**(소유자만):
   - `4주 뒤 가격 — 80% 구간 88,000,000 ~ 112,000,000 · 중앙값 101,500,000 · 오를 확률 58%`
   - 부채꼴 밴드 차트(1 · 2 · 3 · 4주)가 왼쪽에서 오른쪽으로 그려진다
   - `90% 범위 ±9% · 실제 89% 맞음 · 단순 예측(±13%)보다 31% 좁음 · 표본 52`
   - `자신 있을 때만 — 52주 중 14주 판정 · 10번 맞음(71%) · 같은 기간 항상 오른다 58%`
   - `빗나간 때 — 2026-08-05 주 구간 하단 아래로 −14%`
4. **주간 시나리오 표** — "이 주에 판다면":

   | 주 | 나쁠 때(하위 10%) | 중앙값 | 좋을 때(상위 90%) | 오를 확률 |
   |---|---|---|---|---|
   | 1주 | −620,000원 | +80,000원 | +710,000원 | 54% |
   | 4주 | −1,400,000원 | +310,000원 | +1,900,000원 | 58% |

   아래 한 줄: `기대값이 가장 큰 주: 4주 (중앙값 기준) — 판단은 본인` · 금액은 **보유 수량 × 가격**으로 서버가 계산.
5. **내 규칙 가격 도달 확률**(보유): `4주 안에 손실 제한 88,300,000 도달 21% · 1차 익절 112,000,000 도달 18%`.
6. **누가 움직이나** 섹션: 고래 순매수 흐름 · 자사주 취득/처분 공시 · 내부자 거래 · 외신 핵심 3줄 — 각 줄에 **출처 · 시각**.
7. 에이전트 해설: 문장이 토큰 단위로 흘러나오고, 인용한 사실엔 출처 칩이 붙는다.

## UX 상태

- **Streaming**: 단계 → 사실 → 전망 → 문장.
- **Forecast blocked**: 사유 한 줄. 나머지 섹션은 정상.
- **Not owner**: 전망 섹션 자체가 없다(안내 문구도 없다).
- **Stale data**: 섹션별 "마지막 수집 N시간 전".
- **LLM 실패**: 규칙 기반 문장 + 배지. 전망 · 사실 섹션은 그대로(숫자는 LLM 과 무관).
- **Aborted**: 화면 이탈 시 스트림 · LLM 호출 중단(기존 abort 유지).
