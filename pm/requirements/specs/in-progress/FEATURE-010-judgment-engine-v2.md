# FEATURE-010: 판정 AI v2 — 점수를 "채점되는 확률 · 비중"으로

## TL;DR

- 목표 문장(사용자 2026-09-27): *"AI 만 제대로 완벽하게 — 돈 잘 벌고 분석 잘하게."* 트레이딩(자동 매수 · 매도) · 계좌 연동은 **없다**.
  리서치 결론으로 옮기면 **"시장 하락을 덜 맞고, 오를 때 절반 이상 따라가며, 그 사실을 원장으로 증명한다."** 근거:
  `requirements/reports/research/2026-09-27-ai-judgment-upgrade.md`(이하 리서치).
- 방법은 모델 교체가 아니라 **파이프라인**이다: 불변 원장 → 규칙 항목 IC → 국면 · 변동성 → 화면 → 메타 모델 · 보정 → 기대 R · 비중 → 데이터 → 운영(리서치 §10).
  각 단계는 **결과 전에 판정 규칙을 사전등록**하고, 이 시장(업비트 원화 8년)에서 통과한 것만 서버에 넣는다.
- 지금까지 사전등록 넷 중 **서버에 들어간 것은 규칙 가중 조정(`mode-decision@2`) 하나**다. 국면 게이트 · 이벤트일 축소 · 보정 확률은
  기준을 못 넘어 들어가지 않았다. 이것이 이 기능의 정직성이다 — "못 넘었다"도 원장에 남는다.
- 숫자는 서버 · 문장은 템플릿/LLM · 주문 경로 없음 · 명령형 0건 · 3종 고지 상시(마스터 인덱스 §6).

## 배경과 문제

- 코드 감사(리서치 §2): 저장 추천 적중률이 최신가 기준 · n ≥ 1 · 덮어쓰기, 모드 판단이 5분봉 RSI, 화면에 나가는데 고정 프로토콜 없는 숫자 13개.
- "AI 가 매수하라는 게 없다"(사용자) — 규칙 점수는 50 시작 · 가점 < 감점이라 후보 문턱 70 에 거의 안 닿는다.
- 규칙 점수는 **점수이지 확률이 아니다.** 70 이 몇 % 로 맞는지 아무도 모른다. 확률을 보이려면 보정과 표시 게이트가 필요하다.

## 목표

1. 화면의 모든 판정 숫자가 **불변 원장 · 고정 지평 · 기저율 대비**로 채점된다(슬라이스 0 · 1).
2. 규칙 항목마다 이 시장에서 맞는지 재고, 안 맞는 항목은 가중 0 · 거꾸로면 반전한다(슬라이스 1).
3. "얼마를 들고 · 얼마를 지킬 수 있나"에 서버가 답한다 — σ 손절 · 익절 · BTC 베타 합 · 손실 비대칭(슬라이스 2).
4. 첫 화면에 판정 · 성적표 · 위험 노출이 먼저 보인다(슬라이스 3).
5. **확률은 자격이 생긴 뒤에만** 보인다 — 백테스트 게이트 + 라이브 게이트(n ≥ 200 · ECE ≤ 0.05 · BSS > 0)(슬라이스 4).
6. 시장이 평범한 날에도 **목표 비중 부족분**이 나온다 — 확률 없이 σ 타깃 · 한 종목 상한, 3종 고지와 함께(슬라이스 5, 완료). 기대 R · 켈리는 확률 자격 뒤

## 사용자 시나리오

1. `/investments` 머리 아래 [위험에 노출된 돈] · [판정 성적표] — 이번 달 손실 예산 · 집중도 · 회전율 · BTC 베타 합, 신호 유형별 적중 · 기준 대비 · 채점 수 · 빗나간 3건(슬라이스 3, 완료).
2. 종목 상세 첫 카드 = 코치 판단. 익절 계획 가격선 옆에 "변동성 기준(20일 σ)" 근거 한 줄(슬라이스 2 · 3, 완료).
3. (확률 자격이 생기면) 판단 카드에 `익절(+2σ)이 손절보다 먼저 닿을 확률 18% · 채점 212건 · 기저율 12%`. 자격 전에는 `확률 표본 n/200`. **지금은 이 줄이 없다** — 슬라이스 4 두 등록 모두 자격을 못 얻었다.
4. (슬라이스 5, 완료) `/investments` 첫 카드 [이번 주 목표 비중] — 보유 + BTC · ETH 목표 · 지금 · 차(원 · 수량) · 무효화 3조건 · 규칙 근거 · 8년 기록 · 빗나간 때. 실행은 사용자. 기대 R 은 없다

## 비기능 요구사항

- **누수**: 모든 피처 행 t 까지 · 퍼지 · 엠바고 · 누수 테스트(`salt-forecast/.claude/rules/time-and-leakage.md`). 백테스트 > 60% 적중이면 누수부터 의심.
- **재현**: 사전등록 원문 sha256 불변 · 시드 고정 · 리포트 커밋. 같은 as_of 두 번 → 같은 판정.
- **성능**: 백테스트 < 5분 · < 2GB(슬라이스 4 실측 70초 · 538MB). 매일 작업 < 1분.
- **보안 · 개인정보**: 예측은 종목 단위. 사용자별 예측 행 없음. 계좌 키 받지 않음.
- **접근성 · 모바일**: 화면 슬라이스는 WCAG AA · 360 폭(슬라이스 3 실측).
- **관측성**: 작업마다 `job_run` 행 수 · 소요 시간.

## 정책과 제약

- 사전등록 뒤 판정 규칙을 바꾸려면 **새 키**(`meta-model@2`). 결과를 보고 문턱을 낮추지 않는다.
- 표본 < 30 적중률 %, < 200 확률 표시 금지. Isotonic · 딥러닝 · 종목별 모델 · 랜덤 K-fold 금지(리서치 §6-5).
- LLM 에 종목 · 비중 · 타이밍을 묻지 않는다. LLM "확률"을 보정 없이 표시하지 않는다.
- 참고한 외부 서비스 이름을 문서 · 화면에 쓰지 않는다.
