## TL;DR

- 로그인 안 한 사람도 투자 화면에서 **코인 · 국내 시세 전부**(실시간 · 차트 · 호가 · 투자자 · 업종 · 뉴스 · 왜 움직였나 · 검색)를 본다
- 브라우저엔 서버가 준 **30분짜리 게스트 토큰**(httpOnly 쿠키)만 — KIS 키는 서버 밖으로 안 나간다
- **★ · 포트폴리오 · 매입가 · 거래 기록 · AI(코치 판단 · 해설 · 요약 · 전망)** 는 흐린 유리막 + "로그인하고 보기"
- 로그인한 친구는 국내도 본다(지금은 소유자 한 명만). 국내 코치 판단도 로그인 전체. 전망만 소유자

## 배경과 문제

- 2026-11-10 사용자: 시세 보는 데 로그인을 요구하는 건 맞지 않다 · 친구에게 링크를 보내면 로그인 화면부터 뜬다
- 국내는 소유자 이메일 목록 판정이라 초대받은 친구도 국내 탭이 없다(`isKrStockViewer`)
- 비로그인이 `/investments` 에 오면 코인 표 일부만 보이고, 검색 · 상세 일부가 401 → 로그인 화면으로 튕긴다(`PUBLIC_PATHS` 에 투자 경로 없음)

## 목표

- 시장 데이터는 누구에게나 같은 화면 — 로그인 여부와 무관
- 로그인이 필요한 칸은 "있다"는 것을 보이고 유리막으로 막는다(숨기지 않는다)
- 검사 지점은 서버 한 곳 — 시장 경로 = "읽는 사람"(사람 · 게스트), 나머지 = 사람

### Non-Goals

- 공개 회원가입(초대제 그대로) · 게스트 ★ 임시 저장
- 크롤러용 데이터 SSR(지금 투자 화면은 클라이언트 조회) — Open Question 2
- 전망을 로그인 전체로 넓히기(`ADR-003`)

## 사용자 시나리오

1. 친구가 카톡 링크 `/investments?asset=kr_stock` 을 연다 → 국내 표 · 실시간 점 · 업종 띠가 보인다. 행 ★ 자리에 자물쇠 → 누르면 "로그인하고 관심 종목 담기"
2. 삼성전자 상세 → 차트 · 호가 · 투자자 · 왜 움직였나 ①② · 뉴스 본문이 보인다. 코치 판단 칸 · 거래 기록 칸은 흐린 유리막 + 로그인 단추(돌아올 주소 그대로)
3. 30분 넘게 띄워 둔 탭 → 게스트 토큰 만료 → 화면이 조용히 새 토큰을 받아 이어 본다(로그인 화면으로 튕기지 않는다)
4. 로그인한 친구(비소유자) → 국내 탭 · 국내 코치 판단 보인다. 전망 카드는 지금처럼 없다
