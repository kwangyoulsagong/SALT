# 시간과 누수 — 이 서비스에서 가장 중요한 규칙

> 백테스트 적중률이 높게 나오면 **먼저 누수를 의심한다.** 금융 예측에서 좋은 숫자의 가장 흔한 원인은 실력이 아니라 미래가 섞인 것이다.

## 1. 두 개의 시각

모든 사실 · 시세 · 피처 행은 시각을 **둘** 가진다.

| 필드 | 뜻 | 예 |
|---|---|---|
| `observed_at` | 사건이 **일어난** 시각 | 임원이 주식을 판 날 2026-09-01 |
| `available_at` | 우리가 **알 수 있게 된** 시각 | 공시가 올라온 시각 2026-09-04 17:12 |

**피처는 `available_at <= as_of` 인 행만 쓴다.** `observed_at` 으로 거르면 3일 뒤에 알게 된 내부자 매도를
그날 알았던 것처럼 학습한다 — 이게 가장 흔한 누수다.

- 수집 시각(`ingested_at`)은 `available_at` 이 아니다. 과거를 백필하면 `ingested_at` 이 전부 오늘이 된다.
  원문에 게시 시각이 있으면 그것, 없으면 **보수적으로** `observed_at + 소스별 지연 상한`(`data-pipeline.md` §4 표).
- 일봉 종가의 `available_at` = 그 봉의 마감 시각. 장중 예측에 그날 종가를 쓰지 않는다.

## 2. 시점 고정(as-of) 조회

```python
# ✅ store 는 as_of 를 필수 인자로 받는다
facts = store.facts_for(symbol, as_of=as_of, lookback=timedelta(days=90))

# ❌ as_of 없는 "최신" 조회는 features · models · scoring 에서 금지
facts = store.latest_facts(symbol)
```

`store` 의 피처용 조회 함수는 `as_of` 인자가 **필수**(기본값 없음)다.

## 3. 수정 · 재작성되는 데이터

- 공시 정정 · 뉴스 수정 · 시세 보정은 **덮어쓰지 않고 새 버전 행**으로 쌓는다(`db-contract.md` 버전 키).
- as-of 조회는 `available_at <= as_of` 인 **그 시점의 최신 버전**을 고른다.

## 4. 학습 · 검증 분할

- **무작위 분할 금지.** 시간 순서 분할만.
- 워크포워드: 학습 창 → 검증 창 → 한 칸 전진. 창 크기는 `modeling-evaluation.md` §3.
- **엠바고(purge)**: 예측 기간이 h 주면 학습 끝과 검증 시작 사이에 **h 주를 비운다**. 라벨(미래 수익률)이
  검증 기간과 겹치는 표본을 학습에서 뺀다.
- 정규화 · 스케일러 · 분위수 경계 · 보정 잔차는 **학습 창에서만** 적합한다. 전체 기간으로 fit 하면 누수다.
- 하이퍼파라미터는 학습 창 **안쪽** 검증으로만 고른다. 최종 검증 창 성적을 보고 고르면 그 창은 더 이상 검증이 아니다.

## 5. 생존 편향

- 상장폐지 · 거래 중단 종목을 표본에서 빼지 않는다. 종목 목록도 as-of 로 고른다(그 시점에 존재하던 종목).
- "지금 관심 종목"으로 과거를 백테스트하면 살아남은 종목만 본다 — 리포트에 **표본 선택 방식**을 적는다.

## 6. 누수 테스트 (필수)

`tests/leakage/` 는 validate 단계에서 반드시 돈다.

| 테스트 | 방법 |
|---|---|
| 미래 오염 | 피처 생성 후 `as_of` 이후 행을 DB 에 추가 → 같은 `as_of` 로 다시 생성 → **피처 동일** |
| 셔플 라벨 | 라벨을 섞어 학습 → 방향 적중이 50% ± 표본 오차 안이어야 한다. 넘으면 누수 |
| 재현 | 같은 `as_of` · 같은 모델 버전 · 같은 시드 → 예측 동일 |
| 엠바고 | 학습 표본의 라벨 끝 시각 < 검증 시작 |

## 7. 코드 리뷰에서 먼저 볼 것

- `shift(-` · `.lead(` · `max_date` · `.last()` 가 피처 코드에 있으면 한 줄씩 이유를 댄다
- `datetime.now()` / `date.today()` 가 `jobs` 밖에 있으면 틀렸다
- 전체 기간 `.fit(` — 창 안에서 하는지
