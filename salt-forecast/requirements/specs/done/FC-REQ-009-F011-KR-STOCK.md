## Summary

코인 전망(`FC-REQ-001`)과 **같은 엔진 · 같은 채점 · 같은 게이트**로 국내 주식 변동 범위를 만든다. 다른 것은 시간뿐이다 —
주식은 거래일만 있고, 종가는 장 마감 뒤에야 안다. 그래서 엔진의 시간 규칙을 자산군 달력(`Schedule`)으로 빼고
국내 주식 달력(`KrxSessions`)을 하나 더 둔다. 보정 · 채점 풀은 국내 주식만으로 채운다(코인과 섞지 않는다).
화면 경로는 이 REQ 에 없다 — 서버 `cards()` 는 아직 `KRW-` 심볼만 읽는다(FEATURE-011 FR-83 은 다음 슬라이스).

## 실력 감사 (2026-10-09) — 이 REQ 의 카드는 아직 화면에 가지 않는다

사용자 질문("대충한거야? 딥하게")에 답하려고 다시 쟀다. **파이프라인(누수 · 재현 · 달력)은 맞고, 실력은 증명되지 않았다.**

| 검사 | 결과 |
|---|---|
| 수정주가 · ±30% 초과 움직임 | 수정주가(`FID_ORG_ADJ_PRC=0`) · 초과 0건 |
| 꼬리 이탈 방향 | 위 7~8% · 아래 2~4%(명목 각 5%) — 주평균 실현 +1.1%. **현재 시총 상위 51종목 = 지난 2년 오른 종목**(생존 · 선택 편향). 전체 커버리지 88~91% 는 위아래가 상쇄된 것 |
| 앙상블이 이긴 이유 | 중앙값 +0.3~1.3%(기준 0) — 표본의 과거 상승을 배운 것 |
| 게이트 거짓 양성(8주 블록 부호 뒤집기 200회) | 국내 11/204 vs 실력 0 평균 8.7 · **p≈0.26**. 코인 139/997 vs 43.8 · p<0.001 |

원인 셋: 생존 편향 유니버스 · 겹치는 h주 라벨을 iid 부트스트랩 · 종목 × 기간 수백 개 다중 검정. 다음 REQ 가 고친다(`FC-REQ-020`, to-do).
